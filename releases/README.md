# 配布版（releases/）

コアブレイカーの配布版の zip です。zip を解凍して、中の `index.html` をブラウザで開くと遊べます（ネットにつながっていなくても動きます）。遊び方は zip の中の README にあります。

| 版 | ファイル | 主な中身 |
|---|---|---|
| v0.22（2026-10-20） | [core-breaker-v0.22.zip](core-breaker-v0.22.zip) | 戦闘画面の配置4種類（標準・アーケード・フライト・メカニカル、F2で切り替え）、照準の下のSPは黄色い棒だけ、猫のパイロット8匹とプレイヤー名、マップ「潮路搬送区」と50対50の実験、十字の持ち替えは上主・右副・左補助・下特別（全286種） |
| v0.21（2026-10-20） | [core-breaker-v0.21.zip](core-breaker-v0.21.zip) | 近接で刃の進む向きへ吹き飛ぶ、照準の上下で斬る高さが傾く（回転斬りは水平）、大剣の回転斬りの硬直の見た目を合わせた、マップ選択で白煙循環区の3つの配置を折りたたむ |
| v0.20（2026-10-20） | [core-breaker-v0.20.zip](core-breaker-v0.20.zip) | 補助装備11系統35型（全285種）、機体の新3系統ハリアー・プリズム・バスティオン（全72パーツ）、機体の関節と動き、ジャンプパッドとリフト、自動生成マップ「白煙循環区」、壁越しに撃てた不具合の直し |
