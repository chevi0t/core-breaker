## 本作で決めたこと

- 武器が空中で回る見た目をやめ、右手で柄を握り、肩・肘・胸を連動させる。二刀は左右の各段を別々に動かす。槍と杭は突き、爪は短い前方への打ち出しを作る。各武器の細部の動作は本作で手付けしたもので、動画から取り出したモーションではない。
- 動画は家庭版なので、性能の出典には使わない。既存のAC/PS4由来の数値とオーナー指定をそのまま保つ。特に本作の通常ソードの2回転・踏み込み・ブースト回復・ダメージ・硬直を、動画の説明から変更しない。
- 刃が横に動く攻撃は既存の `from` / `to` と各段の時刻に合わせる。構えと戻しは判定外の時間で行う。槍/杭/爪の手の伸縮で攻撃の到達時刻を変えない。
- 動画の視点に合わせた上下斬りは観察したが、本作の既存の攻撃高さを維持するため、今回は追加していない。別の操作・判定変更としてClaudeへ提案する。
- 本作の歩行・着地・銃の構えは、今回の関節と既存の状態から作ったオリジナル。歩行周期を実移動距離に合わせ、着地は足裏を残して膝を曲げる。
- 被弾判定を別の固定した代理形状にはしない。動いた装甲メッシュ自体へレイを当てる。武器の銃口も見えているメッシュへ合わせる。

## Claudeへの改善提案

[Issue #14](https://github.com/chevi0t/core-breaker/issues/14) に、ダッシュ斬りの読みやすさ、斬る方向と吹き飛び方向、空中攻撃から着地へのつながり、攻撃後の隙の見せ方を共有した。吹き飛びの向きや数値はこの動画だけでは確定できないので、追加のAC実演で確認する候補として記載した。今回のPRでゲームの性能や操作ルールは変更しない。

## 再現と検証

```sh
python3 tools/test/make_dbg.py dbg/mech-animation
node tools/test/mech_animation_check.js dbg/mech-animation
node tools/test/mech_motion_capture.js dbg/mech-animation /tmp/mech-motion
node tools/test/mech_shapes_check.js dbg/mech-animation
node tools/test/weapons_check.js dbg/mech-animation
node tools/test/bot_battle.js dbg/mech-animation city,wide,mesa,dock 150
```

`mech_animation_check.js` は6シリーズ+型を混ぜた1機で全285武器の構え、近接の各段、手と武器の握り位置、銃口の一致、着地の足裏、壁際/空中/ダッシュ/死亡/再出撃、動いた各部位への実射、7つの近接プレビューを確認する。第4引数で変更前の性能JSONを渡すと、全72パーツ・285武器・選択肢の同値も照合する。20機の関節処理のCPU時間はGPU描画を除いた参考値として記録する。
