# パーツのⅡ型・Ⅲ型（アーケード版）

取得日：2026-10-19。転記した全表と出典は `research/arcade/parts/`。各JSONの数値はACの元表で、本作の数値は下の比率で計算する。

| 本作 | Ⅰ型の基準 | Ⅱ型の出典 | Ⅲ型の出典 |
| --- | --- | --- | --- |
| スウィフト | シュライクI | シュライクII | シュライクV |
| ハウンド | クーガーI | クーガーII | クーガーS |
| ブルワーク | ヘヴィガードI | ヘヴィガードIII | ヘヴィガードIV |

ACに字面どおりのIIIやIIが無い箇所は、同一系統の購入順の次の2型を採用した。画面の型名は本作のⅠ・Ⅱ・Ⅲで、公式名は表示しない。

本作の新型 = 本作のⅠ型 × ACの新型 ÷ ACのⅠ型。重量・重量耐性は整数、ロック距離・ブーストは小数1桁、歩行・ダッシュは2桁、倍率は4桁に丸める。ランクの印字ではなく横の実数を使う。SP容量と巡航速度はAC表に値が無いため、Ⅰ型の本作共通値を継承する（比率を作らない）。索敵・DEF・加速・チップ・エリア移動等は本作に対応項目がなく移植しない。Ⅰ型と既存セットボーナスは変更しない。
