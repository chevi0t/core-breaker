# OSM の平坦市街地試作

ユーザー指定（2026-10-22）：起伏は後回しにし、実在都市の道路と建物を基に、道路・屋上の障害物、プラント、基地を追加する。最初の街区は新宿・都庁周辺。

`tools/mapgen_osm.py` は OSM XML を読む開発用の変換器。ブラウザ内のファイル選択画面は未実装。変換後は既存の HTML 版で遊べる。

```sh
python3 tools/mapgen_osm.py source.osm --id osm_city --output /tmp/osm_city.js
python3 tools/build_maps.py --check /tmp/osm_city.js
```

既定の中心は経度139.6918・緯度35.68975、街区は600×700m、街路の主方向を12度回してゲームの座標へ合わせる。範囲と回転は引数で指定可能。地面は高さ0。建物の高さは `height`、なければ階数×3.5m、それもなければ10.5mを用いる。高さの出典区分を個々に記録する。標高 `ele` は使わない。

建物は4m格子で箱へ近似する。中庭は multipolygon の内周として除き、分割された外周は接続する。四隅と中心が輪郭内にあるセルを使うため、外壁の位置は原図より内側へ寄ることがある。屋内、地下、通り抜けるピロティ、アーチ、立体交差、屋根の細部は再現しない。`building=roof` は地面からの壁へ変換しない。建物の重なりはセルごとの最大高へ統合する。

道路は地上の主要な `highway` の線を使用し、種類別の仮の幅で舗装を描く。実測の車線幅の再現ではない。地下と橋の道路を地上路として転用しない。舗装は任意の `roads: [[x,z,幅,奥行き],…]`。全矩形を1つの表示メッシュにし、衝突や標高へ影響させない。既存マップはこの項目が無ければ従来のまま。

`batchBuildings: true` はこの試作の任意項目。`office` の建物の壁面・屋根を材質ごとの2メッシュへまとめる。箱ごとの移動判定は残し、射撃面は同じ位置の三角形をまとめる。指定しない既存マップの建て方は変えない。基地へ伸ばした舗装は元の街路とは別に `generation.baseApproaches` に記録する。道路の資材は舗装内に配置する。

地理情報の変換と対戦用配置を分ける。基地は街区の外の2か所、プラント5基は交差点と広場から設置・両軍の再出撃帯を検査して選ぶ。大通りには6群の資材を追加する。屋上の機器は床の高さから始まる箱として既存の `bridges` に書き、ジップラインで上がる。地面の起伏を省略する今回の指定に合わせ、両端プラントの補給所は防壁と屋根で隠す。

今回の段階は到達・占拠・交戦の機能確認。3戦場の自律選抜や200〜2000戦による公平さの評価は未実施。現実の非対称な街区がそのまま公平になるとは扱わない。

参照した既存の設計知識：`mapdesign/LESSONS.md` の M01/M02（実物理で検査）、M14/M25（占拠地点と出撃帯を別に検査）、M19（屋上と地上の体積）、M28（屋根へ実際に上がる）。
