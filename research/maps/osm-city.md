# OSM 市街地の試作

ユーザー指定（2026-10-22）：実在都市の道路と建物を基に、道路・屋上の障害物、プラント、基地を追加する。最初の街区は新宿・都庁周辺。初版の俯瞰図への指摘に基づき、第2版では公園の盛り土・立体交差・街区内の基地・基地から離れた争奪点へ変更した。第3配置は追加指定「橙基地を右角に移動。マップ中央に寄りすぎ」に従い、橙基地を北東の角へ移した。第4配置でBを中央、Aを右下へ分散し、第5配置でDを削除して中立3基にした。第6配置は到着時間比較で選んだB移設(60,44)をユーザーが採用した。

## 再生成

Python が地理形状と施設候補を作り、Node.js が本体の通行判定を使って経路を完成させる。Node.js・Python 3・Playwright/Chromium が必要。ブラウザ内のファイル選択画面は未実装だが、完成したマップは既存の HTML 版で遊べる。

```sh
npm install
npx playwright install --with-deps chromium
node tools/generate_osm_city.js source.osm /tmp/osm_city.js
python3 tools/build_maps.py --check /tmp/osm_city.js
python3 tools/test/osm_import_check.py
node tools/test/osm_city_check.js dbg/osm-city-v2 /tmp/osm_city.json /tmp/osm-check
```

ZIP の `osm-data/` に入力・加工済みデータ・変換器を同梱する。Node の変換器はリポジトリ内の `tools/mapgen_browser.js` と本体を使うため、同梱ファイルだけでは実行できない。リポジトリで上記の手順を実行する。`python3 tools/mapgen_osm.py source.osm --output /tmp/flat.js --revision 1` は初版の平坦配置を作る。第2版は新宿専用の配置で、別の都市へ適用するには別の配置設計が必要。

## 地理形状

既定中心は経度139.6918・緯度35.68975。街路の主方向を12度回してゲーム座標へ合わせる。第2版は600×600mを取り出し、戦場全体を648×632mにする（初版は街区600×700m・戦場648×1100m）。

建物は4m格子で箱へ近似し、multipolygon の中庭を除く。高さは `height`、なければ階数×3.5m、最後に10.5mを使い、出典区分を記録する。標高 `ele` は使わない。道路の大半は地上タグだけを使うが、第2版では対象の4街路の橋・地下タグも取り込む。道路の舗装は表示だけで、移動・弾の障害物にはしない。建物の壁と屋根は2メッシュ、道路は1メッシュへまとめ、個別の箱の衝突判定を保つ。

## 第2版の対戦用地形

- 公園：中央に最高18m、北側に9mの台地と緩斜面、南側に7mの丘を追加する。
- 中央通り（z=-75）・ふれあい通り（z=114）は床を-8mとし、都庁通り（x=44）・議事堂通り（x=168）を高さ0mの橋で通す。4交差点とも平面接続しない。橋の厚さ1m、桁下7m、機体の判定高4m。横道の脇の坂から地上へ戻れる。これらの高さはゲーム用の仮置きで、実測標高ではない。
- 建物輪郭の単純な地上押し出しで道路を塞いでいた連絡部分2か所は、道路幅28mの部分だけ下端8mの空中スラブへ直す。元の上面高さを保ち、下を通行できるようにする。
- 青基地は南西(-236,250)、橙基地はマップ北東角(270,-260)。基地判定はそれぞれ半径50m。砲台・レーダー・補給所・カタパルト・出撃点・防衛判断・マップ上の印も新位置へ移す。
- プラントは最初すべて中立の3基。Aは右下の街区(268,212)、Bは中央街路(60,44)、Cは公園北側9m(-208,-155)。第5配置でDを削除し、第6配置でBを図の下へ56m・右へ12m移す。A・C・基地・地形は前版を保つ。Bは中央の建物の東側にある街路に置く。すべて両基地の中心から180m以上離す。施設の円と両軍の再出撃帯（基地方向46〜52m・左右8m）を別々に検査する。
- 道路の資材6群、4か所の屋上機器とジップラインを残す。A・Cの補給所には壁と屋根を付け、Aの補給所も右下へ移す。後から置く補給所の壁が全プラントの両軍の出撃帯に重ならないことも検査する。基地のカタパルトは各2基で、弾道全体の障害物・着地を検査する。

歩行経路は高さ付きの節点を使い、橋上と橋下を別に扱う。本体の `clearPath` を往復検査し、終点の高さ・軸別の傾斜・頭上の空間も調べる。下段の坂で頭が橋の床へ入り込む経路は除外する。保存後にも軽量機・重量機の `physics` で両基地から全プラント・敵基地へ実走する。
