# 主武器の撃ち味の調整（2026-10-22）

ユーザーから「カテゴリ内で統一感を出しつつ撃ち味を変えたい」「主武器の反動調整を任せる」と委任された調整。100種・28系統を10カテゴリへ分け、回復のリズムを共有し、系統の基本角と型の補正で跳ねを決める。以下は本作独自の操作感の値で、AC原典の性能そのものとは扱わない。

元のAC対応・初回の採用値は [primary-recoil.json](primary-recoil.json) に残す。現在の全100種の採用値は [primary-recoil-tuning.json](primary-recoil-tuning.json)。コードの `PRIMARY_RECOIL_DEG` も維持し、未調整の新系統は従来の基準で動く。

## 系統の基本角

| 型 | 縦倍率 | 横倍率 |

| 速装型 | 0.9 | 0.9 |
| 重装型 | 1.15 | 1.05 |

精密型は同系統の基本型より必ず縦横を抑え、強装型は縦の一発を重くする。連射・持続は小さい跳ねを繰り返す。大容量マグナムだけは縦0.5/横0.7倍を個別適用し、従来の軽い一発を継続する。大容量や強装がすべての面で有利になることは意図しない。

## 回復のリズム

| カテゴリ | 定速回復までの待機（秒） | 定速回復（rad/秒） | 比例回復の係数（1/秒） |
|---|---:|---:|---:|
| rifle | 0.08 | 0.075 | 2.2 |
| burst | 0.08 | 0.08 | 2.4 |
| machine | 0.08 | 0.075 | 2.2 |
| energy | 0.06 | 0.08 | 2.4 |
| cannon | 0.1 | 0.09 | 1.6 |
| dual | 0.07 | 0.08 | 2.2 |
| marks | 0.06 | 0.12 | 0 |
| magnum | 0.1 | 0.06 | 0 |
| scatter | 0.07 | 0.11 | 0 |
| charge | 0.08 | 0.1 | 0 |

連射主武器は600発以下でも比例回復を使う。現在の反動角×係数が戻る速度となり、定速回復の待機中も動く。単発・充填は係数0で発射後の跳ねを保持し、定速回復を使う。散弾カテゴリも0で、発射時の短い衝撃と速い戻りを作る。マグナム基本型は縦2.75°、待機0.1秒、回復0.06rad/秒を維持する。

待機をまたぐ時間積分、0で止まる復帰、腕部の吸収、縦横の安全上限、照準/弾道/カメラの共通状態は継続する。マウスの操作角を自動で巻き戻さない。ロックや敵の有無に依存しない。副/補助/特殊装備の定義、威力・発射レート・弾数・散布・重量・保存形式は変えない。Botも同じ反動と回復を使うため、低反動化した銃はBotも長く撃ちやすくなる。

## 確認

- `family_recoil_check.js`：338項目。100種の反動以外の性能、他194装備の全性能、28系統内の回復の共有、精密/強装の関係、基本型全系統を含む実射64ケース。
- ガトリング基本型はレート補正後の縦0.12°を維持し、横±0.60°→±0.26°。標準腕・散布0・60fps・回転済みから3秒撃つと75発を維持し、横の振幅約58%減、1フレームの最大視点変化約54%減。
- マグナム基本型は縦の経過が比較前 `cf23419` と一致し、横の跳ね角は半分。
- 600発/分の二丁マシンガン連射型、540発/分の機関砲連射型でも蓄積を抑える。
- 銃のアニメーション・カメラの追従方式・ロックの強さ・散布角は今回変更していない。体感と対戦バランスの最終評価は実プレイで行う。
