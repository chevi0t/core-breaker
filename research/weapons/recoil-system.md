# 本家の射撃反動・照準・弾道の調査

調査日：2026-10-22（日本時間）。対象は主にアーケード版BORDER BREAK。依頼は、射撃反動と照準の見せ方を本家がどう扱っていたかの調査。ゲームの実装・数値は変更しない。

## 分かったこと

本家を参考にするなら、反動の大きさだけでなく、**跳ねるまでの時間と、照準が戻る動き**を扱う必要がある。現在の本作の「発射時に角度を即加算し、撃ち止めるまで蓄積する」方式を、本家の仕組みそのものとは扱えない。

公式ガイドは照準を「弾が飛ぶ方向」と説明する。一方、反動・復元の詳細は主に攻略wikiの説明であり、公開された内部コードや公式の計算仕様を確認したわけではない。照準の画面内移動とカメラ回転の分担については、下記のとおり未確認。

| 項目 | 資料から確認できた説明 | 出典 |
|---|---|---|
| 照準の意味 | 弾が飛ぶ方向を示し、敵へ合わせて射撃する | 公式ガイド [1] |
| 反動と散らばり | 腕部の反動吸収は照準の跳ね・ぶれを抑える。頭部の射撃補正は弾の散らばる範囲を変え、反動によるずれは補正できない | AC腕部 [2]、頭部 [3] |
| 反動が発生する過程 | 高速連射では、照準が動き切る前に次弾が発射され、数値から単純に考えるより反動が小さくなる | AC腕部 [2] |
| 元へ戻る動き | 発射間隔が長い場合にも、照準が元の位置へ戻る力が働き、実際の反動が小さくなる | AC腕部 [2] |
| 腕部と姿勢 | 武器の反動を腕部の反動吸収係数で割り、自機の立ち・しゃがみの状態を掛ける説明。しゃがむと反動を軽減できる | AC腕部 [2] |
| ガトリングの特徴 | 用語集は、多くの銃の主な反動を上方向、ガトリングを円を描く動きと説明。個別ページにも強い横反動・高速連射での相殺の記述がある | AC用語集 [4]、ガトリング [5] |
| 通常ロック | 武器ごとの倍率でズームし、敵の追尾に強い視点移動と一定範囲の照準補正が働く、と説明される | AC頭部 [3] |

腕部ページが示す概念式は次のとおり。戻る速さ・連射間隔も別に考える必要があり、これだけで時間ごとの照準軌跡は決まらない。

```text
反動による照準の移動量
  = 武器の1発あたりの反動 ÷ 腕部の反動吸収係数 × 姿勢の係数
```

同ページには、しゃがみの例として `0.2 / 1.4 × 0.65 ≒ 0.093` がある。これを全バージョン・全しゃがみ状態へ共通の係数と断定はしない。

## 現在の本作との違い

比較対象はPR #49の視点反動復元時点（`9d39a6a`）。本家の説明から直ちに本作を変更するものではない。

| 項目 | 本作の現在の処理 | 調査から分かった差・限界 |
|---|---|---|
| 跳ね方 | `recoilKick`が発射ごとに縦・横の角度を即加算する | 本家には跳ね切るまでの過程がある。単純な瞬間加算だけでは高速連射時の相殺を表せない |
| 回復 | 主武器は最後の発射から0.1秒待ち、0.06rad/秒で戻る | 本作独自の設定。本家の正確な待機時間・回復曲線を裏付ける資料は未確認 |
| 蓄積上限 | 縦0.24rad・横±0.14radを腕部係数で割る | 本作独自の設定。本家の同じ上限を確認したわけではない |
| 横の動き | 各発の左右乱数を加算する | 円を描くというガトリングの説明とは一致を確認できていない |
| 姿勢 | `recoilKick`にしゃがみの係数はない | 本家の姿勢による軽減とは差がある |
| 表示と射線 | 照準は画面中央、カメラに反動を反映。反映済みの角度を弾へ二重に足さない | 本作の現行仕様。これが本家のカメラ/HUDの分担と同一とは未確認 |
| 通常ロック | 目標の角移動の25%、ショートダッシュ中8%を追い、照準を敵へ引き戻さない | ユーザー指定の操作感。本家の強い補正の説明を根拠に勝手に戻さない |

本作の反動値を一律に小さくする前に、単発の時間変化・次弾との重なり・復元を調整する方が、本家の説明には沿っている。ただし、これは実装方針の候補であり、本家の内部アルゴリズムを特定したという意味ではない。

## 未確認・断定しないこと

- カメラ全体を回す割合、照準だけが画面内を動く割合、機体や銃だけの動きとの分担。wikiの「照準がぶれる」という記述だけでは区別できない。
- 発射から最大反動までの秒数、補間曲線、次弾が来たときの上書き・重ね合わせ・打ち切りの規則、横反動の位相や乱数分布、回復の正確な待機時間と曲線。
- AC表の反動数値を、そのまま度数の角度として扱ってよいか。本作では度→ラジアンとして解釈しているが、今回の資料で単位と換算を確定していない。
- 通常ロックによる反動そのものへの軽減率。ガトリングの個別ページはロック時の改善を説明する一方、腕部ページはロック・ダッシュ・ジャンプの反動への影響を詳しく検証していないと明記する。ズーム・照準追従・散らばりの変化と区別する必要がある。
- 通常ロックの説明から、弾が敵の中心へ吸い付く内部処理まで推定しない。本作の「弾を敵の中心へ補正しない」方針は維持する。

映像は、既出のニコニコ動画 `sm37304807` がHTTP 503、YouTubeは接続拒否で再生を確認できなかった。公式初心者ページの埋め込み動画（`I-vdi4MyENE`）もリンクの存在まで確認したが、内容の観察・フレーム計測はしていない。したがって、本メモに映像を見たという主張や計測値は含めない。

映像で残りを確認するなら、地形の固定目印・照準中心・機体を同時に追い、単発／連射、ロックなし／あり、腕部と姿勢を分けて観察する必要がある。操作入力が不明な実戦映像だけでは、手動の反動制御と自動復元を区別できない。

## 既存の調査記録の訂正

以前の[主武器反動の記録](primary-recoil.md)は、ハガードM50の反動実数を不明として本作のマグナムに縦2.75°・横±0.60°を設定していた。今回、AC個別ページ [6] の**本文**にM50の`5/0.6`、カスタムの`2/0.3`、RFの`1.5/0.2`の記述を確認した。

「資料に実数がない」という記録は訂正する。ただし、今回の依頼は仕組みの調査なので、既存の性能値・`PRIMARY_RECOIL_DEG`・対応JSONは変更しない。数値の採用と単位の解釈は別に判断する。
