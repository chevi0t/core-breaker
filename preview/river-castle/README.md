# 翠河城下・チェックモード入り試遊版

レビュー専用ブランチの配布物。公開サイトは変更しません。ゲーム元コミット：6065efd073654fff0bc69e1af095a83ff0cd3b62。

1. このブランチの GitHub 画面で **Code → Download ZIP**。
2. ZIP をすべて解凍。
3. `preview/river-castle/game/index.html` を PC の Chrome / Chromium で開く。必要な Three.js・音・マップは同梱済みです。
4. マップ選択で「翠河城下・地形試作」を選び、左上の「試遊専用・マップチェック」から開始。

ファイルを直接開けないブラウザの場合、この README のあるフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/game/` を開いてください。

歩行：WASD、Shift ブースト、Space ジャンプ、右ドラッグで視点。自由視点：WASD、Q/E 上下、Shift 高速。開始・終了時は試合をリセットします。チェック中は BOT・時計・射撃が停止します。

問題箇所へ照準を向け、コメントを入力して「照準地点を記録」。番号付きマーカーを置けます。一覧で編集・削除・記録視点への復帰が可能。「報告JSONを書き出す」で保存したファイルをチャットに添付してください。空を向いた場合は現在位置が記録されます。メモはページを閉じる前に書き出してください。

公開版にはチェックUI・起動経路は含まれません。PC Chromium の自動操作で確認。実スマホ・Safari・BT機器は未検証です。
