# パイロット4状態の静止画置き場

キャラごとに独立したPNGを4枚配置します。動画・アニメーションPNG・スプライトシートは不要です。現在は**格納規約のみ**で、ここへ置いた画像はまだゲームへ自動反映されません。既存の `../cats.png` とHTML内の猫表示は変更していません。画像未納入のフォルダをゲームからリクエストすることもありません。

## 配置

```text
prototype/avatars/pilots/
  tabby/               # キャラID。例：既存キジトラ
    normal.png
    boost_left.png
    boost_right.png
    damage.png
```

| 状態キー | ファイル名 | 用途 |
| --- | --- | --- |
| NORMAL | `normal.png` | 通常の顔 |
| BOOST_LEFT | `boost_left.png` | 機体自身の左方向へブーストしたとき |
| BOOST_RIGHT | `boost_right.png` | 機体自身の右方向へブーストしたとき |
| DAMAGE | `damage.png` | やられ顔・被ダメージ用 |

左右はカメラや画面の左右ではなく、機体の前方向を基準にした左右です。画像の左右反転で代用せず、それぞれ別画像を用意してください。DAMAGEの発生条件・表示時間・状態優先順位は状態切替を実装する際に決めます。

## 画像の規約

- 推奨は **512×512 px、RGBA、透過背景、静止PNG**。同じキャラの4枚は必ず同じ寸法にします。最終配信時に必要なら縮小・圧縮します。
- 4枚とも顔や体の基準位置、余白、縮尺をそろえてください。状態を変えたときに肖像全体が飛び跳ねるのを避けます。
- 背景・文字・HUD枠を焼き込まず、顔や必要な身体だけを収めます。ファイル名は表の小文字ASCIIで固定です。
- 元の高解像度画像や生成途中の画像はここへ置かず、採用する4枚だけを格納します。外部素材を使用した場合は既存の素材方針に従い、出典・利用条件を `../CREDITS.md` へ追記してください。

## キャラの追加・差し替え

1. 既存キャラなら該当IDフォルダへ4枚を置きます。`tabby`（キジトラ）、`silver`（サバトラ）、`black`（黒猫）、`white`（白猫）、`ginger`（茶トラ）、`calico`（三毛）、`tuxedo`（ハチワレ）、`siamese`（シャム）を用意済みです。
2. 新キャラは小文字英数字と `_` の安定したIDでフォルダを追加します。表示名はファイル名に入れません。既存IDを変更すると保存済み選択に影響するため、別IDを使ってください。
3. 4枚を揃えたら、キャラIDと画像一式を実装担当へ渡します。`.gitkeep` は空フォルダ保持用で、画像を置いた後も残して構いません。

この段階ではmanifestや画像登録を増やしていません。フォルダ名がキャラID、固定ファイル名が状態という対応が唯一の管理元です。ゲームへの選択肢登録・状態切替・未対応キャラの既存猫へのフォールバックは次の連携作業で行います。

既存の `tools/embed_pilot_avatars.py` は猫アトラス専用です。この4枚構造には実行しないでください。現行Pages/ZIPはHTML埋め込み方式なので、このフォルダを自動で配信しません。画像採用時は既存のオフライン動作を維持する埋め込み等の配布連携も必要です。格納だけで公開されたと扱わないでください。
