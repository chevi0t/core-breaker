### 層（2026-11-02）

HUD の揺れは `layers/` の層で動かす（後ろ髪・体・左腕・右腕・顔・前髪、やられ顔の顔。7枚で約62KB）。範囲は `layers/rig.json`、作り直しは `python3 tools/pilot_layers.py ace` の後に `python3 tools/embed_pilot_sprites.py`。

髪が白く、白いスーツ・左の袖と色がほとんど同じ（どちらも彩度0.1前後の薄紫）なので、色では分けない（`hairLight`）。体（`bodyHull`）と両腕の多角形の外の明るい所を髪とし、体に掛かる三つ編み（左肩）と右の房だけは `hairPoly` の中で髪にする。腕は多角形の中を袖の色で絞る（`armRefine`：白い袖は彩度の低い明るい所、黒い袖は暗い所。細い髪の筋は落とし、手と袖口は多角形のまま）。体の範囲は腰の横の肌と紐の輪郭に沿わせ、毛先を体に入れない（オーナー 2026-11-02「右腕は髪が腕について太く」「腰にも髪の毛が付いちゃってる」）。肌も彩度が低いので、肌は色相（橙）で拾って髪から除く。操縦桿の頭（`notHairPoly`）と白目（`notHair`）も除く。前髪（`frontHair`）は頭の上・前髪・顔の横の房・三つ編み・右の房。

揺れの設定は `prototype/index.html` の `PILOT_RIGS.ace.layers`（倍率はテストパイロットちゃんでオーナーが決めた値と同じ）。
