# 長手方向の拡張とカタパルト低角化（ローカル試作）

**後続更新**：この文書の山岳カタパルト約66mは87cdebb時点。最新は [TERRAIN_LAUNCH_RANGE.md](TERRAIN_LAUNCH_RANGE.md) の187〜192m。

ユーザー指定：コア間とプラント配置を長手方向へ1.5倍、カタパルトを速く低く射出、頂点まで操作固定、その後も射出方向の慣性を残す。公開・マージは未実施。

## 風裂山道の拡張

コア間370→555m。地形・橋・トンネル・外周・防壁・施設・navのZを1.5倍にする。横幅と高さは変えず、実プレイ範囲の外接寸法は320×690m。プラントはA(-65,127.5)、B(5,0)、C(55,-135)。斜めの直線距離まで一律1.5倍にする変更ではない。再出撃は従来のプラント中心から48m、占拠半径・機体・兵装・通常移動値は維持する。砲台が伸びた足場の縁に射線を遮られないよう、各台を前へ1.5m寄せた。

共通レシピ `lengthScale:1.5` で生成後の圧縮座標を伸ばす。元のレシピを変更せず、同じ入力の再生成を保証する。地形10,580三角形のまま、Z格子5→7.5m。内部索引の正方形halfは360へ広げるが、プレイ境界の横幅は広がらない。量子化上限を超える座標は拒否する。

拡張後の中央Bまでの通常歩行は重量二脚で青26.00／赤26.00秒、重量ホバー17.65／17.70秒。施設適用後の歩行navと実物理で測定し、戦闘・ブースト・カタパルトによる近道を除く。距離・速度の近さだけでPvP公平性は証明しない。

## 全マップ共通のカタパルト

時間指定の高角軌道を廃止し、原則30度、最大45度で指定着地点へ射出する。山岳4基は全て30度。拡張前の水平約16m/s・2.8秒から、拡張後は44.9〜53.6m/s・1.23〜1.46秒となる。上昇中は移動入力・ダッシュ・滞空を固定。解除は固定秒数ではなく実際の頂点で決める。視点・武器操作は従来どおり。

降下中の試作調整値は射出方向の水平初速65%以上、横方向35%以下、水平合計は初速以下。逆入力・空中ダッシュ・加速装置でも元の台へ向けて旋回し切れない。接地で制約を解除する。衝突による押し戻し・途中の地形への着地はあり、接地後の引き返しは禁止しない。通常ジャンプとジャンプパッドは変更しない。

低角化で旧経路の建物・高架への衝突を検出したため、星道・環都の射出台／着地点、潮路の着地点を明示的に再配置。星道の赤基地の東向き1基は北西の街路へ向きを変えた。星道の青・赤基地各1基は35度、C→Bの1基は45度、その他は30度。施設の参照先プラントと台の数は維持。建物の描画・衝突を消して通過扱いにはしない。

採用座標は `tools/mapdata/low_angle_catapults.json`。都市の原地形を再生成した後は `node tools/apply_catapult_routes.js` → `python3 tools/build_maps.py` を実行する。旧 `flight` / `catapultFlight` の読込互換は残すが、飛行時間指定としては使わない。基地行の5番目、プラント台の `angle` で30〜45度を指定する。

高速飛行中だけ物理を最大1/120秒刻みに分ける。30fpsで建物角へ接触する経路が120fpsでは抜ける差を、この刻みで抑えた。メッシュ・材質は増やさないが、飛行中のCPU仕事量は増える。実GPU／実スマホのFPS同等性、性能増分は未測定。

## 検査と限界

- `terrain_stretch_check.js`：全支持面のZのみ1.5倍、X/Y・三角形数・再出撃距離維持、入力非破壊。
- `terrain_recipe_schema_check.js`：3レシピ×3seedの再現性、8不正入力の拒否。
- `terrain_recipe_check.js`：軽量／重量の主要往復28本＋トンネル床・天井・射線・カメラ等11項目。
- `terrain_gate_flank_check.js`：砲台支持・実弾射撃・所属、軽量／重量／重量ホバーの両門通行と壁越え・退出、31項目。
- `terrain_access_check.js`：施設適用後の基地／再出撃の距離24組と実歩行12本。
- `catapult_control_check.js`：13マップ定義（配置違い含む）112台×30/120fps相当＝224無入力射出、最大着地点誤差1.86m未満。軽量・重量・重量ホバー×逆入力／横入力／逆方向ブースト×2刻み＝234操作ケース。早期接地解除とジャンプパッドも確認。衝突の微小押し戻しは機体半径程度まで区別する。
- `catapult_entry_check.js`：再配置した都市と山岳24台の中心・縁8点の216射出、歩行navとの入口／出口接続。台の中心だけ通る狭い経路は再配置して修正。
- 山岳の施設／nav検査、都市データ形式検査を通過。通常BOT戦は生ログを試遊パッケージに収録。統計的な勝率評価ではない。
- 新しい全域穴検査はユーザー指定で実施していない。実機Safari／BT・実GPU性能は未検証。
