# タッチ操作の自動攻撃と十字武器選択（ローカル試作）

基準main: `23ba7e4`（公開PR108を保持）。スマホの同時押しを減らすための入力変更。武器・パーツの定義、弾薬、連射間隔、クールダウン、移動、描画、ダメージ・被弾判定は変更しない。PCのマウス・キーボード・ゲームパッドは従来の入力を通す。初期操作は既存の `(hover: none) and (pointer: coarse)` で選び、`navigator.maxTouchPoints` がある画面も実接触でタッチへ切り替えられる。画面幅だけでは切り替えない。描画品質・マップ制限の既存端末判定は維持。

## 操作

- 左側：従来の移動スティック。外側まで倒すとダッシュ。
- 右側：なぞって照準。既定では敵に照準が合うと自動ロック・自動攻撃。初回と武器メニュー終了後は右側をなぞって開始する。
- 右側をダブルタップ：十字武器メニュー。上＝主、右＝副、左＝補助、下＝特殊。武器名を表示し、タップして選ぶ。中央の「閉じる」で取消。既存の「武器」ボタンからも同じメニューを開ける。
- ジャンプ・ダッシュ・リロード・アクションは従来のボタン。移動・視点・ブーストを別の指で同時操作できる。
- オプションの「照準で自動ロック・自動攻撃」をOFFにすると、射撃・ロックを手動ボタンで操作できる。設定は既存のoptions保存へ追加し、旧保存に項目がなければON。

ダブルタップは各接触230ms未満・移動累計8px以下、2回の終了間隔300ms未満・32px以内。同時に2本以上で右側を触った場合はダブルタップや視点操作にしない。左の移動指・ブースト指は除外せず並行して使える。数値は今回の操作調整値。

メニュー内は専用の大きいボタンで操作し、視点を回さない。開いた瞬間と表示中は射撃を止め、未発射の溜めとバースト残りを取り消す。既に飛んだ弾や開始済みの近接攻撃は消さない。選択・取消後は右側の新しいドラッグまで自動射撃を再開しない。ポインタ取消、フォーカス喪失、ページ非表示、画面回転、死亡・再出撃でも自動操作を解除する。縦画面では既存の「横向きにしてください」を表示し、入力を解除する。

## 外付けキーボード・マウス

Bluetoothの接続・ペアリングは検出しない。ゲーム中の実際の操作で切り替える。

- 移動・武器選択などの実キーボード入力、マウスのクリック・ドラッグ・ロック中移動・ホイールで手動操作へ切り替える。タッチ自動攻撃・自動ロックを止め、タッチ武器メニューを閉じる。最初のキー/クリックも通常入力として扱う。ただし武器メニューを閉じるクリックは発砲しない。
- ゲーム画面への実タッチでタッチ操作へ戻る。切替時は双方の保持入力を解除し、照準ドラッグ後に自動攻撃を再開する。入力中に切り替えたキーは離して押し直す。押しっぱなしのリピートで方式を奪い返さない。
- マウスのホバー、入力欄への文字入力、フォーカスだけでは切り替えない。タッチ由来の互換マウスイベントを除外する。ゲームパッドが生成するキーイベントは切替の根拠にせず、既存のゲームパッド操作を維持する。
- フォーカスを失うと保持入力を解除する。手動へ切り替えてもゲーム側の速度・射撃間隔などは同じ。

マウス固定（Pointer Lock）や全画面・画面回転固定はブラウザが許可する範囲だけ使う。非対応・拒否時に強制しない。マウス固定できない環境では既存の押しながらの視点操作が残るが、画面端による制約がある。iOS Safariの実機や実Bluetooth機器での検査は未実施。接続しただけでの自動切替を保証するものではない。

## 武器ごとの扱い

| 装備中の武器 | 自動操作 |
|---|---|
| `gun`（主・副・補助・特殊のどの枠でも） | 中央の実レイが敵に当たり、機体目線と銃口からも遮蔽されていない場合に既存の射撃入力を渡す。爆発物・投擲・散弾も対象。射程・弾道・爆風・味方判定はそのまま |
| 単発銃 | 押下と解除を反復。既存の発射間隔・残弾を越えて撃たない |
| チャージ銃・溜め近接 | 有効対象を保って充填し、満充填で解除して発射。対象を失った場合は溜めを取り消し、空撃ちしない |
| ミサイル | 既存のミサイル捕捉・発射処理を使う。自動操作から新しい追尾・ロック条件を追加しない |
| 遠隔爆弾 | 既存の投射は自動射撃対象。起爆は「起爆」ボタンで明示操作 |
| `sword` | 前方の敵が実際の刃の射程・振る範囲に入り、目線と刃の高さで遮蔽がない場合に開始。踏み込み距離を先取りした遠距離発動はしない。実際の命中・踏み込み・クールダウンは既存処理 |
| 重砲・照射砲 (`cannon` / `beamCannon`) | 装備中で照準が有効な敵に合った場合に既存の射撃入力を渡す。構え・SP・照射制限は既存どおり |
| 加速装置・迷彩・修理・設置支援・榴弾砲の地図指定など | 明示選択・ボタン操作を維持。敵を横切っただけでは起動・設置・地図砲撃しない |

「照準」「起爆」「自己修復」「解除」は該当装備で表示する。自動ロックは従来のロック可能武器・距離・遮蔽条件を満たす相手だけ。取得時に照準を胴へ飛ばさず、その後は従来のロック追従を使う。弾を敵へ曲げたり、画面周辺の敵を自動で選んで撃ったりしない。近接のみ、接近時の発動要求に合わせて前方の実攻撃範囲を調べる。

自動操作から別の武器を選ばない。既存の武器に備わる投擲後の持ち戻り、照射終了時の収納などは従来の武器処理に従う。中立物には自動射撃せず、手動設定で射撃できる。

## 検証・再実行

`python3 tools/test/make_dbg.py /tmp/mobile-auto` でデバッグコピーを生成する。

```sh
node tools/test/mobile_auto_check.js /tmp/mobile-auto /tmp/mobile-auto-results
node tools/test/hybrid_input_check.js /tmp/mobile-auto /tmp/mobile-hybrid
node tools/test/gamepad_check.js /tmp/mobile-auto /tmp/mobile-gamepad
node tools/test/quick_check.js origin/main
node tools/test/weapons_check.js /tmp/mobile-auto
node tools/test/bot_battle.js /tmp/mobile-auto city,wide,mesa,dock 150
```

専用検査はCDPのタッチ接触を使い、ダブルタップ・単タップ・ドラッグ・複数の視点指・3接点・メニューの選択と取消を確認する。ゲーム内の実レイ・射撃・近接経路で敵/味方/死亡/遮蔽・充填取消・近接射程とクールダウンを検査する。従来の `touch_check.js` は常時表示の射撃ボタンと押し離し式武器メニューを前提とするため、そのままでは新UIに適用できない。期待値を緩めず専用検査を追加する。

画面画像は停止した実ゲーム描画と実DOMを合成したもの。ヘッドレスの停止RAFでcanvas合成が黒くなる問題を避けるため、検査だけで実際のWebGLフレームを画像として同じ場所に固定する。製品コードにはこの処理を入れない。実機の指の感触、iOS Safari、実端末性能、非ゼロsafe-areaの実機挙動は未検証。CSSではsafe-areaを考慮する。

## このローカル試作の結果

- 最終専用検査：45項目成功。実タッチ接触、手動モード、単発銃の間隔・弾切れ、PCマウスの射撃・解除も確認。
- ハイブリッド入力：22項目成功。実キー・マウス、CDPタッチ、互換マウス、保持キーの切替・リピート、入力欄、メニュー、blur、主ポインタがマウスのタッチ画面を確認。ブラウザシミュレーションであり実Bluetooth機器検査ではない。
- ゲームパッド：47項目成功（キーボードWを含む）。
- quick_check：成功。武器・パーツ定義に差分なし。
- 全武器実射：エラーなし。
- BOT戦：city 152秒、wide 151秒、mesa 154秒、dock 65秒でコア破壊・正常試合終了。全マップでエラーなし。dockは150秒完走ではない。
- 広範囲検査後の最終タッチ専用修正（メニュー取消・中立対象・武器ボタンの旧循環処理除去など）は専用45項目で再検証。外付け入力の切替追加後にも専用45項目・ハイブリッド22項目・ゲームパッド47項目を再検証。共通の射撃・移動計算を変更していないため、広範囲検査は繰り返していない。
- 旧touch_checkは新UIで非表示となる射撃ボタンの保持テストで停止。新仕様の失敗を成功扱いしたのではなく、旧UI前提の非適用として記録。新UI・手動モードは専用検査で確認。

公開push・PR・マージ・デプロイは未実施。Libraryには既知の401があるため保存していない。成果物はタスク内のローカルZIP・パッチ・画像で渡す。
