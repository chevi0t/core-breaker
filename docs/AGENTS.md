# AGENTS.md（AIエージェント向け）

このフォルダは、ボーダーブレイクの遊びを再現するファンメイド試作「コアブレイカー」です。
作業を始める前に `DESIGN.md` を読んでください。コードの構成、データの約束事、数値の出典、ユーザーが決めた設計方針が書いてあります。

## 要点

- ゲームは `index.html` の1ファイル（HTML・CSS・JavaScript、three.js r128）。ビルド不要で、編集して再読み込みすれば動く。
- 会話・コメント・画面の文言は日本語。コードのコメントは今の密度と書き方に合わせる。
- 武器の数値は `WEAPONS`、兵装の組み合わせは `CLASSES`（4枠）、Botの装備の使い方は `botAct`、移動は `physics` の上の定数、ロックオンは `LOCK_*` 定数。

## 変えてはいけないこと（ユーザーの決定。変えるなら先にユーザーに確認）

1. ロックオンで弾を照準の中心へ補正しない。
2. コアの傘はただの障害物（距離などのダメージ規則を足さない）。
3. リペアポッド使用中は撃てず、ダッシュもジャンプもできない。
4. 兵装ごとの武器の種類（主武器・副武器・補助装備・特別装備の4枠。強襲：アサルトライフル・グレネード・ソード・加速装置、重火力：ガトリング・ロケットランチャー・弱化グレネード・重砲、遊撃：二丁拳銃・狙撃銃・偵察機・光学迷彩、支援：ショットガン・地雷・索敵センサー・リペアユニット）。
5. 公式の素材・名称・ロゴ・音を使わない。効果音は Openverse の CC0 か CC BY の音だけを使い、出典を `sounds/CREDITS.md`（zipでは SOUND-CREDITS.md）に書く。
6. Botもプレイヤーと同じルールで動かす。

## 変更したら

- ブラウザで開き、コンソールにエラーが出ないことを確かめる（確かめ方は `DESIGN.md` の第8章）。
- 数値をwikiから取ったら、定義の横のコメントに元の武器名と値を書く。
- 仕様が変わったら `DESIGN.md` の該当する表も直す。
