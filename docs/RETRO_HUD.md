# レトロ・ミリタリーHUD

オプションの「コンソール」から選択、試合中はF2で巡回。既存4種類を保持し5番目へ追加。初期値は標準のまま。既存 coreBreakerConsole に retro を保存する。装備・機体・試合の保存形式は変更しない。

参考の琥珀色CRT計器をCSS/SVGで表現。参考画像・背景・機体の画像はゲームへ埋め込まない。走査線はパネル内の静的CSSのみ。2026-11-03の改修で中央に琥珀色の三角計器を追加し、作動中SPは連続明滅、ブーストは実噴射の開始時だけ一度明滅させる。動きを減らす設定では明滅しない。警告は既存規則。

- 上中央：既存コア/戦力値、試合時間、プラント。
- 右上：既存ミニマップ・被索敵通知。
- 左下：実際の総耐久・ブースト・SP。SVGは装飾シルエットで、部位ダメージ表示なし。
- 右下：既存武器名、残弾/予備、4枠の選択。既存mechanicalWeaponStateを利用する状態バー（充填、再装填、SP）。充填中のバーは充填率を表示。
- 中央は共通の三角ゲージ。左斜辺に残弾、右斜辺に耐久、底辺にブーストとSP。琥珀色のプレロックと赤い三方向の捕捉線を使用する。捕捉範囲の円とロックの判定・追従は維持。
- タッチ操作時は既存と同じ標準コンソールへ一時切替。保存したretro選択は維持し、キーマウ等へ戻ると復元。タッチ版の専用レトロ配置は今回未実装。
