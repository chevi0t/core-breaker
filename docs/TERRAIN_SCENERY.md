# 風裂山道：工場・住宅・岩と8対8

ユーザーの添付図の**手書きA（右側2か所）**を工場、**手書きB（中央左）**を住宅地と解釈した。プラントの印字A/Bを指す配置ではない。公式素材は使用していない。

- 工場2棟：XZ=(112,-67.5)、(112,54)。28×30mの工場棟、平屋根、換気塔3本、煙突。通り抜け室内は作らず、地形へ埋めた基礎を含む遮蔽物として置く。
- 住宅4棟：(-92,-37.5)、(-56,-37.5)、(-92,-4.5)、(-56,-4.5)。12×13.5m、切妻屋根。山腹の主通路を両列の間に残す。窓は既存の描画を再利用し、室内は設けない。
- 岩6か所：(-38,57)、(28,97.5)、(-35,-52.5)、(35,-97.5)、(105,127.5)、(-108,-135)。幅・奥行約6m、中心の地面から高さ4.3〜5m。角張った低ポリゴン形状で、描画と衝突に同じ三角形を使う。
- 推奨／初期人数は8対8。新規ページで通常出撃し、青8体（プレイヤー1体＋BOT7体）・赤BOT8体を確認。時間は従来の5分。

共通レシピの `props` は `{kind:'factory'|'house'|'rock', at:[x,z], size:[width,depth,height]}`。最大24個、外周内・有限の寸法を検査。レシピ座標に `lengthScale` を適用するため、この山岳ではZと奥行が1.5倍。`team` は5/8/10、未指定は従来の5。建物の体積と屋根・岩の三角形は既存の都市地形形式へまとめ、ゲーム本体の描画・物理コードを追加変更しない。歩行navは建物・岩の占有範囲を避ける。屋根上のBOT経路は生成しない。配置後の最短経路検査で重量機が橋／坑口の縁へ寄り過ぎる例を検出したため、橋の床厚と機体の頭上空間の重なりをnav生成から除き、坑口上層の縁は内側へ迂回させる。プレイヤーを止める不可視壁は追加しない。拡張後も固定48mの再出撃位置を元の地形座標へ戻して検査するよう補正した。

地形本体の支持面は維持。屋根・岩の追加三角形150、体積18個を追加（従来防壁等18個と計36個）。通常BOT数は10→16へ増えるためCPU負荷も増える。実GPU／スマホ性能の同等性は未測定。

## 確認

- 画像3枚を実ゲームで撮影して確認。工場2・住宅4・岩6の存在と12地点の遮蔽射線、プレイヤー込み8対8を検査。
- 主要往復28本＋支持面・天井・射線・カメラ等11項目、ゲート砲台・門下通行・壁越え／退出31項目が通過。
- 約190mの射出は維持。4基×中心／周囲8点の36射出、着地点の歩行nav接続を確認。
- 基地／再出撃からプラントへの距離24組、重量二脚／重量ホバーの実歩行12本を再確認。地形・プラント位置は変更しないが、新しい遮蔽の対人バランスは未評価。
- 3レシピ×3seed、14不正入力の拒否。16機で通常BOT戦60秒以上、ブラウザエラーなし。
- 全域の穴検査はユーザー指定で追加していない。新しい建物の全方位・全機体での厳密検査ではない。

## 採用・復元

ユーザーの採用指示により、白煙循環区（配置違いを含む）を風裂山道8対8へ入れ替える。元データは `mapdesign/archive/circulation.js` に保存。生成対象は `prototype/maps/*.js` のみ。旧IDを保存していた端末は既存の初期マップへのフォールバックを使用する。既存の都市型マップ除外条件を維持するため、風裂山道はPC向け。

PR #110でレビューし、ユーザーの明示承認「マージとサイト反映もやっちゃって」に従って公開する。承認前のローカルレビュー資料に記録した公開保留はこの指示で解消された。mainの戻り先は `b0cb421d66017b0977324b13a1293c47bacb6daa`、公開版の戻り先は `900f32a`。Pagesはgh-pages直下の配信で、mainのマージだけでは更新されない。マージ済みmainを既存の `build_pages.py` で生成し、Pages検査・配信ファイル照合を行う。

既存の検証証跡に加え、公開前に最新mainとの差分quick_check、通常HTML出撃、旧マップ保存値からの起動、配置違いの除外、8対8、山岳射出8軌道／18操作ケースを確認する。ローカル検査は実GPU性能や対人バランスの保証ではない。
