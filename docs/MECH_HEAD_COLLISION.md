# 外装改修の頭部被弾判定確認

基準main `05d40f8607c31db2875fb1773e5fd8c0c0c04139` と採用モデル `a4eed76` を比較。30型すべてで旧被弾頂点・境界・装甲値が一致し、直立・歩行・屈み・空中・ダッシュ・照準の6姿勢でもレイ距離と頭部行列が1e-5単位で一致した。各版3,793,920本を検査。頭部スロットへの命中をヘッドショットとする処理、倍率、武器定義は変更していない。

軽量級は従来から小さい。今回の表示改修による被弾対象の縮小はない。一方、表示と従来判定は一致しない。見える外装の外で当たる部分と、外装が見えていても頭部判定のない部分がある。外観の小ささを、そのまま被弾面積や命中率とは扱えない。バランス変更としての判定調整は行わない。

## 再実行

`MECH_REWORK.md` に従い旧版と新版のデバッグコピーを生成し、次を実行する。

```sh
node tools/test/mech_head_collision_check.js /tmp/mech-before /tmp/mech-after /tmp/head-collision.json
```

JSONに全30型の旧・新境界寸法、三方向投影、各姿勢のハッシュを保存する。実際に登録される頭部raycastと描画メッシュの直接raycastを分けて計測する。保守的な部位境界による判定省略は `mech_hit_bounds_check.js`、他部位・混成・残像の互換性は `mech_rework_check.js` で別途検証する。
