# コアブレイカー 設計書（試作 v0.17）

ボーダーブレイク（SEGA、2023年サービス終了）の遊びをPCで再現するファンメイド試作の設計書です。
人間の開発者と、Claude・Codex などのAIがこのファイルを読んでゲームを改造できるように書いています。
公式の素材・名称・ロゴは使いません。数値の多くは有志wikiの値を参考にした仮置きです。

## 1. ファイル構成と動かし方

| ファイル | 中身 |
|---|---|
| `index.html` | ゲーム本体。HTML・CSS・JavaScriptが1ファイルにまとまっている。ビルド不要 |
| `three.min.js` | three.js r128（MITライセンス）。配布zipでは同梱、開発版はCDNから読む |
| `sounds.js` | 効果音のデータ（`window.SOUND_DATA`）。`tools/build_sounds.py` が作る。無くても無音で動く |
| `maps.js` | マップのデータ（`window.MAP_DATA`）。`tools/build_maps.py` が `prototype/maps/*.js` から作る。無いと遊べない |
| `MAPS.md` | マップの書き方と今あるマップの詳細（開発版では `prototype/maps/README.md`） |
| `music.js` | 戦闘中BGMのデータ（`window.MUSIC_DATA`）。`tools/build_sounds.py --music` が作る。無くてもBGMが鳴らないだけ |
| `SOUND-CREDITS.md` | 効果音とBGMの出典とライセンス（開発版では `sounds/CREDITS.md`） |
| `DESIGN.md` | この設計書 |
| `AGENTS.md` / `CLAUDE.md` | AIエージェント向けの作業ルール（CLAUDE.md は AGENTS.md を読み込むだけ） |
| `README.txt` | 遊ぶ人向けの説明 |

- 遊ぶ：`index.html` をブラウザで開く。マウスが固定されないときは `python -m http.server 8000` を実行して `http://localhost:8000` を開く。
- 改造する：`index.html` を直接編集してブラウザを再読み込みするだけ。

## 2. ゲームの骨組み

- 人数と試合時間はマップで決まる（`MAPS`）。台地演習場は5対5・5分、広域演習場は10対10・10分（v0.10）。プレイヤー＋味方Bot 対 敵Bot。敵コアの耐久（9000）を0にするか、時間切れ時に残りが多い側の勝ち。
- 三人称視点。機体の耐久は全員10000（wikiと同じく兵装による差はない）。
- 座標：単位はメートル。y が高さ。自軍（B、青）のベースは +z 側、敵軍（R、橙）は -z 側。マップは中心 (0, 0) をはさんで点対称で、大きさとベースの位置はマップごと（台地演習場は x ±135・z ±240・ベース z=±210、広域演習場は x ±180・z ±300・ベース z=±265）。丘・高台・坂・谷の高低差がある（第4章「マップと地形」）。
- 向き：`yaw = 0` で -z 方向（敵ベース方向）を向く。`fwdOf(u)` が前方ベクトル。

### 毎フレームの更新順（`loop`）

0. 戦闘中BGM（`bgmTick`：試合中でスイッチがオンなら鳴らし、そうでなければ止める）。
1. 各機体：行動不能なら `downTick`、大破していれば再出撃待ち、生きていればエリア移動の待機を数えてから（待ち終わると `doTransfer`）`playerUpdate` か `botUpdate`（移動→照準→武器）。行動不能とエリア移動は v0.17。
2. プラント → 戦況アナウンス（`annTick`：残り時間・コアの残り・ベース侵入。v0.15）→ 指示出しの印と返事（`qchatTick`。v0.17）→ スコア（`scoreTick`）→ 防衛砲台 → レーダー → 砲弾・ロケット・投げる物 → 設置物と偵察機（`gadgetUpdate`）→ リペアポッド（`repairing` を毎フレーム作り直す）→ カタパルト。
3. 勝敗判定、見た目の同期（機体の位置、ブースター炎、銃身の形、リペアの光線）、演出、カメラ、HUD。

固定の時間刻みにしたい試験では、`loop` 冒頭の `const dt = Math.min(0.05, ...)` を `const dt = 0.05` に置き換える（第8章）。

## 3. データの約束事

### 当たり判定の持ち主

- 弾が当たるメッシュは `hittables` 配列に入れ、`mesh.userData.ref` に持ち主のオブジェクトを入れる。
- 持ち主の `kind`：`'unit'`（機体）、`'turret'`（防衛砲台）、`'barricade'`、`'core'`、`'umbrella'`（傘。弾を止めるだけ）、設置物の `'mine'`・`'sensor'`（`gadget: true`。`damage` は `damageGadget` へ回す）。`ref` がないメッシュは障害物や柱。
- 地面は `hittables` に入れない。`castFrom` が `terrainHit` で地形との交差を先に求め、レイの長さをそこで打ち切る（戻り値の `ref` は `null`）。
- 移動を止める箱は `obstacles` 配列に `{ minX, maxX, minZ, maxZ, top }` で入れる。`top` より上には乗れる。

### 機体（`makeUnit` が作るオブジェクト）

| フィールド | 意味 |
|---|---|
| `team` / `isPlayer` / `name` | 'B' か 'R'、プレイヤーか、表示名 |
| `pos` / `vel` / `yaw` / `pitch` | 位置、速度、向き |
| `hp` / `maxHp` / `alive` / `respawnT` | 耐久、大破してから再出撃までの秒数（5秒）。行動不能の間も `alive` は false |
| `downT` / `downBy` / `downYaw` / `reviveAcc` / `downPing` | 行動不能の残り秒（0なら倒れていない）、倒した相手、倒れた向き、受けた修理量（`REVIVE_NEED` で起き上がる）、「救援をたのむ」の印（v0.17） |
| `transfer` / `xferCd` | エリア移動の待機 `{ t：残り秒, base：自軍ベースの中で始めた, at：Botの移動先 }`、Botが次に使えるようになる時刻（v0.17） |
| `order` | 味方からの指示 `{ kind：'go'・'hold'・'cover', pos, by：送った機体, until：終わる時刻 }`（v0.17、Botだけ） |
| `invulT` | 出撃直後の無敵の残り秒（`SPAWN_INVUL` 2秒、ユーザー指定 v0.9.2）。この間は `damage` と `blast` を受けず、機体が点滅する |

| `slots` / `weapon` / `switchT` | `{ main, sub, aux, sp }`（主武器・副武器・補助装備・特別装備）の武器スロット、選んでいる枠、持ち替えの残り時間 |

| `chargerOn` / `charging` | 加速装置を作動させているか、加速装置で進んでいるか |
| `cloak` / `cloakT` / `vis` / `shimmer` | 光学迷彩で消えているか、消えてからの秒、見えやすさ（1で普通、0で完全に消える）、揺らぎの強さ（0〜1） |

| `act` / `actCd` | Botが補助装備・特別装備を使っている最中の行動（`{ slot, aim, t, done }`）、次に考えるまでの秒 |
| `swing` / `lungeT` / `recoverT` | ソードの振りの状態（`{ a, t, yaw0, phi, hit, aimed（敵へ誘導している振り）, tgt（踏み込みで追う敵） }`）、踏み込みの残り時間（回転斬りと横なぎ）、回転斬り後の硬直の残り時間 |
| `stun` / `stunT` / `tilt` | 崩れている状態（''・'stagger' よろけ・'down' ダウン・'roll' 受け身・'land' 着地硬直）と残り秒、見た目の傾き |

| `mech` / `stats` | パーツの型 `{ head, body, arms, legs, color }`（プレイヤーは `mechCfg` の写し、Botは試合ごとに `botMech`）、`mechStats` の結果（出撃のたびに `equip` が武器の重量込みで作り直す） |

### 武器スロット（`slotOf` が作る）

`{ w（WEAPONSの定義）, ammo（マガジン内）, reserve（予備の弾数）, reloadT, cd（次弾までの時間）, spin（ガトリングの回転 0〜1）, temp（ガトリングの熱 0〜100）, ohT（オーバーヒートの残り）, conv（狙撃銃の照準の収束 0〜1）, heat（特別装備のSPゲージ 0〜100）, overheat（SPを使い切って満タンまで使えない）, bn（3点射の残り発数）, held（単発の武器で引き金を押したまま） }`

### 武器の定義（`WEAPONS`）

| キー | 使う武器 | 意味 |
|---|---|---|
| `type` | 全部 | `'gun'`（銃・ロケット・投げる物・偵察機）・`'sword'`・`'repair'`・`'charger'`（加速装置）・`'cannon'`（重砲）・`'camo'`（光学迷彩）・`'field'`（リペアフィールド） |
| `name` / `desc` | 全部 | 画面に出す名前（オリジナル）と、機体カスタマイズのシリーズの説明 |
| `series` / `model` / `maker` / `label` / `kg` | 全部 | 起動時に入る（v0.13）：シリーズのキー（`SERIES`）、型番（例 `SR-7`）、メーカー（`MAKERS`）、型の名前（例「持続型」。1つしか型の無いシリーズは空）、重量（`WEAPON_KG`） |
| `burst` / `gap` | 3点射の銃 | 1回で撃つ発数と、次の組までの秒（引き金を離しても組の残りは撃つ） |

### ロックオン（`lockUpdate`）

- 50m以内（`LOCK_RANGE`、ユーザー指定）の敵機・敵砲台を照準中央の円（`ACQ_R`）に0.15秒入れると自動でロック。外側の円（`KEEP_R` 0.42）から外れるか、0.6秒見えないと解除。Qで切り替え。
- v0.10.2（ユーザー指定）：ロック中は画角を1.3分の1（`LOCK_ZOOM`、70度→約54度）にして目標を大きく見せる。マウスの感度も画角に合わせて細かくなる。ズームで画面上のずれが大きく見えても外れる角度が変わらないよう、`KEEP_R` を画角に合わせて広げる（`keepScale`）。そのうえで「外れやすければもうちょい外れにくく」の指示により `KEEP_R` を0.34から0.42へ（動き回る強襲Bot相手の20〜40mで、ロックが続く時間が平均約2.2秒から約3.6秒に）。ショートダッシュで振り切れる仕組みは変えていない。
- **弾は照準どおりに飛ぶ（中心へは補正しない）。** ロック中は、目標が動いた角度だけ視点が追う（`LOCK_TRACK` 1.0、1秒に最大 `LOCK_MAX_RATE` 4ラジアン）。相手がショートダッシュ中は35%（`LOCK_TRACK_SHAKEN`）に落ちる。
- v0.9.1（ユーザー指定で強めた）：照準が機体（`LOCK_BODY`：横に±1m、足元から0.4〜3.9m）から外れていたら、機体の端まで毎秒0.8ラジアン（`LOCK_PULL`）で引き戻す（`lockStick`）。中心へは寄せないので、頭に置いた照準は頭のまま。相手のショートダッシュ中は引き戻さない。
- v0.15（ユーザー指摘「全体的に地面が平面だから横エイムだけでヘッドショット入っちゃう」）：上に外れたときは頭のてっぺん（3.9m）ではなく肩（`LOCK_BODY.top` 3.1m）まで下ろす（`lock.down` の間は頭の高さでも止めない）。カメラの高さ（`CAM.up` 4.6m）が頭（3.2〜3.95m）より上なので、それまでは平らな所で水平に構えるだけで照準が頭のてっぺんに吸い付いていた（20〜35mで確かめた：v0.14は頭の3.91m、v0.15は胴の3.15m）。下ろし終わった後に自分で頭に置けば頭を追い続ける。地形の起伏はマップ製作のスレッドへ回した。
- 狙撃銃を持っている間はロックしない（wiki）。
- v0.11.2（ユーザー指定）：索敵を受けている敵機（`spotted` に入っている）は `SPOT_LOCK`（1.5倍、仮）遠くからロックできる（プレイヤーは75m）。Botも気づく距離（70m）が1.5倍の105mになる。
- 光学迷彩で消えている敵はロックできない。ロック中に消えたら1秒後に外れる（wiki）。
- Botと防衛砲台の照準も同じ考え方（`trackAim`）：目標の動きを85%だけ追い、ずれが `BOT_LOCK_BREAK` を超えると0.7秒撃てない。光学迷彩の相手はロックできないので、追う割合はショートダッシュ中と同じ35%。

### よろけ・ダウン・着地硬直（`jolt`、`land`、`physics`。ユーザー指定、数値は wiki PS4版）

| 定数 | 値 | 意味 |
|---|---|---|
| `STAGGER_DMG` / `DOWN_DMG` | 3500 / 7000 | 射撃と爆発で、1回の攻撃のダメージがこれ以上ならよろけ・ダウン（wiki） |
| `STAGGER_MELEE` / `DOWN_MELEE` | 3000 / 6000 | 格闘（ソード）のよろけ・ダウン（wiki） |
| `STAGGER_TIME` / `STAGGER_PUSH` | 0.65秒 / 9 m/s | よろけで操作できない時間（wiki）、押される速さ（約2m） |
| `DOWN_PUSH` / `DOWN_UP` / `DOWN_LIE` | 14 m/s / 12 m/s / 1.2秒 | ダウンで吹き飛ぶ速さ（約10m、0.65秒）、倒れている時間（wikiに秒数なし、仮置き） |
| `UKEMI_COST` | 32 | 受け身のブースト消費（wikiは「大量」とだけ。仮置きの40の8割） |
| `LAND_SPEED` / `LAND_TIME` | 28 m/s / 0.5〜1秒 | これより速く着地すると着地硬直（約12mの落下）、その長さ（速いほど長い。仮置き） |

- 1回の攻撃：散弾と二丁拳銃は1回の射撃で当たった分の合計（`volley`）、爆風は1つずつ、ソードは1振り。弱化グレネードの倍率とヘッドショットを含めた実際のダメージで判定する。撃破したときは起きない。
- よろけ：0.65秒、移動・ダッシュ・ジャンプ・武器が使えず、攻撃の反対（爆心か撃った機体の反対）へ押される。重砲や偵察機で屈んでいれば押されない（wiki）。続けて当たるとまたよろける。
- ダウン：後ろへ吹き飛んで倒れ、1.2秒たつと起き上がる。重砲などの構えは解ける。ダウン中によろけは起きないが、もう一度ダウンはする。無敵時間はない（wiki）。吹き飛んでいる間に Space と Shift を同時に押すとブーストを32使って受け身を取り、着地したら動ける。Botは4割で受け身を取る。
- 崩れている間は振っているソードも止まる。リペアポッドを使っている間と、カタパルトで操作できない間は崩れない（wiki）。
- 着地硬直：着地したときの落ちる速さが28 m/sを超えると（約12mの落下。普通のジャンプ（約4.3m）と、高台の崖（10m）を降りるだけなら出ない）、その場で屈んで動けない（撃つことはできる）。着地の直前0.3秒以内にSpaceを押すか、滞空で降下を緩めれば出ない（wiki：着地直前のジャンプで消せる）。カタパルトの着地でも出る。Botは6割で消す。
- 見た目：よろけはのけぞり、ダウンは後ろへ倒れる（`tilt`、機体の向きのあとに傾けるため `group.rotation.order = 'YXZ'`）。着地硬直は屈む。自機は画面中央に状態を出す。
- このため、ソードの横なぎ（6000、格闘のダウン6000以上）は当たるとダウンを取り、ショットガンは近くで当てるとよろけ（ヘッドショットが混じると7000を超えてダウン）、ロケットの直撃・地雷・狙撃銃のヘッドショット（9000）はダウン、狙撃銃の胴体（3600）はよろけになる。

### ダメージ（`fire`、`damage`、`blast`）

- ヘッドショット（頭部の形に当たったとき。v0.12から。それまでは機体の足元から3.3mより上）は `HEADSHOT_MULT` 1.3倍（ユーザーの仮置き）。狙撃銃だけ武器の `head` 2.5倍（wikiのクリティカル倍率）。
- ヘッドショットの命中はボディより派手に見せて鳴らす（v0.9.5、ユーザー指定）：着弾は白い芯と大きな金色の光、広がる金色の輪（`ringTex`）、倍の数（16本）の速い火花。撃った本人には照準に金色の×が広がり「HEADSHOT」の文字が出て、命中音の代わりに `headshot`（slash を高く）と `headping`（beep を高く）を重ねて鳴らす（`impact`、`hitMark`）。
- 機体が撃破されると、その陣営のコアが最大値の1/160（`KILL_CORE`、56.25）減る（元のゲームの仕様。ユーザー指定）。
- コスト制（v0.10.9、マップの `vs: { cost, death }`。ユーザーが選んだ、港の倉庫街）：`VS` と `coreMax` が立つと、`buildCores` は撃てる物を作らずゲージだけの `cores` を置き、防衛砲台・レーダー（ベースの境目の線も）・傘を作らない。上のゲージは両軍の戦力（`coreMax` = cost）で、撃破1回で death 減る。0以下で負け、時間切れは残りの多い側の勝ち（コアと同じ判定）。再出撃はいつもベース側の出撃地点で、残りが death より少ないと耐久が 残り/death 倍（コストオーバー）。ベース侵入・ベース防衛・BRAVE（プラントの無いマップ）の加点は無し。Botは気づいている一番近い敵機へ向かい、見えていない間は止まらずに回り込む。
- コアでダメージが入るのは上の色の付いた結晶（`core.glow`、中心の高さ19m）だけ。黒い支柱と台座は弾を止めるが無敵（v0.10.6、ユーザー指定）。結晶は横に広い八面体（v0.10.7、ユーザー指定「コアもっと大きく」：横の半径8.5m・縦4.2m）で、支柱（上の半径5m）より外へ張り出すので、傘の下の近くからは張り出した下面を撃つ（中心を狙うと支柱に当たる）。`core.pos` は結晶の中心。攻撃役のBotはコアの前12mに立ち、`coreAim`（中心から自分の方へ水平に6m・1m下の下面）を狙う。
- コアへのダメージは機体への威力の1割（`CORE_RATE`）。ロケットはコアに直撃したときだけ効く。ソードはコアに当たらない（wiki）。
- 爆風は爆心で最大、半径の端で半分。敵機・敵砲台・バリケード・敵の設置物に効く。
- 狙撃銃（`scope` のある銃）の弾道には白い煙の筋が0.4秒残る（`smokeTrail`、`SMOKE_LIFE`。v0.14、ユーザー指定）。25mごとに区切り、カメラから遠い所ほど太くして見えるようにし、少し太りながら薄れる。
- 自分の爆発物の爆風は自分にも効く（v0.11.3、ユーザー指定「グレネードのゼロ距離射撃が強すぎる」）。ダメージのある爆風だけで、衝撃グレネードと弱化グレネードは自分に効かない。味方には v0.13.1 からダメージは無いが、よろけ・ダウン（押される勢いも）は、あったはずのダメージで判定する（衝撃グレネードも味方を倒す。弱化グレネードは味方に効かない）。味方へのあったはずのダメージは撃った機体ごとに数え（`friendlyFire`、`ffDmg`）、1万（`FF_STEP`）ごとに戦闘のスコア −10（`FF_PENALTY`。照準の右下に赤で「−10 味方への誤射」）。ユーザー指定。自分の爆風で倒れるとキルログに「自爆」と出て、撃破された扱い（コアが減る。撃破のスコアは誰にも入らない）。自爆は誤射とは別に、1回ごとに戦闘のスコア −10（`SC.selfKill`。「−10 自爆」。v0.14、ユーザー指定）。Botは自分を巻き込まないよう、ロケットは16mより遠い敵だけ、手榴弾は爆風の半径+4m（最低15m）より遠い敵だけに使い、遠隔爆弾は自分が爆風の半径+2mより離れているときだけ起爆する。
- 機体へのダメージは `armorMult(u, 部位)` 倍（v0.12）：当たった部位（形の `userData.armorSlot`。`castFrom` が `slot` で返す）のパーツの装甲（`PARTS[部位][型].armor`、wiki の被ダメージ倍率）×弱化グレネードの1.4倍。爆風・ソードなど部位の無いダメージは4部位の平均（`armorAvg`）。手に持った武器の形は腕、背中の装置と重砲は胴に数える。

### ソードの当たり判定（`swordTick`、`bladeSweep`、`bladeHits`。ユーザー指定）

- 刃は実際に振る。毎フレーム、前のフレームの刃の角度から今の角度までの扇形（中心は機体、半径 `BLADE_IN` 1.4m〜`reach` 4.8m、高さは足元から `height`）を求め、そこにかかった相手（機体は半径1.3m・高さ4m）に1回だけ当たる。
- 横なぎ：前方150度（左75度から右75度）を0.15秒で払う。刃の高さ2.6m。構え0.1秒、振り全体0.5秒。
- 回転斬り：ダッシュ中に振ると、0.6秒で前へ16m踏み込みながら2回転し、周りを斬る（1回転だと進路の右側の敵を取りこぼすため）。v0.9.3（ユーザー指定）で11mから16mに伸ばし、ブーストの残りに関係なく出せて消費もなく、踏み込んでいる間はブーストが毎秒50回復する。刃の高さ2.0m。回し終わると1秒その場で動けず、ダッシュもジャンプもできない（チャンスも隙も大きい）。
- 踏み込みの速さ（v0.13.1、ユーザー指摘「攻撃方向にスライドして伸びていかない」）：出だしが平均の1.35倍で、終わりは0.65倍まで落ちる（距離は同じ）。ダッシュ中の技は振り終わってもピタッと止まらず、`SLIDE_TIME` 0.6秒のあいだ止まり方をゆるくして（`SLIDE_DECEL` 4。普段の地上は10）勢いのまま滑る（ソードの回転斬りで踏み込み16m＋滑り約4m、スピアは22m＋約7m）。横なぎの踏み込みは普段どおり止まる。
- ロックオン誘導（`meleeHome`。v0.13、ユーザー指定「本家に寄せる」）：振り始めにロック中の敵（Botは狙っている敵）が踏み込みの届く所（`lunge` か `step`＋`reach`＋機体の半径）にいれば、その敵の方へ向かって振る。
  - 横なぎにも踏み込みが付く：敵が刃の6割の所に来るまで、最大 `step`（ソード4m・大剣3m・スピア4m）を振っている間（構え＋振り）に進む。0.3m未満なら踏み込まない。刃と機体の向きはその敵が基準（`aimed`。視点が少しずれていても敵を中心に払う）。
  - 踏み込んでいる間も、その敵の方へ毎秒 `homing` ラジアンまで曲がる（回転斬り・突進突き1.8（大剣1.5）、横なぎ6（大剣5））。目の前（機体2つぶん＋0.6m）まで来たら追うのをやめ、踏み込みの勢いのまま抜けていく（v0.13.1。v0.13 では止まっていた）。敵が横より後ろ（約100度）へ回ったら追わない。横へ逃げても曲がってくるので、回転斬りはジャンプで避ける。値は仮。
  - Botも同じ（狙っている敵へ誘導する）。Botがソードを振り始める距離は変えていない。
- ジャンプで足元が刃より0.3m以上高ければ当たらない。ジャンプ（最高約4.3m）なら回転斬りを避けられる。Botは近くで敵が回転斬りを始めると6割の確率でジャンプして避ける。
- 防衛砲台とバリケードにも当たる。コアには当たらない（wiki）。

### 操作の仕様（ユーザー指定）

- 武器の持ち替え：マウスのサイドボタン（戻る・進む）を押している間、画面中央に十字の武器選択が出る。マウスを上で主武器、右で副武器、下で補助装備、左で特別装備、離して決定。ホイール（順送り）と1〜4キーでも持ち替えられる。持ち替えは0.8秒（`SWITCH_TIME`）。リロードは持ち替えても続く。
- 投げる物（グレネード・弱化グレネード・地雷・センサー）：照準の所へ山なりに投げる。落ちる所に黄色の円（`aimMark`）が出る。届かないときは届く所まで。
- 加速装置：**選んだ時点で作動し、もう一度選ぶと止まる**（左クリック不要。v0.9.5、ユーザー指定）。持っている武器は持ち替えない。作動中はShiftを押し続けると、ロングダッシュの代わりにSPを使って向いている方へ進む（押した瞬間のショートダッシュはいつもどおり）。横の入力で少し曲がる。加速しながら撃てる（ユーザー指定）。SPを使い切ると止まる。
- 重砲：選ぶと構えて動けない。左クリックで撃つ。撃ち切るか右クリックで元の武器に戻る（SPが1発ぶん無いときも戻る）。
- 光学迷彩：**選んだ時点で姿を消し、もう一度選ぶと解除**（左クリック不要。v0.9.5、ユーザー指定）。持っている武器は持ち替えず、消えている間も使える。
- 光学迷彩・加速装置の作動と停止（`toggleSp`）：1〜4キー、サイドボタンの武器選択、ホイールのどれで選んでもよい。続けて切り替えられるのは0.5秒ごと。リペアポッドの上、よろけ・ダウン中は切り替えられない。ホイールでSPを選んだ次の回しはSPの隣（下へ回せば主武器）へ進む。作動中は、右下の武器一覧の特別装備の名前（「（作動中）」付き）と、左下のSPの文字・SPゲージが緑に光って0.7秒周期で点滅する（v0.9.6、ユーザー指定。`#wpn .act`、`#sp.act`）。
- 偵察機：選ぶと屈んで動けない。左クリックで打ち上げ、元の武器に戻る。
- ソード：止まっているか歩いているときは横なぎ、ダッシュ中（ショートでもロングでも）に左クリックで回転斬り。ロック中の敵がいれば、横なぎでも回転斬りでもその敵へ踏み込み、踏み込み中も追う（v0.13）。
- 狙撃銃：右クリックを押している間スコープ。止まっていると照準が収束する。覗かずに撃つと大きくばらつき（wiki「スコープを覗かずに…とんでもない方向に弾がスッ飛んでいく」）、HUDに「覗かないと大きくばらつく」と出る。
- リペアユニット：左クリックで照準の先の味方機と自軍の防衛砲台・レーダー、右クリックで自分を回復。ゲージを使い切ると満タンまで使えない。リペアポッドの上でも使え、ポッドと効果が重なる（v0.9.3、ユーザー指定。ポッドの上で自分に使うと毎秒約2300）。
- 兵装の選択：出撃前の画面と、撃破後の再出撃画面（Z・X・C・V）。v0.15（ユーザー指摘「不快度高い」）から撃破されてもマウスの固定を外さない。再出撃地点は数字キーかホイール（下で前線寄り）で選び、数え終わると自動で出撃する（クリックは要らない）。Esc などで固定が外れたときだけ「画面をクリックで操作に戻る」と出る。
- キルカメラ（v0.16、ユーザー指定「撃破されたら最初の半分は倒した相手をカメラで映す、後半は今と同じフリーカメラ」）：撃破されると、再出撃までの待ち（5秒）の前半（`KILLCAM` 0.5）は、撃破された場所の側から倒した相手（機体か防衛砲台）を12m離れて少し上から映す（`KC_DIST`、間に壁や地面があればその手前。相手は画面の上の方、`KC_LOOK`）。その間、再出撃の画面は下の端へ寄せ、一番上に相手の名前・兵装・残り耐久・距離と再出撃までの秒を出す（`#killcam`）。後半はそれまでと同じく自分の周りを見回すカメラで、倒した相手の方を向いて始まる。自爆では映さない。
- M で全体マップ（v0.15）：ミニマップと同じ物（地形・障害物・プラント・ベース・砲台・レーダー・ポッド・カタパルトの向き・味方と見えている敵・自機の向き）を画面の高さの8割で出す。もう一度 M で閉じる。地形はミニマップの3倍の細かさで、マップを替えると作り直す（`bigBg`）。v0.17 から、開いている間はマウスでマップの上のカーソル（自機の所から始まる）が動き、左クリックで「ここへ向かえ」、右クリックで「ここを守れ」をその地点に送る（視点は動かず撃てない。マウスの固定が外れているときはマップを直接クリック）。
- G 長押しで指示出し、H でエリア移動、行動不能の間は F ですぐ大破（v0.17。「指示出し・蘇生・エリア移動」の節）。

### マップ（`MAPS`、`buildMap`。v0.10でマップ選択を追加、v0.10.1でマップのデータを別ファイルに。ユーザー指定）

- マップのデータは `prototype/maps/<id>.js`（1ファイル1マップ）にあり、`python3 tools/build_maps.py` が中身を確かめて `maps.js` にまとめる。index.html は `maps.js` の `window.MAP_DATA` を読み、項目がそろったマップだけを `MAPS` に `order` 順で並べる（足りないマップは警告を出して外す。1つも無ければ「maps.js が読めない」と出して止まる）。
- **項目・座標・点対称・地形の種類の書き方、今あるマップ（台地演習場・広域演習場）の詳細、確かめ方は `prototype/maps/README.md`（配布zipでは `MAPS.md`）**。マップはマップ製作のスレッドが持ち、エンジン（index.html）は「ボーダーブレイクPC再現」スレッドが持つ。公開ページの `maps.js` はマップ製作のスレッドが出し、エンジン側の公開では `maps.js` を送らない（`prototype/maps/` には作りかけのマップがあり得るため）。配布zipは公開中の `maps.js` を取ってきて `python3 tools/build_zip.py <版> --maps <そのファイル>` で作る。
- 選んだマップは `localStorage` の `coreBreakerMap` に残り、次に開いたときもそのマップで始まる。無くなったマップIDなら最初のマップになる。
- 任意の項目（v0.10.3、マップ製作スレッドの依頼で「丘の市街地」のために足した。書き方の詳細は maps/README.md）：
  - `subtitle`：副題。マップ選択の名前が「名前 〜副題〜」になる。
  - `variants: { キー: { name, plants, plantPods, catapults, … } }`：配置違い。地形と `layout` は元のまま、書いた項目だけ上書きした版を、ID `マップID-キー`・名前「名前 〜name〜」・`order` は元の直後で `MAPS` に並べる。
  - `layout` の6番目の要素：建物の種類 `'house'`（切妻屋根・窓。壁と屋根の色は自軍側の座標のハッシュで決まり、点対称の建物は同じ色）、`'wall'`（石壁）、`'tower'`（石の塔、細い窓と胸壁）。当たり判定は箱のまま、屋根と胸壁は見た目だけ。模様は3m（`CELL`）ごとに繰り返す（`tileUV`）。屋根は色ごとに1つのメッシュにまとめる。
  - `bridges: [[x, z, 幅, 奥行き, 上面の高さ, 厚さ], …]`：layout と同じく中心と大きさで、点対称に足す。上面の高さは海抜。地面に埋めず、上面から厚さぶんの板にする。障害物に `bottom`（上面 − 厚さ）を持たせ、`resolve` は頭が `bottom` より下ならくぐれるとして押し出さない。`groundAt` で床に立てる。下でジャンプすると `ceilingAt` で頭が床の底に当たって止まる。カメラも床の下に収める。弾と視線は床に当たる。
  - `water: [[x, z, 横の半分, 奥行きの半分, 高さ], …]`：半透明の水面。見た目だけ（当たり判定なし）。ミニマップと見取り図では青。
  - `nav: { nodes: [[x, z] または [x, z, y], …], links: [[i, j], …] }`：Botの通り道。自軍側の半分を書き、点対称に足す（`'~3'` は3番の点対称の節点、原点の節点は1つ）。節点の3番目 y は歩く高さ（海抜）で、橋の床の上の節点に書く（省くと地面の高さ）。Botは目標までまっすぐ歩けない（`clearPath`：登れない段差と障害物の箱を0.5mごと〔v0.10.9 まで2mごとで短い急な崖を見落としていた〕に見る。歩いて乗れる橋の床は地面に数え、箱はその区間の足元より0.6m以上高い時だけ塞ぐので、上を歩く橋の下の橋脚は普通の箱でよい。v0.10.4）と、自分から見通せる近い節点と、目標を見通せる近い節点（どちらも近い順に6個まで調べる）を結ぶ最短路（ダイクストラ法）をたどる。リンクの長さには機体ごとの1〜1.4倍のばらつき（`navW`）を出撃ごとに掛け、迂回路も使う。節点に5m以内で着いたら次へ、次の節点が見通せて近ければ飛ばし、目標が見通せたら残りを飛ばす。5秒ごとか目標が15m動いたら引き直す。v0.10.9（ユーザー指摘の崖づまり）：通り道に入る節点は `navEntry` が選び、近くの節点へまっすぐ歩けなければ周り（8・16・28m、12方向）の経由点 `navVia` を先に通る。向かう節点へ歩けなくなったら（0.5秒ごとに確かめる）と、詰まって横へ逃げた後は引き直す。nav の無いマップでは目標（120m以内）へまっすぐ歩けないときだけ `detour` が同じように経由点を探す。
- `stepTo` は1回に0.5mずつ進める（v0.10.3）。ショートダッシュやカタパルトの速さだと1コマで2m以上進み、厚さ2mの壁を通り抜けていた。
- Bot：10機の兵装は `BOT_CLASS`（強襲3・重火力3・遊撃2・支援2）、役割は `BOT_ROLE`（攻め4・プラント4・守り2）。プラント役は、プラントが4つ以上あるマップでは、まだ自軍のものでないプラントのうち自軍ベースに近い1つ目と2つ目に分かれて向かう。1陣営は10機まで（11機以上はエンジンの変更が要る）。

#### 共通

- 高さは |z| が `baseLine` から25mの間で0に近づき、ベースの周りは平ら。
- 高さはマップを作るときに1m格子へ焼き（`bakeTerrain` → `heights`）、`terrainH(x, z)` が補間して返す。地面のメッシュは2m格子。
- 移動：`physics` は水平移動を `stepTo` で1軸ずつ試し、動いた距離の1.1倍より地面が高くなる所（約48°より急な斜面）へは進めない。下り坂では、接地していて落ちる速さがなければ地面に沿って歩く。
- 弾と視線：`terrainHit` がレイに沿って1.5mずつ進み、地面の下に入ったら二分探索で交点を詰める。丘や盛り土の向こうは撃てず、見えない。
- 施設・出撃地点・砲台の照準・砲弾の着地判定は `terrainH` を使う。プラントの範囲は水平16m以内かつプラントの地面から6m以内。

### 武器の形（`MODEL_OF`、`buildWeaponGeo`、`weaponLook`。v0.11.1）

- 形は Codex 版（ユーザーが v0.10.9 を Codex に渡して作ってもらった版）の weapon-models.js のオリジナルの形を移植したもの。外部の素材は使っていない。箱・円柱・球を組み合わせて頂点の色で塗り、1つの形にまとめる。同じ形は `weaponGeo` がキャッシュして共有する（捨てない）。
- `MODEL_OF[武器のキー] = [形の系統, 型（0・1・2）]`。型で差し色（`palette`）と細部が変わる。v0.14の型は元の武器の系統で、型を順に変える（`makeType` の後のループ）。spear・sonar・sentry・remote・fmine・field は本作で足した形。割り当てが無ければアサルトライフルの形。
- 機体：右手 `gun` に今の武器（ソードか重砲を選んでいる間は主武器）、二丁の武器は左手 `gun2` にも。ソードは左腕 `blade`（振っている間は形の長さから間合い `reach` まで伸ばす）。加速装置・光学迷彩・リペアフィールドは背中 `pack`。重砲は背中に畳み、選ぶと0.65秒（`CANNON_DEPLOY`）で右肩へ起こす（`cannonDeploy`。基部 `mount` は背中に残る）。
- 銃口（`muzzle`）は持っている形の先端。重砲は起こした砲身の先（`CANNON_TIP`）。
- 武器の形も当たり判定に入る（隠れている形は `castFrom` が飛ばす）。肩に起こした重砲に当たってもヘッドショットにならない。
- 投げる物は飛んでいる間も置いた後も武器の形（チームの色を半分混ぜた `toolMat`）。自動砲台は1.5倍（`SENTRY_SCALE`）で、砲身の先から撃ち、砲身の高さ（地面から1m）から見る。偵察機も形を1.4倍で使う。

### 機体パーツと重量（`PARTS`、`mechStats`。v0.12、Codex 版から）

- 頭・胴・腕・脚をそれぞれ軽量型・標準型・重装型から選ぶ（機体カスタマイズの「機体」タブ）。4つの兵装で共通で、`localStorage` の `coreBreakerMech` に残り、次の試合から使う。重量・装甲・脚の速さ・重量耐性は wiki PS4版の各部位の最初の型の強化前（軽量＝シュライクⅠ、標準＝クーガーⅠ、重装＝ヘヴィガードⅠ）。頭のロック距離と射撃補正、胴のブーストとSP、腕の反動吸収と携行弾数は Codex 版の補正。名前と形はオリジナル。
- 頭：ロック距離（60・50・40m。索敵を受けた敵は `SPOT_LOCK` 倍）、射撃補正（ばらつきを `aim` で割る）。胴：ブースト容量（120・100・80）、SP容量（80・100・120）、SPの戻る速さ（重装1.1倍）。腕：リロード時間（0.91・1・1.18倍）、持ち替え（`SWITCH_TIME` 0.8秒÷`swap`）、反動吸収、主武器・副武器の携行弾数（0.75・1・1.25倍、装填ぶんを含む）。脚：歩行・ダッシュ・巡航（wiki の m/s を、標準型がこれまでの `WALK`・`BURST`・`DASH` になる比で換える）、重量耐性（3700・4650・6450kg）。
- 重量：4部位と4つの武器（`WEAPON_KG`、wiki の強化前）の合計が脚の重量耐性を超えると、40kgごとに1%遅くなる（wiki「移動速度と重量超過」。上限100%、速さには下限）。初期装備・標準のパーツで、強襲4340kg・遊撃4630kgは超えず、重火力は780kg超過で約0.8倍、支援は250kg超過で約0.94倍。
- 反動（`recoilKick`、既定は `baseKick`）：撃つたびに銃が跳ね上がり（ラジアン）、毎秒0.04ずつ戻る。腕部の反動吸収で割り、上限は0.08÷反動吸収。重砲0.02、ロケット0.014、狙撃銃0.018、散弾0.014、二丁0.006、ガトリング0.002、ほかの銃0.004、投げる物と偵察機は0。プレイヤーは視点が上がり（ロック中は機体へ引き戻す）、Botは照準が上へずれる（`recoilAim`）。
- 塗装（`PAINTS`）：チームの色と5色。チームの色以外に塗っても細い帯にチームの色が残る。Botはいつもチームの色。
- Botの機体（`botMech`）：試合ごとに頭・胴・腕はランダム、脚はその兵装の初期装備で重量超過が300kg以下になる型からランダム（無ければ重装型）。
- 画面は v0.13 の3列（「シリーズと型、メーカー」の節）。兵装のボタンには重量超過を出す（`overNote`）。

### シリーズと型、メーカー（`SERIES`、`PART_SERIES`、`MAKERS`。v0.13、ユーザー決定）

方針は Claude Doc「武器・機体のバリエーションとカスタマイズ画面の方針（たたき台）」（ユーザーが「基本おすすめ通り、セットボーナスは欲しい」と決めた）。

- 2段：撃ち方・形・働きが同じ物のまとまりが「シリーズ」、その中の数値違いが「型」。型の違いは数値だけで、新しい仕組みは足さない。
- 武器（`SERIES`）：`{ maker, types: [[武器のキー, 型番], ...] }`。型番はオリジナル（例 SR-7、LC-3D）で、名前は「型番＋武器の名前」。v0.13 の48種は1種1シリーズ、特別装備の同じ仕組みの物（加速装置・重砲・光学迷彩・リペアユニット）だけ1シリーズに型が2〜3つだった。大剣（`blade`）はソード系の上位の型（SE-9「ソード・大剣」。v0.13.1、ユーザー指定）。`se.cat` は武器の名前の「・」の前、`label` は後ろ。v0.14で wiki の各系統の型と Codex 版の主武器の系統を足した（次の節）。
- パーツ（`PART_SERIES`）：`{ maker, name, desc, types: [PARTS の型のキー], set }`。今はスウィフト（軽量）・ハウンド（標準）・ブルワーク（重装）の3シリーズで、それぞれⅠ型だけ（`PARTS[部位][型].series` / `model` / `label` が起動時に入る）。
- メーカー（`MAKERS`）：架空の5社（シルフ精機＝軽く速射の効く銃と刃物、ガルド重工＝重く頑丈な実弾兵器、ルミナ技研＝エネルギー兵器と高出力の装置、ボルカ火工＝爆発物と設置物、アイリス電子＝索敵・迷彩・修理の電子装備）。名前と割り当ては Claude の案。
- セットボーナス（`setBonus`、`mechStats`）：頭・胴・腕・脚が同じシリーズなら（型は問わない）、そのシリーズの `set = { text, fx: [[部位, 項目, 'mul' か 'add', 値], ...] }` をパーツの数値に掛けてから重量・速さを求める。本家はアーケード版だけにあり、PS4版はシリーズごとのチップに置き換えた（`research/parts/setbonus.md`）。値はアーケード版 wiki のブランドごとの表（https://w.atwiki.jp/borderbreak/pages/24.html 、2018年3月のBB.NET表記。v0.13.1、ユーザーが示した）：スウィフト＝シュライク（ブースト+5、歩行+0.45m/s）、ハウンド＝クーガー（射撃補正+5%、重量耐性+150）、ブルワーク＝ヘヴィガード（装甲+3%を各部位。被ダメージ倍率から0.03引く。もう1つの DEF耐久+250 は本作に DEF が無いので入れない）。初期の機体はハウンドで揃っているので、何も変えなくても射撃補正+5%・重量耐性+150が付く。
- 機体カスタマイズの画面（`renderCustom`）：上に兵装のタブ（`#cuTabs`）と構成1〜3（`#cuBuilds`。メニューにも `#ovBuild`）。左の列（`renderSlotList`）に部位4つと武器の枠4つ（重量と付けている物）。中の列（`renderSeries`）に選んだ枠のシリーズをメーカーごとにまとめ、開くと型の行（主な数値 `keyStats` と重量）。並べ替えで軽い順・重い順の平らな一覧にもできる。右の列（`renderDiff`）に回るプレビュー（`mechPreview`：マウスを乗せている物を付けた姿。武器の枠を選んでいればその武器を持つ）、今の物の数値と、マウスを乗せた型との差（`itemNums`、`mechNums`。良くなる方は緑の▲、悪くなる方は赤の▼）、セットボーナス（付く・外れるも出す）、塗装。下に重量のバー（`#cuWBar`）と兵装ごとの重量表（`#cuMore`）。↑↓キーで型を移り、Enter で付ける。付けた物はすぐ保存する。

### 被ロックオン警告（`lockWarning`。v0.11.1、Codex 版から）

- 自分をロックしている敵機・防衛砲台を数えて「被ロックオン／敵機N機・砲台N基 ｜ 方向」を出し、照準の周りの輪に8方向の矢印を出す（同じ方向に複数いれば ×N、全員が8m以上上なら ↑、下なら ↓）。1.4秒ごとに警告音 `lockWarn`。
- ロックしない武器（`noLock`：狙撃銃・重砲・偵察機）で狙っている敵と、光学迷彩中の自分は数えない。

### 被索敵の警告（`spotWarning`。v0.11.2、ユーザー指定）

- 敵のレーダー（敵ベースに入っている間）・センサー・偵察機・索敵ソナーに映されている間、ミニマップの下に「被索敵」と、索敵している物と残りの秒数（レーダーはベースにいる間ずっとなので秒数なし）を出す。映され始めたら1回 `spotWarn` を鳴らす。
- 索敵している物は `spot(team, e, keep, by, src)` の `src`（'レーダー'・'センサー'・'偵察機'・'索敵ソナー'）で `spotSrc[陣営]` に残り秒数つきで入る。
- 敵ベースのレーダーに探知されたときの「探知されています」の表示（v0.9.3）は、この警告にまとめた。上部の赤い帯は自軍ベースへの侵入警告だけ。

### 設置物と索敵（`gadgetUpdate`）

- 地雷とセンサーは `gadgets` に入り、撃って壊せる。地雷とセンサーは起動まで1秒（`armT`）。1人が置ける数（`max`）を超えると古い物から消える。地雷は地面に置かれ、センサーは当たった所（壁・地面・機体なら足元）に貼りつく。
- 索敵：センサー（0.25秒ごと、球）と偵察機（水平距離）が見つけた敵機を `spotted[陣営]` に残り秒数つきで入れる。ミニマップでは、自機の80m以内の敵は丸（光学迷彩中の敵は出ない）、索敵で見つけた敵は赤い ◇（光学迷彩中でも出る。wiki）。味方のセンサーと偵察機は黄色い円で範囲を出す。
- 偵察機はまだ撃ち落とせない。
- Botの狙い（v0.11.2、ユーザー指摘「設置物にタゲが行かない。優先されすぎても困るが、壊さないのはもっと問題」）：見えている敵機（70m、索敵を受けていれば105m）がいちばん。ただし自分を撃っている自動砲台が、その敵機より近ければ先に壊す。敵機が見えなければ55m以内の防衛砲台、無ければ見えている敵の設置物（`botGadget`。自動砲台60m・センサー50m・地雷と遠隔爆弾30m、自軍のコアに貼りついた遠隔爆弾は60m。自動砲台は距離を0.7倍に見積もって先に選ぶ）。重火力はロケットを設置物にもよく撃つが、重砲は撃たない。設置物を狙う点（`targetPoint`）は自動砲台が砲身の高さ（1m）、ほかは0.2m。
- v0.11の設置物：遠隔爆弾は当たった所（壁・コア）に貼りつき、プレイヤーは遠隔爆弾を持っている間に右クリックで全部起爆（`detonateRemotes`）、Botは敵機が爆風の6割の距離に来たら起爆する。敵のコアに貼りついていればコアにも当たる。自動砲台（`sentryTick`）は地面に置かれ、0.3秒ごとに range 以内で見えている（光学迷彩は `noticed`）一番近い敵機を選び、持ち主の弾として撃つ。浮遊機雷は地雷と同じ動きで、1.6m浮かんで7m以内に反応する。滞空センサーは `dur` 秒で消え、扇形センサーは置いたときの持ち主の向き（`g.dir`）の前方だけを見る。索敵ソナーは設置物にならず、炸裂（`blast` の `scan`）した瞬間だけ映す。
- 設置物破壊のスコアは、遠隔爆弾を地雷、自動砲台をセンサーと同じに数える。

### 光学迷彩（`camoTick`、`reveal`、`cloakHit`、`cloakLook`、`noticed`。ユーザー指定）

- 見えやすさ `vis` は、止まっているとだんだん下がって0.04に近づく（約1秒で半分）。動くと速さに応じて揺らぎながら上がり、歩きで約0.4、ダッシュで0.55。撃つかソードを振ると0.8、被弾すると0.6まで上がり、そこからまた下がる。
- 見た目：機体の不透明度を `vis` にし、揺らいでいる間はちらつかせる。味方（自機を含む）には最低0.3で薄く見える。ブースターの炎は消えない（wiki）。消えている間、自機の画面中央に見えやすさを出す。
- 被弾すると、ダメージ4000（`hitHp`）でSPが尽きる割合でSPを余分に使う（アサルトライフル1発で約8.5%、10発ほどで解除。v0.9.1でユーザー指定）。自機ならSPゲージが赤く光る。SPが尽きると解除。撃破されても解除。
- Botと防衛砲台は、光学迷彩中の敵機には距離が `8 + vis × 80` m より近くないと気づけない（止まっていれば約11m、歩いていれば約40m、撃った直後は約70m）。プレイヤーは画面で見て探す。

### Botの補助装備・特別装備（`botAct`）

Botはプレイヤーと同じ装備を同じルールで使う。数秒ごとに次の条件を見て、当てはまれば `act` を作り、その枠に持ち替えて使い、終わったら元に戻る。

| 兵装 | 使う場面 |
|---|---|
| 強襲 | 15〜40mの目標へ副武器（3点射は撃ち切るまで）。交戦していなければ加速装置を作動させ、遠い移動では加速して進む |
| 重火力 | 40m以内の敵機へ補助装備の手榴弾（衝撃散弾銃は15m以内で撃つ）。30m以上離れた目標へ、SPが満タンなら重砲を撃ち切る |
| 遊撃 | 35mより遠い敵には狙撃銃を使い、その場で止まってスコープを覗き、照準が6割まで収束してから撃つ（止まっている間はショートダッシュで避けない。v0.10、`u.snipe`）。交戦していなければ、敵ベースの方へ偵察機を打ち上げるか索敵ソナーを30m先へ投げる。自動砲台は自軍のプラントか守りの役のとき、40m以内に無ければ足元の6m先に置く。SPが満タンなら光学迷彩で消えて進む |
| 支援 | 自軍のプラントにいて近くに無ければ、センサー（滞空センサーは前方60mへ）と地雷・遠隔爆弾を置く。リペアユニットは今までどおり。リペアフィールドは、自分か周り12mの味方の耐久が9割未満なら作動させ（SP3割以上）、いなくなれば止める（交戦中も） |

### 指示出し・蘇生・エリア移動（v0.17、ユーザー指定）

**指示出し**（`QCHAT`、`qchatSend`、`qchatTick`。ユーザー指定「G 長押しの円形メニュー（マウスの向きで選び、離すと送る）と、全体マップをクリックして地点を指す」）

- G を押している間、画面の中央に8つの言葉を円く並べる（`#qchat`）。マウスを真ん中から22以上動かした向き（上から右回りに8方向）を選び、G を離すと送る（真ん中のままなら取り消し）。メニューの間は視点が動かない。
- 送った言葉は味方の右の欄に出て、短い音（`chat`）が鳴る。敵の言葉は出ない。
- 言葉、従う機数、秒は Claude が決めた。

| 言葉 | 印 | 従うBot | 秒 |
|---|---|---|---|
| ここへ向かえ | 照準の先 | 近い順に3機。その地点の6m以内まで行く | 40 |
| 敵を発見 | 照準の先 | 近い順に1機。その地点へ | 20 |
| ここを守れ | 照準の先 | 近い順に2機。その地点の周り10mで戦う | 45 |
| 援護をたのむ | なし | 200m以内の2機。送った機体の12m以内へ来る | 30 |
| ありがとう・後退する・ごめん・了解 | なし | なし | ― |

- 印（`pings`）は黄色の光の柱で、全体マップとミニマップには輪、画面には言葉と距離が出る。10秒で消え、1陣営3つまで。全体マップを開いている間は、照準の先の代わりにマップのカーソルの地点に出す。
- 従うBotの1機目が「了解」と返す。
- 指示はカタパルトへ向かう途中より優先する。リペアポッドへ下がるときと、行動不能の味方を起こしに行くときは、そちらを先にする。援護を頼んだ機体が撃破されると指示は終わる。
- 試合をやり直すと、印と指示は消える。

**蘇生**（`kill`、`wreck`、`downTick`、`revive`。ユーザー指定「耐久0で約10秒倒れたまま、その間にリペアユニットで起こせる。大きな一撃なら即大破」）

- 耐久が0になった機体は、その場に倒れて行動不能（`downT`）になる。`REVIVE_WAIT` 10秒たつと大破し、機体が消えて再出撃までの5秒を数え始める。
- 撃破の一撃が `REVIVE_BIG`（ダウンと同じ7000）以上なら、倒れずにすぐ大破する。散弾は1回の射撃の合計で見る。自爆もすぐ大破。
- 行動不能の間に味方のリペアユニットで `REVIVE_NEED` 3000修理されると起き上がる。耐久は3割（`REVIVE_HP`）、3秒無敵（`REVIVE_INVUL`）。
  - 修理量3000と無敵3秒は wiki の再始動の値。耐久3割はユーザーに示した値。
  - 起こす修理には、味方を直すときの1.2倍が掛からない（wiki）。
  - リペアユニットは、照準の先の行動不能の味方も相手に選ぶ（地面から0.8mの所を狙う）。
- 数える時：撃破のスコアと撃破数・大破数は倒れたとき。コアの1/160（コスト制のマップは戦力）とキルカメラは大破したとき。
- 行動不能の機体には弾も爆風も当たらない。ロックオンもできず、プラントの占拠にも数えない。
- 見た目：後ろへ倒れたまま赤く点滅し、ときどき煙が出る。
- プレイヤーが行動不能になったとき：
  - F ですぐ大破し、再出撃へ進める。
  - 画面の真ん中に、大破までの残り秒、修理の進み、起こせる一番近い味方とその距離を出す。
  - 起き上がると「蘇生されました」と知らせる。
- Bot が行動不能になったとき：
  - 120m（`REVIVE_CALL`）以内に起こせる味方がいなければ、1秒で大破する。起こせる味方とは、リペアユニットを持ち、ゲージが残っている機体。
  - 起こせるのがプレイヤーなら「救援をたのむ」と言い、その場所に印（「行動不能 名前」）を出す。
- リペアユニットを持つBotは、120m以内の行動不能の味方を起こしに行く。リペアポッドへ下がるとき以外は何より先にする。
- 起こすとスコアは貢献 +1（「スコア」の節）。

**エリア移動**（`startTransfer`、`doTransfer`、`botTransfer`。ユーザー指定「H で待機してから、ベースかプラントへ。耐久・弾は持ち越し、ベースの中では半分の時間で兵装も変えられる」）

- H でその場に屈んで待機し、待ち終わるとベースか自軍のプラントへ移る。もう一度 H で取り消し。出る場所は再出撃と同じ（`spawnPos`）。
- 始められるのは地上で動けるときだけ。空中・カタパルト・よろけ・ダウン・ソードの振りの途中・リペアポッドの上ではできない。
- 待っている間は動けず撃てず、ダウンすると取り消しになる。
- 待ち時間は重さ（`stats.weight`）で決める。
  - 4700kg（`AREA_KG0`）までは2.5秒、超えた分は1kgごとに4.5/730秒、最長10秒。
  - 標準のパーツと初期装備なら、強襲（4340kg）と遊撃（4630kg）が2.5秒、支援（4900kg）が約3.7秒、重火力（5430kg）が7秒。ユーザーに示した「重火力7秒、ほか2.5秒」に合わせた。
- 自軍ベース（`BASE_LINE` より奥）で始めると、待ち時間は半分になり、兵装も変えられる（Z・X・C・V）。兵装を変えると武器は全量になり、耐久はそのまま。
- 待っている間は、画面の下に移動先の画面を出す（再出撃と同じ。数字キーかホイールで選ぶ）。その一番上に残り秒（`#rtXf`）。最初の移動先は、ベースの外ならベース、ベースの中なら最前線のプラント。
- 耐久・弾・SPは持ち越す。撃破ではないのでコアも減らない。移った先では2秒無敵。
- コスト制のマップ（ベースもプラントも無い）では使えない。
- Botの使い方（`botTransfer`）：敵を狙っていないときだけ使い、1度使うと40秒は使わない。攻め役は使わない。
  - 守り役は、自軍ベースのレーダーが敵機を見つけていて、自分がベースから150m以上離れていればベースへ。
  - 占拠役と守り役は、敵が入ってゲージが動いている自軍のプラントから150m以上離れていれば、そのプラントへ。

### マップ要素

| レーダー | 各ベースに1基（自軍は (-50, 215)、敵軍は点対称）。耐久20000（仮置き）。壊れていない間、ベースの境目 `BASE_LINE`（z=±150、地面に色の線）より奥に入った敵機を探知し、味方のミニマップに映し（光学迷彩も）、自軍なら画面上部に「警告：ベースに敵機侵入」と音（4秒ごと）を出す。守り役のBotは侵入した敵機へ向かう。自分が敵ベースに入って敵のレーダーが生きていれば被索敵の警告（「レーダー」）が出て、索敵を受けたのと同じくロックされる距離が伸びる（v0.11.2）。壊せて（ロックオンはできない）、リペアユニットで修理量7000を与えると再始動（防衛砲台と同じ）。v0.9.3、ユーザー指定（`radars`、`radarUpdate`） |
| 防衛砲台 | 各ベース前に2基。耐久14000、射程70m。移動を予測して遅い榴弾（1800、爆風5m）を3発ずつ撃ち、3秒リロード。ロックオンでき、壊せる。壊れた砲台はリペアユニットで修理量7000を与えると再始動（wiki） |
| カタパルト | `MAPS[id].catapults`。台地演習場では、各ベースに左右2基ずつ（内側2基は中央の横 (±57, 12) へ、外側2基は左がプラントAの前 (-50, 66)、右が高台の上 (85, 72) へ。外側はv0.9.2でユーザー指定により増設）。プラントAにBへ飛ぶ台 (-24, 122)→(-7, 20)、点対称にCにも（v0.9.2、ユーザー指定）。どの台も陣営に関係なく誰でも（敵も）使える（v0.10.5、ユーザー指定。それまではベースの台はその陣営だけ、プラントの台は占拠している陣営だけ）。5番目のプラント名は、Botがそのプラントから出たときに使う台の目印。乗ると決まった着地点へ2.8秒で射出（打ち出し方はv0.10.5でも変えていない）。見た目（v0.10.5、ユーザー指定「BBのカタパルトとAPEXのグラビティキャノンを合わせた形」、`catModel`）：黄色と黒の縞の縁の八角形の射出台にレール2本と後ろの押し出し板、飛ぶ道の4.5mと8mの所に傾けた2つの輪（砲身。脚と4本の棒で支える。中の紫の光の膜は射出のたびに光る）、砲身の先に飛ぶ向きが分かる程度の光の点（道に沿って11〜41mに7個、先ほど小さく。ユーザー指定）。着地点の印は付けない（ユーザー指定「着地のわっかは不要、飛んだら飛んだっきり」）。どれも見た目だけで当たり判定は無く、動かない部分は材質ごとに1つのメッシュにまとめる（`accGeo`）。着地点の高さに合わせて打ち上げる。最初の1秒は操作できずブーストが回復し、その後は空中ダッシュとSpace長押しで調整。Botはベースから出ると75%で自軍側のベースの台を、カタパルトのあるプラントから出ると50%で敵陣の方へ飛ぶ台を使う |
| リペアポッド | 台地演習場では、ベースに2基、プラントBに2基、A・Cに1基。A・Cのものはプラントの自軍ベース側 (-40, 117) にあり、前と左を高さ5mの崖の土手で囲み、深さ2mの窪地に置いて敵陣側から見えないようにしている（v0.9.2、ユーザー指定。`TERRAIN` の block 2つと trench 1つ）。自軍ベースと自軍プラントのものだけ使える。止まっている間、毎秒1200回復。入った瞬間に撃ちかけのマガジンを満たし、1秒ごとに1マガジン、10秒で全量を補給（wiki）。**使っている間は撃てず、ダッシュもジャンプもできない**（ユーザー指定。移動キーで中断） |
| バリケード | 耐久30000。壊すと通り道が開き、試合中は復活しない |
| コアの傘 | コアの上の半透明の屋根（半径26m、縁の高さ13m）。**弾を止める障害物としてだけ存在し、距離などのダメージ規則はない**（ユーザー指定） |

### スコア（v0.9.5、ユーザー指定。wiki PS4版のスコア表 https://w.atwiki.jp/ps4borderbreak/pages/615.html ）

### 効果音（`SFX`、`sfx`）

- 音は [Openverse](https://openverse.org/) から自由に使えるライセンス（CC0、CC BY）のものを選ぶ（ユーザー指定）。出典は `sounds/CREDITS.md` に書く。NC・ND・SA と公式の音は使わない。
- 開発版のフォルダ：音の元ファイルは `sounds/src/<名前>.*`、`python3 tools/build_sounds.py` で `prototype/sounds.js`（mp3 を base64 にしたもの）を作る。ファイルを直接読まずに script で読むのは、index.html をダブルクリックで開いたとき（file://）も鳴らすため。
- 音の名前（13個）：ar、pistol、sniper、shotgun、rocket、explode、swing、slash、hit、dash、reload、beep、heal。場面ごとにどの音をどの音量・高さで鳴らすかは `SFX` の表（同じ音を高さを変えて使い回す。例：ジャンプとカタパルトは dash）。
- 武器の射撃音（v0.11.3、ユーザー指定「Codex 版から射撃音を」）：Codex 版の音は同じ13個のファイルで、増えていたのは `magnum`（pistol を低く大きく鳴らす設定）だけだったので、それを足し、同じ音を使う武器は `SFX_TUNE` で音の種類と高さ（`w.sfxRate`）を武器ごとに変えた。`sfx(名前, 位置, 鳴らした物, 高さ)`。
- `sfx(名前, 位置, 鳴らした物)`：自機から遠いほど小さく（`range` で0）、左右に振り分ける。同じ物が同じ音を `gap` 秒より短い間隔で鳴らさない。同時に鳴らすのは32音まで。`ui` の音は距離に関係なく鳴る。
- ブラウザは操作の後でないと音を出せないので、最初のクリックかキー入力で `initAudio` が準備する。N キーで効果音と音声アナウンスを消す（v0.15まで M。M は全体マップになった）。
- 戦況アナウンス（v0.15、ユーザーが選んだ「本家から移植」の一番）：画面の上の方（`#announce`）に2.6秒出し、短い電子音（`annGood`・`annBad`・`annInfo`）を鳴らす。メニューのスイッチ「音声アナウンス」（`localStorage` の `coreBreakerVoice`）がオンなら、ブラウザの読み上げ（`speechSynthesis`、日本語の声があれば）でも読む。出す物：作戦開始、プラントの占拠・中立化（自軍・敵）、自軍のプラントが敵に占拠され始めた（同じプラントは20秒あけて）、自軍コアが攻撃を受けている（20秒あけて）、敵コアへの攻撃を確認（30秒あけて）、コアの残り50%・25%（コスト制のマップは除く）、ベースへの敵機侵入（15秒あけて）、残り時間3分・1分・30秒・10秒（試合がそれより長いとき）。一度に3つまで。文言は Claude が決めた。
- 戦闘中BGM（v0.10、ユーザー指定）：ユーザーが選んだ OpenGameArt.org の曲「Nightmare(prototype)」（Centurion_of_war、CC0）1曲（`sounds/music/bgm.ogg`、19.2秒）を、試合中だけ繰り返し鳴らす（音量0.32、始まりは1秒で大きく、試合が終わると0.6秒で消える）。メニューのトグルスイッチ「戦闘中BGM」で切り替え、`localStorage` の `coreBreakerBgm` に残る。N キーの効果音オフとは別。ogg は繰り返しの継ぎ目が出ないよう再圧縮せず `music.js` に base64 で入れる。ogg を再生できないブラウザ（古いSafariなど）ではスイッチの横に「このブラウザでは再生できません」と出る。操作説明の最後に謝辞（「Author: Centurion_of_war さんの nightmareheavy.ogg を使わせていただいています。ありがとうございます」と出典。ユーザー指定の書き方）。
- 鳴らす場面：発射（武器の `sfx`）、防衛砲台の発射、爆発（`boom`）、リロード完了、ソードの振り・命中、自分の命中（ヘッドショットは `headshot` と `headping`、v0.9.5）・被弾、ダッシュ、ジャンプ、カタパルト、ロックオン、プラント占拠、リペアポッド、リペアユニット、持ち替え。

### 武器の型（`WEAPON_TYPES`、`makeType`。v0.14、ユーザー指定「兵装ふやしてこっか」「主武器バリエーションに関してはCodex版からある程度移植できると思うので検討願います」）

- 型の選び方：wiki（PS4版）の各系統の表（`research/weapons/*.md`）から、元にした武器と撃ち方・働きが同じで数値だけ違う行を、シリーズが4種までになるよう選んだ（Claude が選んだ。選んだ行・選ばなかった行と理由は `research/weapons/types/*.json` にあり、`WEAPON_TYPES` の行はそこから作った）。入れなかった物：コラボ・イベントの珍しい品、撃ち方が違う物（3点射・チャージ・誘導・分裂・2連装・切り替え）、数値の足りない行。遠隔爆弾（リムペットボムは貼りつく）には型が無い。
- `WEAPON_TYPES[元の武器のキー] = { w0, types: [[型の名前, wiki の値, 説明], ...] }`。`w0` は元にした wiki の型の強化前の値、行の終わりのコメントは wiki の名前（画面には出さない）。起動時に `SERIES` の後で `makeType` が型を作り、`WEAPONS`・`WEAPON_KG`・`MODEL_OF`・`ARMORY`（同じシリーズの後ろ）・`SERIES` に足す。
- 数値：「wiki の値 ÷ `w0`」の比を、本作の元の武器の値に掛ける（本作で強化・縮小した分、例えばショットガンの強化や爆発半径の0.82倍は型にも残る）。重量は wiki の値そのまま。整数の物（弾数・発数・所持数）は丸める。
  - 所持数（count）：補給できない物（`mags` が1）は `mag`、ほかは `mags`。`proj.max` が元の所持数と同じなら一緒に変える。
  - 偵察機：range → `dist`、dur → `hover`。滞空センサー：range（届く距離）は弾速の2乗に比例するので弾速に比の平方根を掛ける。弱化グレネード：dur → `weak.time`。加速装置：power → `speed`。自動砲台：銃の値は `proj.gun` へ。散弾の砲台は `pellets` を足し、ばらつき0.07と距離の減り `[10, 30, 0.3]`。
  - SP：満タンまでの秒の比で、使い切らなかったときの秒も変える（wiki に値があればその比）。
  - 精度（acc）・反動（recoil）のランク（E-〜S）は、1段上がるごとに `spread`（狙撃銃は `sway` も）と反動を0.88倍。反動は `baseKick`（元の武器の既定）に掛けて `recoil` に書く。
  - 近接：wiki の値は連撃の合計なので比の平方根を掛け、横なぎ9600（どの型でも2回は要る）・ダッシュ斬り20000が上限。重さの比 k で、構え・振り・硬直を k^0.35 倍、間合いを k^0.12 倍、ダッシュ中の踏み込みを k^0.3 で割り、誘導を k^0.35 で割る。値の決め方は仮（Claude の判断）。
  - 射撃音の高さ（`sfxRate`）は威力の比の −0.12 乗（重い弾ほど低い）。
- 名前：「元の武器の名前の・の前＋・＋型の名前」（例：アサルトライフル・強装型）。型の名前は軽量型・連射型・強装型・大容量型・精密型・速装型・広域型・持続型・瞬発型・高出力型・重装型と、巡航型（加速装置）・即応型（光学迷彩）。キーは元のキー＋1文字（`TYPE_LETTER`、例 `arH`）、型番も元の型番＋同じ文字（例 SR-7H）。形は元と同じ系統で、型（0・1・2）を順に変える。
- Codex 版の主武器の系統（ユーザーが Codex に作らせた版の weapons.js から）：本作の撃ち方のまま数値だけで作れる7系統を `WEAPONS` に足した。カービン（SK-56、UK56速射機銃）・軽量散弾銃（SS-7、SSG7－ゲイル、単発）・エナジー機銃（LV-1、ヴルカンLG1、オーバーヒートなし）・単射二丁拳銃（SW-40、マーゲイM40）・二丁エナジー銃（LM-6、LMM－ジェミニ）・マグナム（GN-50、ハガードM50、頭2.5倍）・エナジー散弾銃（LA-1、LSG－アヴローラ、単発）。数値は wiki の強化前、形は Codex 版の物（`buildWeaponGeo` にもともとあった系統）。Codex 版が作った「大容量」「高威力」の型は wiki に無い数値なので使わず、型は wiki の表から選んだ。ばらつきと反動は wiki のランクを本作の近い武器から0.88倍ずつで換算した。LSG の表には精度が無いので、拡散率（大・小・極小）を精度 D+・C・B として扱った。

## 5. 守ってほしい設計方針（ユーザーの決定）

1. ロックオンは弾を中心へ補正しない。撃つ側はヘッドショットを狙う技量、撃たれる側はショートダッシュでロックを外す技量が勝負になるようにする。ただし追従が弱すぎるのは不可。
2. コアの傘は障害物。ダメージの距離減衰や「傘の外からは無効」といった規則を足さない。
3. リペアポッド使用中は行動不可。
4. 兵装ごとの4枠（主武器・副武器・補助装備・特別装備。v0.8でユーザーの了承を得て4枠にした）。v0.11から各枠の武器を選べる（`ARMORY`。v0.14で型を足して全172種、v0.15で全194種）。数値は仮置きで、wikiに寄せる方向で調整する。ただしショットガンとソードはユーザーの指摘で wiki より強くしている（戻すときは先に確認）。
5. 公式の素材・名称を使わない（機体、音、ロゴ、武器名の固有名詞）。武器は一般名（アサルトライフル等）で呼ぶ。
6. Botもプレイヤーと同じルールで動かす（ロックの追従、ポッドの行動不可、弾数制限など）。

## 6. 改造のしかた

- **武器の数値を変える**：`WEAPONS` の値を変えるだけ。HUD・Bot・補給は自動で追従する。
- **武器を足す**：`WEAPONS` に定義（`name` と `desc` も）を足し、`ARMORY` のその兵装の枠のリストに入れる（先頭は初期装備なので `CLASSES` と同じにしておく）。形は `MODEL_OF` に割り当てる。カードの数値は `wStats` が種類ごとに出す。銃なら `type: 'gun'` で `dmg/rpm/mag/mags/reload/spread/look` を書けば動く。投げる物は `proj` に `grav` を足す。新しい種類なら `weaponsTick` に分岐を足す。
- **型を足す**：`WEAPON_TYPES` の元の武器の行の `types` に `[型の名前, wiki の値, 説明]` を足す（値のキーは `w0` と同じ物。比で換算される）。新しい型の名前なら `TYPE_LETTER` に1文字を足す。
- **Botに装備を使わせる**：`botAct` に兵装ごとの条件を足し、`{ slot, aim（狙う所。無ければ目標）, t（諦めるまでの秒）, done（使い終わったか） }` を返す。
- **兵装を足す**：`CLASSES` と `CLASS_KEYS`、`CLASS_HOTKEYS` に足す。Botの兵装の割り当ては `BOT_CLASS`、使い分けは `botUpdate` の「兵装ごとの使い分け」の部分。
- **マップを足す**：`prototype/maps/<id>.js` を書いて `python3 tools/build_maps.py` を実行する（書き方と確かめ方は `prototype/maps/README.md`）。メニューのマップ選択、ミニマップ、プラントの表示、Botの人数は自動で追従する。マップ製作のスレッドの担当。
- **障害物を足す**：マップのファイルの `layout` 配列に `[x, z, 幅, 奥行き, 高さ]` を足すと、中央をはさんで点対称に置かれる。斜面に置いた箱は低い側の地面まで埋まり、高い側の地面から「高さ」ぶん出る。
- **地形を変える**：マップのファイルの `terrain` に起伏を足す（自軍側の半分だけ書けば敵軍側は点対称に足される。中心 (0,0) のものは1つだけ）。施設（プラント・ポッド・砲台・カタパルト）は置いた場所の `terrainH` に乗るので、座標を変えるだけでよい。坂は傾き1.1（約48°）を超えると登れない壁になる。
- **当たる物を足す**：メッシュを `hittables` に入れ、`userData.ref` に `kind` 付きのオブジェクトを入れ、`damage` に分岐を足す。
- **効果音を足す**：`sounds/src/` に音を置き、`tools/build_sounds.py` の `SOUNDS` と `index.html` の `SFX` に名前を足し、鳴らしたい所で `sfx()` を呼ぶ。出典は `sounds/CREDITS.md` に書く。
- **数値の出典を書く**：wikiの値を使ったら、定義の横のコメントに元の武器名と値を残す。

## 8. 動作確認のしかた

ヘッドレスブラウザ（Playwright）で動かすと便利です。

1. `index.html` をコピーし、`loop` の `const dt = Math.min(0.05, (now - last) / 1000); last = now;` を `const dt = 0.05; last = now;` に置き換える（毎フレーム0.05秒進む）。
2. 末尾の `requestAnimationFrame(loop);` の後に `window.__g = { get player() { return player; }, units, turrets, cores, WEAPONS, SLOTS, equip, selectWeapon, gadgets, drones, spotted, shells, aimMark, nearestEnemy, noticed, physics, damage, ... };` を足し、外から状態を読めるようにする。
3. `#start` をクリックして試合を始め、`__g.player` の位置や向きを書き換えて試す。Botを止めたいときは `botUpdate` の冒頭に `if (u.frozen) return;` を足す。

WebGLが必要です（ヘッドレスなら `--use-gl=swiftshader` で動く）。

`python3 tools/test/make_dbg.py 作業フォルダ` が 1・2 の書き換え（`__g` の公開、`frozen`、three.js をローカルから読む）をした `dbg.html` と、`sounds.js`・`music.js`・`maps.js`・`three.min.js` を作業フォルダに用意する。マップの確認（施設の置き場所、ポッドの見え方、カタパルトの着地点、再出撃位置）は `node tools/test/map_check.js 作業フォルダ マップID`（`prototype/maps/README.md`）。
