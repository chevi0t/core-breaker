# 新しい脚の種類（案、2026-10-20）

このファイルは Claude が書いた案です。オーナーは一度「この案で頼む」を選んだあと、「やっぱ新脚は後回しで」と決めました（2026-10-20）。Issue はまだ書いていません。再開するときは、この案から Codex の Issue（`docs/codex/tasks/`）にします。
脚の種類は元のゲームに無い（アーマード・コアに寄せた本作のオリジナル）ので、wiki の数値はありません。下の数値は今の標準脚（ハウンドⅠ型）と比べた最初の仮置きで、Bot 戦と試遊で直します。

## 今の脚（比べる元）

| | 重さ | 装甲 | 歩行 | ダッシュ | 巡航 | 重量耐性 |
|---|---:|---:|---:|---:|---:|---:|
| 標準（ハウンドⅠ） | 850kg | 1.00 | 6.0 | 21.8 | 19.7 | 4650kg |

装甲の数字は小さいほど硬い（受けるダメージの倍率）。どの脚でも、歩く・ショートダッシュ・ロングダッシュ・ジャンプ・空中でブーストを吹かして浮く、ができる。

## 4種の特徴（案）

| 種類 | 得意なこと | 苦手なこと（捨てる物） |
|---|---|---|
| ホバー | 地面を滑るように速く動く。起伏や小さな段差で遅くならない | 止まりにくい（慣性で滑る）。押されやすい。重い装備は積めない |
| 四脚 | 射撃が安定する。空中で長く浮ける。よろけにくい | 歩きとダッシュが遅め。横に広く、弾が当たりやすい |
| キャタピラ | 重い装備をそのまま積める。よろけ・ダウンしにくい | ジャンプできない。ダッシュが短く、身軽に避けられない |
| 逆関節 | 高く跳べる。着地の沈みが短い | 重量耐性が低く、装甲も薄い |

### ホバー

- 数値：重さ900kg、装甲0.95、歩行8.5、ダッシュ22.5、巡航22.0、重量耐性4000kg
- 動き：地面から0.5m浮く。速さが変わるまでに慣性がある（最高速まで約0.5秒、手を離してから止まるまで約0.8秒滑る）。起伏（gen_rough の凸凹）と1m以下の段差で減速しない。歩く足の動きは無く、進む向きへ少し傾く。
- 弱点：よろけで押される距離が1.5倍。ジャンプの高さは0.8倍。

### 四脚

- 数値：重さ1250kg、装甲0.90、歩行5.2、ダッシュ19.5、巡航18.0、重量耐性5600kg
- 動き：4本の脚で歩く（#15 の関節を4本に）。射撃のばらつき0.85倍、反動0.8倍。空中で浮くときのブースト消費0.6倍。よろけ・ダウンの閾値1.2倍。
- 重砲などの「構える」武器を、屈まずに構えられる（構えたまま歩行の半分の速さで動ける）。これは遊び方が大きく変わるので、オーナーに確かめたい所。
- 弱点：脚の当たり判定が横に広い（胴の半径は今のまま、脚の装甲だけ広い）。

### キャタピラ

- 数値：重さ1600kg、装甲0.70、歩行5.5、ダッシュ16.0、巡航18.0、重量耐性8000kg
- 動き：履帯で走る。重量超過の減速は半分。よろけ・ダウンの閾値1.5倍。急な斜面（今は約48°まで）は同じ。
- 弱点：ジャンプできない（Space は何もしない。1.2m までの段差は乗り越える）。空中で浮けない（カタパルトとジャンプパッドは使える）。ダッシュは短く、Bot の「よける」動きも短くなる。

### 逆関節

- 数値：重さ820kg、装甲1.10、歩行6.5、ダッシュ22.0、巡航19.7、重量耐性3900kg
- 動き：膝が後ろへ曲がる脚（#15 の関節で膝の向きを逆に）。ジャンプの高さ1.6倍。着地の沈みと硬直0.5倍。
- 弱点：重量耐性と装甲。

## 決めること

1. 上の4種の特徴でよいか（特に、四脚の「屈まずに構える」）。
2. パーツの数：各種類に1型ずつ（全4パーツ）から始めるか、今のシリーズのようにⅠ〜Ⅲ型（全12パーツ）にするか。Claude の案は1型ずつ。動きの作りが重いので、まず4つで手触りを決め、Ⅱ・Ⅲ型は後で足す。
3. 名前とメーカー（案）：ホバー「スキマー」（アイリス電子）、四脚「タランチュラ」（ガルド重工）、キャタピラ「クローラー」（ボルカ火工）、逆関節「ホッパー」（シルフ精機）。脚だけのシリーズなので、セットボーナスは無し。

## 実装の段取り（Codex に渡す内容）

1. データ：`PARTS.legs` の型に `kind`（hover・quad・tracks・reverse。今の脚は biped）と、上の特別な値（慣性、ジャンプ倍率、よろけ倍率、構えて歩く、など）を足す。今の脚の動きは変えない。
2. 動き：`physics`・`playerUpdate`・`botUpdate` が `kind` の値を読む。Bot もプレイヤーと同じルール（AGENTS.md の5）。リペアポッド、カタパルト、ジャンプパッド、リフト、エリア移動は全種類で使えること。
3. 形：`buildMech` に4種の脚の形を足す（公式の素材は使わない）。四脚は4本の脚の関節、キャタピラは履帯の回転、ホバーは浮きと傾き、逆関節は逆向きの膝。装甲は今と同じく4部位のメッシュで、部位ごとの被弾が分かること。
4. Bot：キャタピラはジャンプの要る道を通らない（nav と `clearPath` に跳べない機体を足す）。Bot の脚の選び方（`botMech`）に新しい種類も入れる。
5. 画面：機体カスタマイズで脚の種類と特徴（例：「ジャンプできない」）を出す。
6. 確かめ方：`quick_check.js`（増えた脚を1つずつ）と、種類ごとの動きを確かめる `legs_check.js`（慣性、跳べない、跳ぶ高さ、構えて歩く、よろけの倍率）、短い Bot 戦。
7. 設計書：`docs/DESIGN.md` に脚の種類の節を足す。数値はオリジナルの仮置きだと書く。
