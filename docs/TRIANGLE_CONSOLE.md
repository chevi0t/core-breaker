# 三角コンソール（2026-11-03）

ユーザーが確認した図と赤線の移動図を、標準・アーケード・フライト・メカニカル・レトロミリタリーの5種類へ実装する。照準・捕捉範囲・距離・弾道・武器性能・機体性能・保存形式は変更しない。

## 配置と配色

- 左斜辺は選択武器の残量、右斜辺は耐久。下のBOOSTとSPは同じX位置で上下2段に重ねる。4本とも残弾・耐久ゲージと同じ長さにそろえる（斜辺の長さは維持、BOOST/SPは延長）。配置基準の円の接線へ外向きに移し、基準円自体は描画しない。基準半径は従来の捕捉円半径と元の三角形の内接半径の大きい方とし、小画面でも棒を内側へ移して頂点で交差させない。
- AMMO/AP（Armor Points・装甲値）/BOOST/SPと、RELOAD/CHARGE/HEAT/COOLINGなど中央の状態名を英語化。左は-60度、右は60度、下の2本は水平に、名前・数値・状態は同じ行へまとめ、文字と数値も棒へ平行に置く。文字は12pxから10px、数値は22pxから18px、下段の表示は11pxから10pxへ一段小さくする。周辺計器の日本語は維持する。
- 中央の残量は現在値だけとし、残弾の弾倉数や最大耐久の分母は表示しない。
- リロードは腕の装填倍率を含む進み具合、弾数のない装備はSP・無制限・充填など既存の装備状態に従う。スコープ中は左右の計器を隠し、ブーストとSPを維持する。
- 標準・アーケード・フライトはシアン/緑/黄/紫。メカニカルは淡緑、レトロは琥珀色に合わせる。捕捉後の線は全種類で赤。
- 周辺の機体・装備・マップ・方位計は維持。旧中央の円弧計器・SP棒・メカニカルの4枠の弧を隠す。旧DOMは既存の周辺HUD処理と互換のため残す。
- 捕捉範囲の円は非表示にするが、捕捉範囲と判定は変えない。三角ゲージは画面高に合わせ、UI拡大の倍率からは独立させる。タッチでは既存の標準コンソール切替を維持する。
- メカニカルの自動UI調整ONは1600×900を基準にする（ほかは1280×720）。耐久欄220px、武器欄280px、下中央は最大340pxへ整理し、小画面ではBOOSTと方位計を下段パネルの上へ移す。自動調整OFFの倍率は変更しない。

## ロックと熱

- プレロックは正三角形の各頂点を18%ずつ切った、短辺と長辺が交互の六角形。選択候補を強調し、候補DOMのプールと遮蔽検査の上限は維持する。
- 捕捉時だけ3本の赤い折れ線が120度間隔から、曲線上を移動しつつ60度回転する。画角ズームと同じ減衰係数9で進め、95%収束時（30/60/120fpsで約0.3秒）に、それぞれが短辺1本と隣の斜辺1本へ重なり、赤い六角形が完成する。カメラのズーム速度自体は変えない。移動・遮蔽復帰・メニュー復帰では再開せず、再捕捉・Q切替では再開する。
- チャージと熱は同じ半径44px・同じ太さ4pxの3本の円弧を共有する。チャージ中は`chargeT/chargeTime`に合わせて緑（全5配色共通）で伸び、各120度で緑の円が完成する。過熱しないチャージ銃・光波剣も対象とし、発射すると空に戻る。
- 充填/熱の数値は円の上へ1行で置き、画面中央にあるときも下のBOOST/SPの文字と重ねない。
- 発熱式の武器は`temp/100`、満充填の保持で過熱する武器は`holdT/chargeHold`を熱の表示に使う。保持中は満充填の緑を残し、同じ3弧の上へ熱色を伸ばして重ねる。円を増やさず、充填と保持過熱の両方を示す。文字はCHARGE/HEAT/COOLINGで現在の状態を区別する。
- 熱色は全5配色とも桃色（#ffb6d5）から赤（#ff3030）まで実熱量に比例して連続変化する。75%で急に色を切り替えない。実過熱は赤で固定し、冷却完了で通常へ戻す。
- 実際に`overheat`になったときだけ、緑を消して赤で円を満たし、OVERHEATと冷却の残り秒数を表示する。満充填だけでは過熱警告を出さない。冷却完了で解除。通常の充填率は残弾欄にも表示する。
- OVERHEATの文字は12pxから24pxへ2倍に拡大。背景も108×22pxから216×44pxへ広げ、文字を切らずに表示する。
- 充填/熱の共有リングはロック中の敵カーソルへ追従し、それ以外は画面中央。充填も熱もない武器、停止・大破・メニュー・地図・武器選択中は隠す。

## 明滅

- ブーストは既存の背面炎が検出した実噴射開始（ショート、巡航、滞空、加速装置）を表示用の連番へ渡し、ブースト計器を220msで1回明滅させる。押下だけ・不成立・ショートから巡航への継続では繰り返さない。踏み込みは通常燃料を使う噴射とは分ける。
- SPは既存の特殊兵装の作動状態を参照し、作動中だけ0.7秒周期で中央の棒を明滅。停止・SP枯渇・大破・メニューでは解除する。保持された装置、照射準備・照射中、修復、砲撃なども対象。
- OS/ブラウザの「動きを減らす」設定では、ロックは完成形を即表示し、ブースト/SPの明滅を停止する。SPの作動状態は一定の明るさで区別できる。
