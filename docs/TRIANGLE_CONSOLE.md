# 三角コンソール（2026-11-03）

ユーザーが確認した図と赤線の移動図を、標準・アーケード・フライト・メカニカル・レトロミリタリーの5種類へ実装する。照準・捕捉範囲・距離・弾道・武器性能・機体性能・保存形式は変更しない。

## 配置と配色

- 正三角形の左斜辺は選択武器の残量、右斜辺は耐久。底辺は左にブースト、右にSP。名前・現在値・最大値や状態も表示する。
- リロードは腕の装填倍率を含む進み具合、弾数のない装備はSP・無制限・充填など既存の装備状態に従う。スコープ中は左右の計器を隠し、ブーストとSPを維持する。
- 標準・アーケード・フライトはシアン/緑/黄/紫。メカニカルは淡緑、レトロは琥珀色に合わせる。捕捉後の線は全種類で赤。
- 周辺の機体・装備・マップ・方位計は維持。旧中央の円弧計器・SP棒・メカニカルの4枠の弧を隠す。旧DOMは既存の周辺HUD処理と互換のため残す。
- 中央の円は既存の捕捉範囲だけを表す。三角ゲージは画面高に合わせ、UI拡大の倍率からは独立させる。タッチでは既存の標準コンソール切替を維持する。

## ロックと熱

- プレロックは正三角形の各頂点を18%ずつ切った、短辺と長辺が交互の六角形。選択候補を強調し、候補DOMのプールと遮蔽検査の上限は維持する。
- 捕捉時だけ3本の赤い折れ線が120度間隔から、曲線上を移動しつつ60度回転する。1.4秒で、それぞれが短辺1本と隣の斜辺1本に重なり、赤い六角形が完成する。移動・遮蔽復帰・メニュー復帰では再開せず、再捕捉・Q切替では再開する。
- 発熱式の武器は`temp/100`、満充填の保持で過熱する武器は`holdT/chargeHold`を表示に使う。3本の弧が同時に伸び、各120度で一周が完成する。
- 実際に`overheat`になったとき、円を満たしてOVERHEATと冷却の残り秒数を表示する。冷却完了で解除。通常の充填率は残弾欄にも表示し、充填と熱を混同しない。
- 熱リングはロック中の敵カーソルへ追従し、それ以外は画面中央。熱のない武器、停止・大破・メニュー・地図・武器選択中は隠す。

## 明滅

- ブーストは既存の背面炎が検出した実噴射開始（ショート、巡航、滞空、加速装置）を表示用の連番へ渡し、ブースト計器を220msで1回明滅させる。押下だけ・不成立・ショートから巡航への継続では繰り返さない。踏み込みは通常燃料を使う噴射とは分ける。
- SPは既存の特殊兵装の作動状態を参照し、作動中だけ0.7秒周期で中央の棒を明滅。停止・SP枯渇・大破・メニューでは解除する。保持された装置、照射準備・照射中、修復、砲撃なども対象。
- OS/ブラウザの「動きを減らす」設定では、ロックは完成形を即表示し、ブースト/SPの明滅を停止する。SPの作動状態は一定の明るさで区別できる。
