# #228 脚の種類：四脚と逆脚の動きと形をゲームに入れる

## やること

四脚と逆脚を、動きと形ごとゲームに入れて遊べるようにする（オーナーの了承 2026-11-10。案は `docs/legs-plan.md` の「改訂案」）。

**先に済んでいること**：アクション（#226）と、四脚・逆脚の性能定義と形の試作（#227）。両方マージされ、オーナーが形の案を選んでから始める。

### 1. 動き（`physics`・`weaponsTick`・`jolt` など）

#227 で型に持たせた特性を読んで動かす。脚の種類の名前（`kind`）で分けず、できるだけ型の値で分ける（後で数値を直しやすいように）。

- 四脚：ばらつき・反動・よろけ閾値・空中の消費・ジャンプ・構えの速さ。しゃがみは「踏ん張り」：その場で止まる（歩けない）、ばらつき×0.6、よろけで押されない、よろけ・ダウンの閾値×1.5。踏ん張り中も旋回と射撃はできる。
- 逆脚：ジャンプの初速、着地硬直の閾値と長さ、よろけ閾値。しゃがみは「溜め」：0.3秒以上しゃがんでからジャンプで約12m、ジャンプのブースト2倍。空中の蹴りの届く距離2倍。
- タックル・蹴りの倍率を、#226 で作った表に足す。
- 今の二脚・ホバーの動きと数値は変えない。リペアポッド、カタパルト、ジャンプパッド、リフト、ジップライン、エリア移動は全種類で使える。

### 2. 形（`buildMech`）

#227 で仕上げた形を入れる（四脚は B案・重機型、逆脚は A案・2節。オーナーの決定 2026-11-11。元の下描きは `media/legs-proto/`）。

- 四脚は4本の脚で歩く（対角の2本ずつ）。踏ん張りは脚を開いて腰を落とす。逆脚は逆向きの膝で歩き、ジャンプの前に沈む。
- 装甲は今と同じ4部位のメッシュ。部位ごとの被弾、ヘッドショット、ロックオン（`LOCK_BODY`）が今どおり働く。四脚の脚の当たりは横に広い。
- 足音は今の物を使う（四脚は歩調を速く）。外の素材を足さない。

### 3. Bot とマップ

- Bot もプレイヤーと同じルール。`botMech` に新しい脚を入れる。四脚の Bot は撃ち合いで踏ん張りを使う（回り込まれたら解く）。逆脚の Bot は、最初は今の通り道をそのまま使う（高いジャンプ専用の道は足さない）。
- **高さの確認**：逆脚のジャンプ（約9m、溜めで約12m）で、今は登れない屋根・壁の上・マップの外へ出られないかを、今あるマップで調べて PR に書く。出られる所があればマップは直さず、場所の一覧を報告する（直すのはマップ製作スレッド）。

### 4. 出す

- 性能定義で付けた印を外し、機体カスタマイズの一覧に出す。脚の種類と特徴（例：「踏ん張り：しゃがみで射撃が安定」）が分かる説明を出す。
- オンライン対戦でも同じに動く（ホストの判定、ゲストの予測）。通信の形を変えたらプロトコルの番号を上げる。
- `docs/DESIGN.md` に脚の種類の節を足す。数値はオリジナルの仮置きと書く。

## 釣り合いの考え方

- 得意を1つ取ったら、速さか耐性で払う。四脚は重装二脚、逆脚は軽量二脚と比べる。
- 得意には相手が狙える隙を付ける。踏ん張り中の四脚は回り込みと格闘に弱い。逆脚は空中と着地を狙われる。
- 同じ武器で脚だけ変えた Bot 戦（各脚 同じ数、2マップ）で、生存時間・与ダメージ・撃破を比べた表を PR に載せる。どれかが二脚の 1.3倍を超える・0.7倍を下回るなら、数値を直す案を「決めたこと」に書く。

## 確かめること

- 新しい `tools/test/legs_kinds_check.js`（`lib.js` の `check`）：ジャンプの高さ、着地硬直、よろけの閾値、ばらつき、踏ん張り（止まる・押されない）、溜めジャンプ、アクションの倍率、Bot が選ぶこと、二脚とホバーが前と同じ動きであること。
- 形が変わるので `mech_shapes_check.js`、当たり判定の確認（頭・胴・腕・脚に撃つ）、`bot_battle.js dbg city,wide,mesa,dock 150`「エラー なし」。
- `quick_check.js origin/main`、今ある `hover_*_check.js`・`action_*_check.js`、オンラインの試験が通る。
- 機体カスタマイズの見本のスクリーンショット（四脚・逆脚×軽量・標準・重装の上半身）。
