# Codex に頼む作業

1ファイルが1つの作業（GitHub の Issue と同じ中身）。Codex への頼み方の例：

> docs/codex/tasks/2-weapons.md の作業をして。AGENTS.md と手順書に従い、終わったら PR を出して。PR のタイトルの頭に #2 を付けて。

| ファイル | Issue | 中身 |
|---|---|---|
| `1-map.md` | #1 | マップの自動生成のルーチンを作り、新しい地形と戦場3つ以上を入れる（設計書 `docs/codex/mapgen.md`） |
| `2-weapons.md` | #2 | アーケード版 wiki にあって本作に無い武器を調べ、形と性能まで作ってゲームに入れる |
| `3-parts.md` | #3 | 機体パーツの3シリーズにⅡ型・Ⅲ型を調べて足し、性能までゲームに入れる |
| `4-mech-shapes.md` | #4 | 機体の形を3シリーズで作り分ける |

1〜4 はどれも `prototype/index.html` を変える（1 の自動生成は地形の読み込みや Bot、速い対戦の仕組みまで変える）ので、1つずつ順に頼む（前の PR がマージされてから次）。
