# #227 脚の種類：四脚と逆脚の性能を定義し、形を試作する

## やること

新しい脚の種類「四脚」と「逆脚（逆関節）」の、性能の定義と形の試作をする（オーナーの了承 2026-11-10。案の全文は `docs/legs-plan.md` の「改訂案」）。**動きと、ゲームの機体（`buildMech`）への組み込みは#228**。この Issue では遊べる所に出さない。

四脚・逆脚はアーケード版に無い（二脚とホバーだけ）。数値は本作オリジナルの仮置きで、オーナーが例外として認めている。`research/` と `docs/DESIGN.md` に「オリジナルの仮置き」と書く。

### 脚の役割（4種が重ならないように）

| 脚 | 役割 |
|---|---|
| 二脚 | 何でもこなす基準 |
| ホバー | 横に速い（慣性、水上） |
| 四脚 | 止まって当てる移動砲台。重い・硬い・安定、遅い |
| 逆脚 | 縦に動く軽い脚。高く跳ぶ、薄い・積めない |

### 1. 性能の定義（`prototype/parts.js`）

シリーズを2つ足す。各4型。**全身のシリーズにする**（オーナーの指定 2026-11-11「全身作って」。最初の案は脚だけだった）：頭・胴・腕も各4型とセットボーナスを持ち、ほかのシリーズと混ぜられる。ドーザーは重量級（比べる相手はブルワーク）、ホッパーは軽量級（比べる相手はスウィフト）。頭・胴・腕はふつうのパーツと同じ項目だけで、特別な動きは脚だけ。頭・胴・肩の形もシリーズごとに作る。

頭・胴・腕の数値はアーケード版 wiki の表を換算する（オーナーの指定 2026-11-11：ドーザー＝ランドバルク、ホッパー＝フォーミュラ。換算はホバーと同じ。原表 `research/arcade/parts/quad-reverse-sources.md`）。脚の数値はオリジナルのまま（「脚性能はオリジナルで」）。セットボーナスも原表から（ドーザー 重量耐性 +150kg、ホッパー ダッシュ +0.72m/s）。

基準の型（Ⅰ型）：

| | kind | 重さ | 装甲 | 歩行 | ダッシュ | 巡航 | 重量耐性 |
|---|---|---:|---:|---:|---:|---:|---:|
| 四脚 | `quad` | 1350 | 0.80 | 4.6 | 18.0 | 17.0 | 6800 |
| 逆脚 | `reverse` | 800 | 1.15 | 6.8 | 22.0 | 19.0 | 4000 |

比べる相手は、四脚が重装二脚（1340kg・0.77・4.8・19.4・17.2・6450）、逆脚が軽量二脚（770kg・1.17・7.6・24.8・21.4・3700）。

脚の種類ごとの特性（型ごとに持たせ、#228 の動きが読む。名前は任せる）：

| 特性 | 四脚 | 逆脚 |
|---|---|---|
| 射撃のばらつき | ×0.8 | — |
| 反動（腕の反動吸収に掛ける） | ×0.7 | — |
| よろけ・ダウンの閾値 | ×1.3 | ×0.9 |
| 空中で浮くブースト消費 | ×0.6 | — |
| ジャンプの初速 | ×0.8 | ×1.15（高さ 約6.8m → 約9m） |
| 着地硬直が出る落下の速さ（`LAND_SPEED` 28） | — | 34 |
| 着地硬直の長さ | — | ×0.5 |
| 構える武器の構えの速さ | 速い（値は任せる） | — |
| タックル | 距離×0.6、威力×1.5 | 威力×0.8 |
| 蹴り | 威力×1.2 | 威力×1.5、空中の届く距離×2 |
| しゃがみ | 「踏ん張り」：止まる、ばらつき×0.6、押されない、よろけ閾値×1.5 | 「溜め」：0.3秒以上しゃがんでからジャンプで約12m、ジャンプのブースト2倍 |

Ⅱ〜Ⅳ型は、Ⅰ型から重さ・装甲・速さ・重量耐性・特性のどれかを入れ替えた物（1つ良くしたら1つ悪くする。各値は Ⅰ型の ±10% くらいまで）。中身は任せる。PR の「決めたこと」に表で書く。

名前とメーカー（案。画面に出す名前に公式の名称を使わない。`docs/codex/parts.md` の「名前の確認」をする）：四脚「タランチュラ」（ガルド重工）、逆脚「ホッパー」（シルフ精機）。今ある名前・キーと重なったら変えてよい。

**遊べる所に出さない**：型に印（例 `wip: true`）を付け、機体カスタマイズの一覧と Bot の機体選び（`botMech`）から外す。この2か所を外すための `index.html` の小さな変更は、この Issue に入れてよい。印を外すのは #228。

### 2. 形の試作（`media/` に比較ページ）

**形はオーナーが選んだ（2026-11-11）**。Claude の下描き `media/legs-proto/`（絵と、形を定義したコード `cap.js` の `__PROTO`）が元。

| 脚 | 今回の形 | 下描き |
|---|---|---|
| 四脚（重い移動砲台） | **B案（重機型）**：低い胴から太い柱の脚 | `quadB.png`・`__PROTO.quadB` |
| 逆脚（軽い跳ぶ脚） | **A案（2節）**：太い腿が後ろへ曲がり、細い脛が前へ戻る | `revA.png`・`__PROTO.revA` |

使わなかった案は捨てない。四脚 A案（蜘蛛型）は後で足す**軽量の四脚**、逆脚 B案（鳥の脚）は後で足す**中量の逆脚**に回す（オーナーの指定。この Issue では作らない。性能も決めない）。

やること：ホバーのとき（`media/hover-models/`）と同じ進め方で、採択した2つの形を仕上げる。ゲーム本体の `buildMech` はまだ変えない。

- 下描きは立ち姿だけの粗い箱。輪郭と釣り合いは保ったまま、今の機体の作り（面取りした装甲板、フレーム、関節、チームの色の帯）に合わせて作り込む。背中の武器や剣と脚が重ならないようにする。
- 軽量・標準・重装の上半身と混ぜた姿で並べ、回して見られるページとスクリーンショットを作る。立ち・歩き・しゃがみ（四脚は踏ん張り、逆脚は溜め）・ジャンプの姿勢も見せる。
- 箱などをコードで組む今の作り方。デザインはオリジナルで、公式や他の作品の機体に似せない。三角形の数はホバー脚と同じくらいまで。
- 当たり判定の考え：腰から上の高さは今と同じ。四脚は脚の当たりが横に広い（幅は約1.5倍まで）。逆脚は二脚と同じくらい。
- 後で軽量の四脚・中量の逆脚を足せるよう、形はシリーズごとに選べる作りにしておく（ホバーの3シリーズと同じ考え）。

仕上げた形をオーナーが見てから、#228 でゲームに入れる。
