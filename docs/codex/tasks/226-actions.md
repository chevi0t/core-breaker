# #226 アクション：C のアクションを選べるようにし、タックルと蹴りを足す

## やること

C キーのアクションは今「しゃがみ」だけ（`prototype/index.html` の「アクション」の節、`ACTIONS`・`actionUpdate`・`actionId`）。これを機体ごとに1つ選べるようにし、「タックル」と「蹴り」を足す（オーナーの了承 2026-11-10。案の全文は `docs/legs-plan.md` の「改訂案」）。

アーケード版 wiki のアクションの数値は確かめられていない。下の数値は本作オリジナルの仮置きで、試遊と Bot 戦で直す。定数にまとめ、`docs/DESIGN.md` に「仮置き」と書く。

### 1. アクションを選ぶ

- 機体カスタマイズに「アクション」の欄を足し、しゃがみ・タックル・蹴りから1つ選ぶ。機体の構成（3構成）ごとに保存する。
- 保存データ：今の構成に項目を1つ足すだけにする。項目が無い古い保存は「しゃがみ」として読む。今あるキーの名前と中身は変えない。
- Bot はランダムに選ぶ（しゃがみは今どおり自分からは使わない）。

### 2. タックル（C を押した瞬間に出る）

| 項目 | 値 |
|---|---|
| 動き | 向いている方へ 8m を 0.35秒で突進。地上だけ。向きは途中で変えられない |
| ブースト | 20 使う（足りない・オーバーヒート中は出ない） |
| 当たり | 機体の前面。最初に当たった敵1機で止まる。壁でも止まる |
| ダメージ | 2000 × √(自分の総重量 ÷ 相手の総重量)。倍率は 0.7〜1.4 に収める |
| 崩し | 当たれば必ずよろけ（格闘扱い）。重さの比が 1.25 以上、または相手がスタンガン・スタン系で動けない間（`electricT`・`shockT`）ならダウン |
| 隙 | 当てたら 0.5秒、外したら 0.9秒、動けない・撃てない |
| 再使用 | 3秒 |

### 3. 蹴り（C を押した瞬間に出る）

| 項目 | 値 |
|---|---|
| 動き | その場で前へ蹴る。出るまで 0.2秒。前方 3m・左右 90° の扇 |
| ブースト | 10 使う |
| ダメージ | 1200。扇の中の敵すべて |
| 崩し | 必ずよろけ、6m 押し出す |
| 空中 | 空中で出すと斜め下（約45°）へ 6m の跳び蹴り。当たればダウン。外すと着地で 0.6秒の硬直 |
| 隙 | 0.4秒 |
| 再使用 | 1.5秒 |

### 4. 共通

- しゃがみは今のまま（C を押している間）。ダッシュ中の制動、ホバーの急降下（空中で C）も今のまま。タックル・蹴りを選んだ機体では、ホバーの急降下だけは空中で C を**押し続ける**と出るように残す（蹴りは押した瞬間、急降下は 0.25秒以上の長押し）。
- 出せない時：しゃがみが出せない時と同じ（リペアポッド、構え、転送、行動不能、格闘の最中など）。
- 脚の種類ごとの倍率を掛けられる作りにする（`PARTS.legs[型].kind` → 距離・威力の倍率の表）。今回入れる値はホバーだけ：タックルの距離 1.3倍・威力 0.8倍、蹴りの威力 0.8倍。四脚・逆脚の値は #228 で足す。
- よろけ・ダウンは今の `jolt` を使う。よろけの連続（スタンガンからのつなぎ）は止めない（オーナーの決定）。味方には当たらない。コア・施設・設置物には効かない。
- Bot もプレイヤーと同じルールで使う：敵が届く距離にいて、相手が構えている・スタン中・格闘を振った後などに出す。使いすぎないよう確率を付ける。
- HUD：再使用までの時間が分かる小さな表示（今のゲージの邪魔にならない所）。
- 効果音は今ある音（格闘・ダッシュ）を使う。外の素材を足さない。
- 見た目：タックルは肩を前に出す姿勢、蹴りは片脚を前へ出す姿勢（ホバーは機体ごと前へ突き出す）。今の骨で作る。
- オンライン対戦：ホストが判定する今の作りのまま、ゲストでも出せること。C の入力はもう送っている。選んだアクションを装備と一緒に送る。通信の形を変えたらプロトコルの番号を上げる。
- タッチ操作とゲームパッドには、今回ボタンを足さない（しゃがみにも無い）。

## 釣り合いの考え方

タックルと蹴りは「削る」技ではなく「崩す」技。ソード（横なぎ 6000）よりずっと弱く、作った隙から射撃や格闘へつなぐ。連打は再使用時間とブーストで止める。数値を変えたくなったら PR の「決めたこと」に書く。

## 守ること

- AGENTS.md の「変えてはいけないこと」。特に Bot も同じルール、リペアポッドの使用中は何もできない。
- 今の格闘武器・しゃがみ・ホバーの数値と動きを変えない。
