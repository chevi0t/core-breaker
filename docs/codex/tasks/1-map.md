# #1 マップ：新しいマップを1つ作る（テーマから Bot の動きまで任せる）

## やること

新しいマップを1つ作り、ゲームで遊べるようにする。手順は `docs/codex/map.md` に沿う。

オーナーの指定（2026-10-19）：**テーマ・名前・大きさ・人数・試合時間・プラントの数と配置・地形・施設の置き場所から、Bot の通り道と動き方（Bot のルール）まで、作る人が決めてよい**。決めたことと理由を `mapdesign/<id>/README.md` と PR の説明に書く。

今あるマップ（台地演習場＝5対5の台地、広域演習場＝10対10の演習場、丘の市街地＝10対10の川と城のある街、港の倉庫街＝2対2のコスト制）と似すぎないテーマにする。

## 守ること

- `prototype/maps/RULES.md` で「ユーザー指定」と書いた決まり（`docs/codex/map.md` の冒頭にまとめた）。
- 名前はオリジナル。元のゲームのマップ名・地名・形はそのまま使わない。
- 道路・広場・住宅地は平らに（`paved`）、起伏は `tools/gen_rough.py` で付ける。
- Bot もプレイヤーと同じルールで動く。Bot の動きのためにエンジン（`botUpdate` など）を変えるなら、そのマップの項目が無い今のマップの動きを変えない。

## 確かめること（`docs/codex/map.md` の 5・7）

- `python3 tools/build_maps.py` が通る。
- `node tools/test/map_check.js dbg <id>` で★が無い。隠すポッドは敵陣側から0か所。
- `node tools/test/bot_battle.js dbg <id> 150` で「エラー なし」、両軍に撃破があり、プラントの持ち主が試合中に変わる。エンジンを変えたら今の4マップでも回す。
- 上から見た図と、map_check のスクリーンショットを `mapdesign/<id>/` に置き、PR に載せる。

PR は Claude が確かめて承認・マージする。
