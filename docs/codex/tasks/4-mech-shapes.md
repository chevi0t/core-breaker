# #4 モデル：機体の形を3シリーズで作り分ける

## やること

今の機体（`prototype/index.html` の `buildMech`）は、どのシリーズも同じ箱の組み合わせを大きさで変えているだけ。スウィフト（軽量）・ハウンド（標準）・ブルワーク（重装）の頭・胴・腕・脚を、見ただけでシリーズが分かる形に作り分ける。

- スウィフト（シルフ精機）：細身で尖った形、薄い装甲板、脚は細く長め。
- ハウンド（ガルド重工）：釣り合いの取れた標準の形。
- ブルワーク（ガルド重工）：太く角張った形、厚い装甲板と肩の盾、脚は太い。
- デザインはオリジナル。元のゲームの機体に似せない。

## 守ること

- 形はコードで作る（外部ファイルの読み込み無し）。今と同じく箱などを組み合わせ、部位ごとに1つのメッシュにまとめる。
- 当たり判定は部位ごと（メッシュの `userData.armorSlot`）。頭の高さ（3.2〜3.95m）、胴・脚の高さ、全体の幅を大きく変えない。ヘッドショットとロックオン（`LOCK_BODY`）がそれに合わせてある。
- 色：装甲は塗装（`PAINTS`）かチームの色、チームの色の細い帯を残す。武器を持つ位置（`gun`・`gun2`・`blade`・背中の装置）は今の位置から動かさないか、動かすなら銃口（`muzzle`）も合わせる。
- 部位を混ぜた組み合わせ（頭はスウィフト、脚はブルワークなど）でも破綻しない。
- 箱の数は今の1.5倍くらいまで（10対10で重くならないように）。
- #3 が先にマージされていたら、型のキーではなくシリーズ（`PARTS[部位][型].series`）で形を選ぶ。

## 確かめること

- 機体カスタマイズの回る見本で、3シリーズと混ぜた組み合わせのスクリーンショットを PR に載せる。
- `node tools/test/bot_battle.js dbg city,wide,mesa,dock 150` で「エラー なし」。
- ヘッドショットが頭に当たったときだけ出ること（`docs/DESIGN.md` 第8章のやり方で、頭・胴に撃って確かめる）。

手引きは `docs/codex/parts.md` の「今の作り」。PR は Claude が確かめて承認・マージする。
