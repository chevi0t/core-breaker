# マップ設計の知識台帳

次のマップを作る前に読む。狙った戦い方が成立しなかった理由と、次回の生成・検査で確かめることを蓄積する。原設計書 `docs/codex/mapgen.md` の方針そのものと、その方針を十分に検証できていない実装を混同しない。

記録は「仮説 → 観測事実 → 解釈の限界 → 次の設計・検査 → 採否と証拠」の順で残す。古い失敗も削除せず、改善で否定された仮説は結果を追記する。結果にはエンジン・地形・配置・検証器の版、seed、試合数、初期編成、変更した要素を付ける。以下のIDは後続マップでも引用する。

## 次の生成で使う確認順

M34（2026-10-23）：都市の道路は「道路データがある点」の高さ誤差だけでは確認不足。南北線の下は道路面の欠測と低い橋片が混在し、同じ72通りの実走で32通りが通れなかった。路面を連続面へ補修し、古い部品を除くと72通りすべて通行した。地面・道路・橋の重なりと欠測、走行帯の中央/両端、往復を同じ物理で検査する。高架切断後の建物細片と、盛土の陰影がガタつきに見えることも分けて調べる。[比較と適用範囲](akihabara_city/trial/README.md)。

1. 狙う交戦と、前進・迂回・撤退・補給・防衛の経路を先に定義する（M03/M06）。最短路と退避路が同じ長い射線に晒されていないかを見る。
2. 高さと施設を含む接続を実物理で通す（M01/M02/M28）。通常歩行の経路と特殊移動を区別し、両軍・複数機体で確かめる。街区は用途に合う自然な一段目から屋根へ上がり、隣の屋根または地上へ抜けられるかを確認する。建屋の高さを波状に並べることで代用しない。
3. 施設の安全性と、各陣営が所有した場合の再出撃位置を検査する。配置ごとに移動施設を再評価し、基地初動・前線からの前進・再出撃からの再合流を機体別に実測する。リフトの待機・乗降と目標の床への到着を分け、開始位相も振る。プラント座標や基地からの1条件だけでアクセス条件を比較しない（M03/M27）。
4. 編成入替と同じ初期状態で対照比較し、直接攻撃・大破・目標の変化を分解する（M04/M05/M07）。勝敗だけを最適化しない。
5. リプレイで「想定した経路が利用されたか」を確認する（M06）。利用・生還を測っていなければ、その効果は未確認と書く。
6. 採用・棄却の両方を実験記録へ残し、次の試作では別seed・未使用の編成でも試す。原設計書の200〜2,000戦・複数戦術による最終選抜は別段階。
