# 橙寄りの結果の切り分け：Bot初期化

既存の対戦器は青1をプレイヤーとして生成し、後から `isPlayer=false` にしていた。機体は保存済みプレイヤー構成のまま、初動も `spawn` でベースへ戻すため、通常Botの機体抽選と `botSpawn(first=true)` のカタパルト選択を通っていなかった。橙1は通常Botで、ここに条件の差があった。これだけで過去の勝率の原因を確定したとは扱わない。

検査用HTMLにだけ通常Bot生成のフラグを設け、対戦器と記録器は青1も最初から `makeUnit(...,false,0)` で作る。通常のゲーム・操作用デバッグはプレイヤーのまま。機体モデルと当たり判定も本体の生成処理を使う。

mainのv0.18（名前・耐久バー・損傷の見た目、a39ac62）を取り込み、同じエンジン・地形で旧初期化と通常Bot初期化を各戦場4試合ずつ比較する。初期乱数は前回の20261071〜20261082を使用。初期化で乱数の消費数が変わるため、同じシードでも装備・戦闘の乱数列は一致しない。1試合ずつ勝敗が反転したことを修正の因果効果として扱わない。

コアの直接攻撃と大破による減少を分け、実際のHP差と照合する。結果を見て、装備構成の入替比較・プラント配置・迎撃できる凸ルートのどれを先に検証するか決める。地形はこの比較では変更しない。陣営バランスは勝率未確定。

## 実時間の音と乱数

同じ初期化・シードの通常対戦器と記録器で、初期状態が完全一致しても終局が一致しないことを確認した。音の `sfx` は再生中の音数・デコード完了・AudioContextの実時間で再生を制限し、再生する場合だけ `Math.random()` でピッチを変えていた。戦闘も同じ乱数列を使うため、壁時計の進み方で後続の乱数列が変わる。

高速対戦器と記録器は読み込み前にAudioContextを無効にし、検証時だけ無音にする。通常のゲームと、`openMap` の指定なしの動作は変更しない。`silent` を初期化記録に残す。同じシードでブラウザ呼出しを400フレーム一括/100フレームごとに変え、20秒・全10機の位置・速度・耐久・生死とコアの状態列が完全一致することを検査した。

音ありで先に実行した比較とリプレイは `unmuted/` に保存する。最終の比較は `legacy.json`（旧初期化＋無音）と `ordinary.json`（通常Bot初期化＋無音）だけを使う。過去の音ありの戦績と混ぜない。

## 無音で比較し直した結果

各セルは4試合の「青勝－橙勝」。引き分けなし、全24試合300秒完走、エラー0。全試合でコア被害内訳が実際のHP差と一致した。

| 戦場 | 旧初期化＋無音 | 通常Bot生成＋無音 |
|---|---:|---:|
| 昇降交差 | 1－3 | 1－3 |
| 高架縦断 | 2－2 | 2－2 |
| 片翼争奪 | 2－2 | 1－3 |

通常Bot生成に修正しても、今回の観測では昇降交差・片翼争奪の橙寄りが残った。修正で有利不利が解消したとは扱わない。各4試合であり、抽選される構成も変わるため、旧/新の勝敗の差を初期化だけの因果効果としては扱わない。

通常Bot生成の4試合合計で、直接攻撃により**削ったコア耐久**は以下のとおり。大破は自軍コアが失う耐久。両者を足して勝敗を判定する。

| 戦場 | 青が直接削った量 | 橙が直接削った量 | 青の大破損失 | 橙の大破損失 |
|---|---:|---:|---:|---:|
| 昇降交差 | 0 | 1,851 | 8,718.75 | 6,975 |
| 高架縦断 | 160 | 80 | 8,662.5 | 8,437.5 |
| 片翼争奪 | 3,044 | 92 | 8,493.75 | 7,706.25 |

片翼争奪では青が大きくコアを削った試合もあり、橙の3勝をすべて「橙の凸が強すぎる」で説明できない。2試合は両軍の直接攻撃が0で、大破による差だけで決着した。直接攻撃が多い1勝が合計値を大きく動かす点にも注意する。

[全条件と集計](summary.json)・[通常Bot12戦](ordinary.json)・[旧初期化12戦](legacy.json)を保存。旧v0.17・音ありの戦績とは別集計。

## 修正案の優先順

以下は比較結果から絞った**次のマップ修正候補**で、この比較ではまだ採用していない。1案ずつ、同じBot構成を陣営入替した条件で変更前後を比較する。

1. **昇降交差：青ベース手前で迎撃できる凸ルートにする。** 今回は橙だけが直接攻撃を通し、大破差も青が大きい。侵入前に射線が通る区間と防衛側が移動できる横道を確保する。カタパルト着地後の進路も比較する。
2. **片翼争奪：青の中央進軍路で退避・補給へ戻りやすくする。** 直接攻撃は青の合計が上回る一方、大破損失は青が大きい。まず中央から北へ進む経路の遮蔽物と退避できる横道を候補にする。中央のプラント位置も候補だが、移動と遮蔽を同時には変えない。
3. **高架縦断：現状を比較基準として保つ。** 4戦ずつでは五分だったため、先に残る2戦場の偏りを扱う。
