# 片翼争奪を目視で検証する

[replay.html](replay.html) は対戦データを同梱した閲覧用HTML。保存してブラウザで開けば動き、サーバーや外部ライブラリは不要。

1. 試合を選び、「再生」。速度と時間のスライダーで一時停止・巻き戻しできる。
2. 「場面を探す」のコア命中や敵ベース侵入を押すと、攻撃機を選択して8秒前へ戻る。
   「青／橙の最初の凸」は、最初にコアへ命中した機体の出撃時点へ戻る。
3. 軌跡を「今の出撃から」にすると、その機体がどのプラントから出てどの道を通ったか見られる。出撃・エリア移動の前後は線でつながない。
4. 右側で、コア減少を「敵の直接攻撃」と「自軍機の大破」に分けて確認する。下の時間軸にはコア残量と各プラントの所有状態が並ぶ。

[preview.mp4](preview.mp4) は2試合目を5倍速にした約1分の動画。[preview.png](preview.png) は操作画面の例。

## 何を記録したか

過去13試合には位置が残っていないため、同じ片翼争奪で**新たに3試合**を実行して保存した。過去13試合の映像を推定・再現したものではない。ジャンプパッド・リフトを追加する**前**のエンジンで記録し、実行したソースと観測器のハッシュを `recorded.json` に残す。新設備の変更と元の勝敗を混ぜない。

- 位置・高さ・生死・出撃の区切り・所有状態：0.25秒刻み。再生中の機体の位置だけは、同じ出撃で生存中の前後の標本を補間する。
- コアへの直接命中・大破によるコア減少・再出撃とエリア移動・敵ベース侵入・プラントの所有者変更：0.05秒刻み。HPは実際の代入前後の差を記録し、被害の内訳が終局HPの減少と一致することを3試合とも検査した。
- 命中イベントの機体位置は**命中した時点の攻撃機の現在位置**。発射地点や弾道を表すものではない。侵入回数は敵ベース境界を越えるたびに数え、同じ出撃でも一度出て入れば再計上する。
- 全機の軌跡は検証用の全情報表示。ゲーム中のBotへ敵の位置情報を追加してはいない。

## 新たに記録する

```sh
python3 tools/test/make_dbg.py dbg --trace
node tools/test/record_battle.js dbg circulation-v3 dbg/replay-new 20261060,20261061,20261062
```

生成したHTMLは記録だけを使って再生し、閲覧のたびにゲームを再シミュレーションしない。初期乱数だけで過去の試合を完全再現できるとはしていない。`--trace` はデバッグ版に観測イベントを加えるための指定で、本体のゲーム計算・乱数を置き換えない。
