# 摩天街区 — OSM 市街地の試作

ユーザー指定（2026-10-22）：新宿・都庁周辺を題材に、起伏を後回しにした市街地を作る。大通り・屋上の遮蔽物、プラント、基地を追加する。

街区600×700mを4m格子へ変換し、街区の外に両基地を置いた。戦場全体は648×1100m、10対10・600秒。107件の建物形状を500個の箱へ変換した。道路の遮蔽6群と基地の防壁6個を含む移動判定は計512箱。道路の表示は1メッシュ、建物の壁と屋根の表示は2メッシュへまとめる。

機体の判定高は4m。初期機体の表示モデルを測ると3.982m。建物の高さは53件が `height`、29件が階数、25件が既定値に基づく。最高点243m。屋上へのジップラインは4本で、高さ120〜143.9mへ7.85〜9.35秒で到着する。屋内・地下・立体交差は再現していない。

## 再生成

入力は https://api.openstreetmap.org/api/0.6/map?bbox=139.6865,35.6855,139.6960,35.6940 で取得した OSM XML。入力の SHA-256 は `validation.json` に記録する。OSM は更新されるため、再取得した入力が同じになる保証はない。

```sh
python3 tools/mapgen_osm.py source.osm --id osm_city --output mapdesign/osm_city/osm_city.js
python3 tools/build_maps.py --check mapdesign/osm_city/osm_city.js
python3 tools/test/osm_import_check.py
python3 tools/test/make_dbg.py dbg/osm-city
node tools/test/osm_city_check.js dbg/osm-city mapdesign/osm_city/osm_city.json /tmp/osm-check
```

マップはここに置いた開発候補で、`prototype/maps.js` と既存マップへは登録していない。変換仕様は [調査記録](../../research/maps/osm-city.md)、地理データの利用条件は [CREDITS.md](CREDITS.md)。入力OSMと変換器を含む試作用HTML一式も作成した。

## 確認結果

- XML・高さの単位・地下除外・分割輪郭・格子の統合の4試験に成功。
- マップの構造検査は既存7マップと候補を含め成功。
- 本体の物理・射撃で3,244件を確認。軽量/重量・両軍の24徒歩経路、8件の屋上着地、8件のカタパルト着地に成功。舗装を射撃障害物にせず、道路と屋上の追加遮蔽が射線を遮ることも確認した。
- 10対10の本体Botを150秒進め、両軍の撃破とプラントの所有権変化を確認。詳細は `validation.json`。1試合の機能検査で、公平さの判断には使わない。
- `quick_check.js 3ec940b` は武器・パーツの差分なし、既存city/dock各60秒で成功。照準・反動・武器性能は変更していない。
- 試作用HTMLはデバッグ用の読み口を含まず、オフラインでマップ選択・出撃・移動・ガトリング射撃に成功。弾数380→378、ブラウザのエラー0、外部通信0。

補給点を敵側から隠す検査は地上の15m格子で各187か所中0。屋上からの全射線を網羅した検査ではない。両端補給所は屋根も設ける。3戦場の自律選抜、編成入替の比較、200〜2000試合の統計評価は未実施。ブラウザで直接OSMを選んで変換する画面も、今回の開発用CLIとは別の段階。
