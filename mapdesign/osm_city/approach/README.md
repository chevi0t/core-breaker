# 中央Bへの到着差と補正案（B移設を採用）

ユーザーの相談（2026-10-22）：中央Bへの到着差をカタパルトで埋められるか、またはBを青側へ少し寄せられるか。第5配置を基準に比較した。ユーザーの「それでお願いします」により、B移設を第6配置として採用した。射出先変更案は比較用の記録として残す。

青側は基地前からB付近までの直線距離が369.7m、経路グラフの徒歩距離が517.4m。橙側は直線321.8m、徒歩402.2m。青の直線距離が47.9m長く、南側のビルを回る経路によって迂回も67.3m多い。合計約115mの差がある。

## 比較結果

初期の強襲装備を固定し、全身軽量・全身重量を各1回、同じ比率で平均する。基地前の固定点からB付近まで、ブースト・戦闘なし。カタパルトは乗り場への徒歩、無入力の飛行、着地後の硬直と徒歩を合算する。

| 条件 | 青平均 | 橙平均 | 差 |
|---|---:|---:|---|
| 第5配置のB・徒歩 | 39.7秒 | 30.9秒 | 橙が8.9秒早い |
| 第5配置のB・既存カタパルト | 36.6秒 | 26.0秒 | 橙が10.6秒早い |
| 第5配置のB・青の射出先を変更 | 25.8秒 | 26.0秒 | 青が0.2秒早い |
| B移設（第6配置）・徒歩 | 35.4秒 | 35.5秒 | 青が0.1秒早い |
| B移設（第6配置）・既存カタパルト | 32.3秒 | 30.6秒 | 橙が1.7秒早い |

徒歩経路を測った旧記録はBotの装備抽選を含む。今回の表は武器重量まで両軍で固定した再計測で、以前の41.1秒/31.9秒と条件が異なる。旧記録はそのまま残し、この比較の基準値は今回の39.7秒/30.9秒とする。

- B移設案：(48,-12)→(60,44)。図の下へ56m・右へ12m、移動量は約57m。中央の建物を避けて街路内へ置く。占拠域9点と両軍の出撃帯各9点を本体の地形・障害物で確認し、両軍・両機体の実移動にも成功。候補の経路は現行生成器の通行検査で作り直している。A・C・基地・地形は同じ。
- カタパルト案：青基地の右側乗り場(-218,230)の着地点を(-100,180)→(32,250)へ変える。橙は既存の右側台を使う。各軍とも左右の台を実測し、平均の短い台同士で比較。Bへ直行せず、飛行後も徒歩が約17秒/27.6秒（軽量/重量）残る。両機体とも実際の物理で着地に成功した。着地点を前に出しすぎた候補は高層ビルに遮られ、採用候補から外した。

B移設は徒歩と既存カタパルトの双方で差が縮むため、第6配置で採用した。カタパルト案とB移設案は別々に測っており、併用の結果ではない。ブーストを含む初動と対戦全体の公平さは未検証。採用データで実移動とBot対戦を検査し、結果は上位の `validation.json` に記録する。候補JSONと比較図は検討時点の保存用データ。
