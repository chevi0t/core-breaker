# 風裂山道：レシピ生成MVP

狙いは高低差・上下通路・非矩形外周を、他のAIが編集できるJSONから再生成すること。原作の施設配置・画像・モデルは取り込まない。公式の山岳画像から谷底・岩盤上・岩盤下・人工橋という関係を参考にした。

5対5、5分。中央谷底、左の山腹、右の尾根の3経路。横断橋の下は谷底を歩ける。右の岩盤は横向きトンネルを貫通し、同じXZ上の天面も歩ける。凹みのある外周は地形の穴とは別に制限する。

既存の city-layout-v1 の三角形・体積・nav・基地施設とカメラを利用する。生成器は地下床をdem、天面と天井・側壁をbridへ分類し、地下床をterrainHで屋根へ持ち上げない。外周だけ任意のpolygon制限を追加する。テーマ名による本体分岐は設けない。

M01/M02（経路は実物理で確認）、M27（機体と出発位置を分ける）、M29（着地だけでなく退出まで検査）の教訓を使う。今回の目標は生成・再現・到達のMVP。完全自律最適化、3つの公平な戦場、200〜2000戦の統計合格は未達の別段階。

実装・実測・再生成手順は [TERRAIN_RECIPES.md](../../docs/TERRAIN_RECIPES.md)。坑道入口の閉塞と屋根縁の段差を生成段階で修正し、28経路実走と標本脱出66回を通過。通常BOT戦と施設検査も通過したが、勝率・楽しさの調整は未実施。上下通路の再利用はquarry/urbanレシピ各3seedでも実走確認した。公式参照は https://borderbreak.com/map/4#opr-19 。配布する地形・画像に公式素材は含めない。

斜面改訂後のプラント／ベースアクセスは [TERRAIN_ACCESS.md](../../docs/TERRAIN_ACCESS.md) に記録。中立Bを中央へ戻し、両基地の左右入口を見える防壁で作る。基地距離だけでなく再出撃からの到達も比較した。対人勝率は未評価。

最新の1.5倍拡張・低角カタパルトは [TERRAIN_STRETCH.md](../../docs/TERRAIN_STRETCH.md)。コア間555m、横幅維持。以前の距離・時間は履歴として参照。
