# 翠河城下・地形試作（ローカル）

ユーザー指定の旧ブロア市街地「熱戦の河畔」を地形・経路の基準とする。公式参照は https://borderbreak.com/map/2#opr-3 、俯瞰 https://borderbreak.com/content/map/bIt9XY4uxe5Gs1lvtH.jpg 。別作戦153のバリケードや施設配置は取り込まない。公式画像・モデルはゲームデータへ同梱しない。ゲーム内の名称・形状データは自作。

観察：左右に高台ベース、中央を北西から南東へ流れる川、左の丘陵と小街区、右の大きな城下と丸い高台街区、北側の扇形の城高台。中央主橋の下は複数アーチ、下流に細い渡河路。川底・河岸通路から街路へ上る坂。左右を鏡像化しない。

推定：原図は斜め俯瞰であり、画像のピクセルを実測の平面距離とは扱わない。10mグリッドを目安に仮の平面登録を行った（画像u,vからゲームx=(v-550)*0.85、z=(800-u)*0.65）。各輪郭・道路・建物は手で読んだ点をレシピ化。標高は画像からの相対関係に基づく仮値：川床-2m、水面-0.5m、街路10〜14m、西丘24m、東丘32m、西基地40m、東基地48m、城60m。数値の正確な復元は主張しない。

`tools/terrain_recipes/river_castle.json` → `node tools/terrain_recipe.js tools/terrain_recipes/river_castle.json prototype/maps/river_castle.js` → `python3 tools/build_maps.py`。

共通生成器に斜め外周、手描き標高領域、河川、アーチ橋を追加。既存の支持面・衝突・nav形式を使う。高さ乱数は使わない。建物は個別の位置・寸法を持つ簡略プレースホルダーで、厳密な間取り・屋根形・建物数は未再現。現段階の足りない部分と実走結果はレビュー資料に記録する。公開マップの差替・push・PR・マージ・公開は未承認。
