# 市街地マップ：必須要素の分析（第2版）

ユーザーの希望（2026-10-18）：「高低差があって都市に見えて、ボトルネックになる激戦区と迂回ルートがあって、プラントとカタパルトの配置次第でマップのバリエーションを増やせる」。
参考：元のゲームの市街地マップ（〜激戦の丘〜）の全体図と景色2枚（ユーザーが貼ったもの、research/map2/ に保存）。公式のマップ名・地名・形はそのまま使わず、作りの考え方だけ借りる。

## 1. 参考マップから読み取れたこと

| 見どころ | 中身 | 何の役 |
|---|---|---|
| 横長、ベースは両端の高台 | ベースは壁で囲まれた台地。街へは坂で下りる | ベースの守りやすさ |
| 中央の丘（副題の「激戦の丘」） | 中央に盛り上がった丘。上に建物と広場、周りを坂道が巻く。ここのプラントが「敵ベース攻略の足がかり」 | **激戦区**。全員がここを通るか、ここから撃たれる |
| 川と橋 | 斜めに流れる川で街が2つに分かれ、渡れる所は中央の橋2本に絞られる | **ボトルネック**その2 |
| 北の城 | いちばん高い所に城と城下町。プラントあり | 見下ろし・狙撃の場所、北の**迂回ルート** |
| 水道橋 | 中央の丘から山肌へアーチ橋。上を歩け、下をくぐれる | 高い所を通る近道／迂回路 |

## 2. 必須要素（作るもの）

1. **高低差3段**：川（低い）・街（地上）・中央の丘と城（高い、約15〜25m）。段の間は坂道、水道橋、カタパルトでつなぐ。今の地形（`block`・`ramp`・`mesa`・`trench`）で作れる。
2. **激戦区**：中央の丘。坂道は2〜3本に絞る。丘の上にプラント。
3. **ボトルネック**：川を渡る橋2本（川は `trench` で作れる。水の見た目は無い）。
4. **迂回ルート**：北（城・高い所、遠回り）と南（崖沿い、細い道）。
5. **街並み**：家の箱を密に並べ、路地を作る。
6. **配置違い**：同じ地形で、プラントとカタパルトだけ変えた版（副題で区別）。
7. 守る決まり：プラントの後ろの隠れたポッド、再出撃は自軍側へ46〜52m、ベースのカタパルト左右2基、レーダーは左奥。

## 3. エンジン側に頼むこと（優先順）

| # | 中身 | 無いとどうなるか |
|---|---|---|
| ① | Botの通り道（マップに経路の点を書く） | Botが街区で引っかかり、迂回路も使わない |
| ② | 建物の見た目（切妻屋根・窓・壁の色） | 灰色の箱の街になる |
| ③ | 配置違い（`variants`） | 版ごとに地形を写した別ファイルで代用（できる） |
| ④ | くぐれる高架（水道橋・橋） | 橋の下を通れない。土手の上の道で代用 |
| ⑤ | 水の見た目（川の面） | 川が窪地にしか見えない |
| ⑥ | 左右非対称のマップ（今は点対称だけ） | 両陣営が同じ地形になる |
| ⑦ | リフト | 坂かカタパルトで代用 |

## 4. 決めたいこと

- **対称か非対称か**：参考は左右で地形が違うが、今のエンジンは点対称だけで、非対称は公平さとBotの調整が難しい。案は「まず点対称で作り（丘・川・城・水道橋・崖道は両側にある形）、非対称は後で別の版にする」。
- 大きさと人数：参考の格子から見て、今の広域演習場（600m）と同じくらいかやや長い。10対10・プラント5〜6を案とする。
