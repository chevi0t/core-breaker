# 星路西街区・再構築の確定方針

2026-10-24のオーナー指定。現試遊版の次に作る地形の条件をまとめる。容量と脱出不能な穴の扱いは今回の追加指示を優先する。元の取得・地形確認・100KB試遊版は比較用の履歴として保持する。

## 容量

マップの目安は**約250KB（250,000B）まで**。非圧縮の生成マップJS全体で数え、背景・接触形状・施設・再出撃点・BOT経路を含む。ゲーム本体・音・Three.jsを含む単独HTML全体の容量とは区別する。

設定は`research/maps/hoshimichi-west-rebuild-policy.json`。現在の対戦用生成器もこの値を参照する。旧取得プロファイルの`maximumLayoutBytes:100000`は過去の地形案を再現するための値で、次回の完成マップ全体の上限ではない。容量のために必要な通路や安全な退出を先に削らない。

## 地形と設備の構成

1. 2基地とA〜Eの大まかな位置関係は引き継ぐ。街や道路を非線形に曲げず、切り取り枠を回転させた半縮尺を使う。
2. 標高格子が出ている川岸を、元の川筋を保ちながら滑らかに再構築する。水面・川底・岸・橋と接触形状をそろえる。
3. 道路と残す通り抜けを先に確保し、区画の内側を基本1〜3個の単純な建物へまとめる。ランドマークは独立して残す。広い路地まで一括して潰さない。
4. カタパルトは**青：基地→A→B、橙：基地→E→D**。Cへは第二プラントから地上・高架で進む構成にする。各段階の台・着地点を分け、占拠円や柱、補給の動線を空ける。
5. 場外背景も同じ街区の輪郭から作り、さらに面数と屋根の段数を減らす。低い街並みを基本に、高層の目印を必要な数だけ残す。複数建物を最高高さの巨大な箱でまとめる方法は採用しない。

## 上空から落ち込む穴は残さない

カタパルトで上空を飛ぶため、**地上から入れないことを理由に、脱出不能な凹地を残してはいけない**。

- 対象は予定の着地点だけでなく、空中操作・途中着地・落下で届く屋上、中庭、屋根のくぼみ、建物と高架の隙間、段差の底など。
- 街路へ戻れない穴は、周囲の屋根や床へ高さを合わせて埋めるか、開口を床で塞ぐ。見た目の板だけを置かず、接触形状も同じ高さ・輪郭にする。
- 必要な補給用の窪地などを残す場合は、徒歩や斜面で確実に出入りできる出口を持たせる。カタパルトへの再乗車、自爆・再出撃、高所からしか使えない移動手段を退出方法として数えない。
- 河川、必要な道路・路地、意図した高架下の通路まで埋めない。深さや屋根の段差が戦術上不要な部分を平坦化する。

## 確認方法と順序

**地形だけを再構築→3D俯瞰→実機体で通行・着地・退出→基地とプラント→移動設備・BOT経路→対戦確認**の順に進める。

予定の着地点の中心に加えて、周辺の縁、途中の屋上、操舵でずれた先を調べる。着地した後は最初の屋根を越えるだけで合格にせず、街路へ戻るまで実走する。軽量・重量機、ブースト残量が少ない場合、機体が障害物に接して着地する場合も確認する。

M01/M02（実物理と階層接続）、M19/M29（高所からの退出）、M30/M31（射出後の操作・慣性）、M35（容量と通行の合格を外観の完成と混同しない）を引き継ぐ。今回保存したのは再構築の要件であり、現試遊版の全屋上・全凹地を検査済みとは扱わない。
