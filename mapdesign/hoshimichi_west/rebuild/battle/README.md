# 再構築した星路西街区・設備配置版

2026-10-25（日本時間）。PLATEAUから組み直した街区へ、オーナー指定の基地・プラント・カタパルト・ジャンプパッドを設置した。名前は星路西街区、登録元IDは`hoshimichi_west`。既定10対10・10分、進入範囲700×350m・背景900×550m・全軸1/2。人数の共通メニューは従来どおり使う。

## 配置と狙い

| 設備 | 数・位置・使い方 |
|---|---|
| ベース | 青(-307,122)、橙(307,-122)。承認済みの平地区画とコア位置を維持 |
| プラント | A(-200,95)・B(-100,5)・C(35,45)・D(100,-45)・E(245,-50)。Aは青、Eは橙、B/C/Dは中立 |
| カタパルト | 基地ごとに左右2基ずつ、計8基で第一プラント付近へ。A→B・E→Dに各1基追加、合計10基。Cへ直行させず段階的に前進 |
| ジャンプパッド | 西側4基・東側4基、合計8基を共有。既存の屋根・高架へ垂直射出し、空中操作と歩行で別の街路へ抜ける |
| 防衛・補給 | 各ベースに砲台4基・レーダー1基・補給2基。A/Eの自軍側には高さ5mの遮蔽・深さ2mの補給窪地と徒歩用斜面 |

10基のカタパルトはすべて飛行時間4.6秒、理論上の上昇約90mの高角射出。台・着地点は占拠円、補給の入口、再出撃点から離す。4基の基地台は第一プラントから19〜48mの街路へ分散して降ろす。敵を含め、どちらの陣営でも使える。

パッドは屋根の高さ12.5〜60mに合わせて上昇44〜92mに設定した。射出時の水平初速は0で、ブーストを使わなくても通常の空中操作で屋根へ届く。着地後はジャンプ・ブーストなしで街路まで下りられる候補を採用した。片側だけに基地専用の強い台は置かない。位置・屋上の目標・退出先は`generation.json`の`jumpRoutes`に保存した。

プラントの柱以外は占拠円を空け、再出撃は各プラント中心から基地側46〜52mの安全な帯から選ぶ。移動台の起動範囲には再出撃させない。地上ナビは施設と補給室の入口も含む240節点・468辺へ再生成した。Botには通常の占拠・前進・補給・防衛と既存の移動設備判断を使わせ、専用の壁抜けや移動補助は追加しない。

地形確認済みの川岸・水面・川底・道路橋と、街路までつながる復帰斜面10本を保持した。局所変更は基地・占拠円・補給室の周辺のみ。M01/M02（実物理）、M19/M29（高所からの退出）、M30/M31（射出後の操作と慣性）、M35〜M37（街区・庇・出口）を検査に反映した。

## 容量と確認

非圧縮の生成マップJS全体は**78,289B（約78.3KB）**。背景、接触、設備、再出撃点、BOT経路込みで250,000B以内。地形JSONは71,120B（末尾改行込み）。Three.js・音・本体を内包する単独HTML全体の容量とは別に計測する。

- 本体で2,245項目成功。候補地・占拠円、再出撃帯、468本すべての地上経路を実機体で確認。
- カタパルト240条件：10基×軽量/重量×両軍×30/120Hz×立ち位置3点。最初の着地が指定地点6m以内、接地後の滑走と操作禁止解除を確認。
- パッド64条件：8基×軽量/重量×両軍×30/120Hz。ブースト残量0で起動し、屋根へ着地して別の街路まで徒歩で退出。通常Botでも32条件で屋根へ到達。
- A/Eの補給室は入室・修理・退出に成功。敵陣側の地上31点/32点から見える点は0。全方向・全高さからの不可視を保証する検査ではない。
- 設備追加後も建物と鉄道・駅屋根の体積干渉0、面積3m²超の閉所0。川・道路橋の形状を地形確認版と照合。
- 通常HTMLでW・Shift・Space・Mの実入力とWebGL描画を確認。ブラウザエラー0・追加通信0。
- 10対10の通常BOT戦150秒指定（実進行153秒）：65撃破、蘇生3、エリア移動19、両軍コア7200/7425。エラーなし。

簡易検査は共通`quick_check.js`の比較側へ新形式のマップが混ざり、古い本体の初期化で停止した。共通の検査ソースは変更せず、タスク用コピーで比較側`maps.js`だけを`origin/main`の版に合わせた結果、cityと新マップの各60秒を含む検査が成功した。生成した同梱`maps.js`は検査後に元の内容へ戻した。

詳細は`verification.json`。無交戦の機能確認と少数のBOT戦であり、勝率、全屋根への任意の途中着地、50対50の性能まで合格した扱いにはしない。
