# PLATEAUからの街区再構築案

2026-10-24。前の加工済み地形を再度簡略化するのではなく、取得済みのPLATEAU建物・道路・橋梁メッシュから組み直した。地形の再確認用で、基地・プラント・BOT・カタパルトはまだ設置していない。承認済み候補地の平地と接続路だけを確保した。旧地形・対戦試遊版は変更していない。

- 進入範囲700×350m、背景込み900×550m。切り取り角30度、XYZ縮尺1/2。機体4mが実都市8mに相当する。
- 元の建物3,383個を道路・鉄道・川で区切り、通常街区は1〜3個のモデルに統合。ランドマーク20部分は色と主要な高さを独立して残す。
- 街区648部分、体積732個。前の対戦試遊版の2,147個から減少した。背景は359街区部分で、基本高さ5〜16m、屋根の上物なし。最高高さの巨大な箱へまとめない。
- 川岸は標高格子から地理院の水域ポリゴンへ変更。120頂点の輪郭を水面・川底・岸の壁で共有する。両岸に計10本の歩行復帰斜面を確保した。
- 地理院の地上線形を基準に鉄道を分け、南北線6.5m、東西線13m。線路と駅屋根の張り出しを先に予約し、建物の干渉を避ける。地上道路を除いて高架下は店舗で埋める。
- 地面と屋根の各高さを機体半径1.3mも含めて調べ、閉じた低所2箇所を周囲の高さへ塞いだ。描画と当たり判定は同じ体積から生成する。

地形JSONは**70,161B（約70.1KB、非圧縮・末尾改行込み）**。施設・再出撃点・BOT経路を含む完成マップJSの目安250,000Bに対して、約180KBを残す。これは完成マップの容量や対戦成立を確定した値ではない。

## 検査の範囲

保存形状では街区あたり最大3個、背景高さ16m以下、全地面・道路橋の平坦化、建物と鉄道・駅屋根の体積干渉0を確認した。壁の各高さと機体半径で調べた面積3m²超の閉所も0。これは閉じた穴の形状検査で、全ての地上経路・屋上移動・頭上の余裕を保証するものではない。

本体では25項目を確認した。基地・プラント候補地7点の平坦な空き、川底から街路まで斜面10本の歩行復帰、穴を塞いだ2地点への空中着地と街路への歩行退出、全体マップ描画に成功。単独3D表示も14,645三角形を描画し、ブラウザエラー0・外部通信0。詳細は`verification.json`を参照。全機体構成・全屋根の端・低FPS・施設配置後の射出と途中着地・BOT利用・対戦バランスはまだ評価していない。地形の外観を確認してから、基地→第一→第二プラントのカタパルトなどを再配置し、配置後の実走と対戦を確認する。
