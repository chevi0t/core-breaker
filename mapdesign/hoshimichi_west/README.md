# 星路西街区・斜め切り出しの半縮尺地形案

2026-10-24ユーザー指定。等尺600m四方の秋葉原を新御茶ノ水方向へ延長し、東西道路に対して長方形の切り取り方向を斜めにする。街・道路の非線形変形は行わない。今回は地形と進入範囲の確認段階で、基地・プラント・カタパルトを確定しない。既存の星路駅前や通常ゲームへの登録は変更しない。

## 地形の案

- 戦場候補は実寸1,400×700m、縮尺1/2で700×350m。中心は経度139.77008・緯度35.6986。
- 切り取り枠の長辺を地理上の東西から北東〜南西へ30度傾ける。秋葉原駅、UDX、新御茶ノ水の参照点を枠内へ含める。角度30度はまず確認するための仮値。
- 切り取り枠の各辺の外側に実寸200mずつの背景を付ける。取得範囲は実寸1,800×1,100m、表示は900×550m。
- 元の秋葉原600m四方は参照枠として重ねる。回転した長方形で改めてトリミングするため、旧正方形の全ての隅を維持する条件は置かない。街の縦横高さを1/2とし、現行4m機体が現実の8m級に相当する。
- 道路や建物の長さ、角度、平行関係を保つ。取得時に地理座標から切り取り座標へ剛体回転し、その座標系で切断・再構築する。地面、水域、線路、駅屋根、ランドマーク、参照枠とラベルは同じ回転を使う。
- プレビューの「北を上」「切り取り枠を横」はカメラの表示方向だけを変更する。地形の頂点は一切動かさない。
- 背景は街並みの外形と色を優先して簡略化する。詳細側では建物間を充填しない。容量は地形100,000Bを目標に実測し、施設とBot経路の予算は次段階で見直す。
- 進入可能範囲と描画範囲を分ける。今回の枠は候補表示のみ。境界の衝突と機体近傍の黄色い警告壁は、本体へ接続する段階で実装・実走検査する。

## 確認の順序

斜めの長方形でPLATEAU取得 → 半縮尺と街区の軽量化 → 地形/進入枠の確認 → 基地位置 → プラントと移動設備 → 本体接続と実機体/Bot対戦。

M19/M29（高所への到達と退出）、M30/M31（射出後の操作と水平慣性）は本体接続時の検査対象。M32（自治体境界と欠測）、M33（切り取り方向と街の変形の区別）を今回の設計へ反映する。

## 再生成

```sh

npm install --prefix /tmp/plateau-draco draco3d@1.5.7
PLATEAU_DRACO_MODULE=/tmp/plateau-draco/node_modules/draco3d python3 tools/plateau_rect_fetch.py /tmp/hoshimichi-west-rotated-cache /tmp/hoshimichi-west-rotated-source --config research/maps/hoshimichi-west-sources.json
python3 tools/build_hoshimichi_west.py /tmp/hoshimichi-west-rotated-source mapdesign/hoshimichi_west
node tools/test/hoshimichi_west_preview_check.cjs mapdesign/hoshimichi_west /tmp/hoshimichi-west-images
```

取得・復号した原資料はキャッシュ側へ保持し、リポジトリへ巨大な原データを追加しない。取得器は中心・寸法・角度・出典が異なるキャッシュの混在を拒否する。生成器は目標容量を超えても街区を消して黙って合格にはせず、generation.jsonへ実測を記録する。

保存形式はcity-layout-v1の形状に、建物の外側の整数列をまとめるvolumeEncodingを追加したもの。通常本体への読み取り接続は未実施。近傍の境界表示・通行・高架下の天井・川からの復帰・施設配置・Bot対戦も次段階。地形確認だけを通行・対戦の検証済みとは扱わない。

## 確認結果

切り取り角は仮30度。街を曲げる処理・切替操作と、そのための長い板の分割処理は撤去した。主要3地点を含む範囲で329個の公開タイルを取得・復号し、描画用形状の有限値と切断範囲を確認した。公表タイルの高さ範囲との差は最大約0.065mで、取得器の0.2m基準を満たした。

地形JSONは111,036B（末尾改行込み）、体積は2,210個。角度を変えたことで取り込む街区が変わり、現在は目標100,000Bを約11KB超えている。施設・Bot経路はまだ含まない。今後は向き・範囲を確認したうえで、詳細側の路地を埋めず背景側から容量を調整する。

17項目の検査で、整数列の復元、範囲と主要地点、既存色、文京区側の取り込み、駅屋根の辺の長さと直角、枠に対する30度の方向、カメラ切替で頂点が変化しないこと、北向きの表示、変形操作の撤去、WebGL実描画を確認した。ブラウザエラー0、追加HTTP通信0。実機体の通行・境界の衝突・Bot戦は未検証。

保存したoverview.pngは北を上にした俯瞰、oblique.pngは同じ地形の斜め表示。過去の曲げた案は現在の生成物へ引き継がない。
