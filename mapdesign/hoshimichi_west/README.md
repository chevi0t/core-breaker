# 星路西街区・斜め切り出しの半縮尺地形案

2026-10-24ユーザー指定。等尺600m四方の秋葉原を新御茶ノ水方向へ延長し、東西道路に対して長方形の切り取り方向を斜めにする。街・道路の非線形変形は行わない。今回は地形と進入範囲の確認段階で、基地・プラント・カタパルトを確定しない。既存の星路駅前や通常ゲームへの登録は変更しない。地形確認後の試走には、本体を使う独立した確認用HTMLを生成する。

## 地形の案

- 戦場候補は実寸1,400×700m、縮尺1/2で700×350m。中心は経度139.77008・緯度35.6986。
- 切り取り枠の長辺を地理上の東西から北東〜南西へ30度傾ける。秋葉原駅、UDX、新御茶ノ水の参照点を枠内へ含める。角度30度はまず確認するための仮値。
- 切り取り枠の各辺の外側に実寸200mずつの背景を付ける。取得範囲は実寸1,800×1,100m、表示は900×550m。
- 元の秋葉原600m四方は参照枠として重ねる。回転した長方形で改めてトリミングするため、旧正方形の全ての隅を維持する条件は置かない。街の縦横高さを1/2とし、現行4m機体が現実の8m級に相当する。
- 道路や建物の長さ、角度、平行関係を保つ。取得時に地理座標から切り取り座標へ剛体回転し、その座標系で切断・再構築する。地面、水域、線路、駅屋根、ランドマーク、参照枠とラベルは同じ回転を使う。
- プレビューの「北を上」「切り取り枠を横」はカメラの表示方向だけを変更する。地形の頂点は一切動かさない。
- 背景は街並みの外形と色を優先して簡略化する。詳細側では建物間を充填しない。容量は地形100,000Bを目標に実測し、施設とBot経路の予算は次段階で見直す。
- 進入可能範囲と描画範囲を分ける。今回の枠は候補。試走版では地上・空中共通の境界衝突を接続し、境界から8m手前に近づいた辺の機体周辺だけ黄色い警告壁を表示する。

## 確認の順序

斜めの長方形でPLATEAU取得 → 半縮尺と街区の軽量化 → 地形/進入枠の確認 → 基地位置 → プラントと移動設備 → 本体接続と実機体/Bot対戦。

M19/M29（高所への到達と退出）、M30/M31（射出後の操作と水平慣性）は本体接続時の検査対象。M32（自治体境界と欠測）、M33（切り取り方向と街の変形の区別）を今回の設計へ反映する。

## 再生成

```sh
python3 -m pip install -r tools/requirements-city-map.txt
npm install --prefix /tmp/plateau-draco draco3d@1.5.7
PLATEAU_DRACO_MODULE=/tmp/plateau-draco/node_modules/draco3d python3 tools/plateau_rect_fetch.py /tmp/hoshimichi-west-rotated-cache /tmp/hoshimichi-west-rotated-source --config research/maps/hoshimichi-west-sources.json
python3 tools/build_hoshimichi_west.py /tmp/hoshimichi-west-rotated-source mapdesign/hoshimichi_west
node tools/test/city_volume_codec_check.cjs
node tools/test/hoshimichi_west_preview_check.cjs mapdesign/hoshimichi_west /tmp/hoshimichi-west-images
```

取得・復号した原資料はキャッシュ側へ保持し、リポジトリへ巨大な原データを追加しない。取得器は中心・寸法・角度・出典が異なるキャッシュの混在を拒否する。生成器は目標容量を超えても街区を消して黙って合格にはせず、generation.jsonへ実測を記録する。

保存形式はcity-layout-v1の形状に、建物の外側の整数列をまとめるvolumeEncodingを追加したもの。整数列の読み取りと境界は本体へ接続し、別HTMLで試走できる。全街区の通行・高架下の天井・川からの復帰・施設配置・Bot対戦は次段階。地形確認だけを通行・対戦の検証済みとは扱わない。

## 確認結果

切り取り角は仮30度。街を曲げる処理・切替操作と、そのための長い板の分割処理は撤去した。主要3地点を含む範囲で329個の公開タイルを取得・復号し、描画用形状の有限値と切断範囲を確認した。公表タイルの高さ範囲との差は最大約0.065mで、取得器の0.2m基準を満たした。

地形JSONは94,314B（末尾改行込み）、体積は2,210個。111,036Bから16,722B（約15.1%）減少し、100,000Bの目標内に収まった。施設・Bot経路はまだ含まないため、これらを含む最終容量は別途確認する。

19項目の検査で、整数列の復元、範囲と主要地点、既存色、文京区側の取り込み、駅屋根の辺の長さと直角、枠に対する30度の方向、カメラ切替で頂点が変化しないこと、北向きの表示、変形操作の撤去、WebGL実描画を確認した。ブラウザエラー0、追加HTTP通信0。このプレビューの検査には実機体とBot戦を含めない。実機体の境界と代表地点の移動は後述の試走検査で確認する。

保存したoverview.pngは北を上にした俯瞰、oblique.pngは同じ地形の斜め表示。過去の曲げた案は現在の生成物へ引き継がない。

## 形状を保った軽量化

背景体積は117個・整数列3,294Bにとどまり、背景の輪郭だけを減らしても不足分を埋められなかった。地形の形は固定し、建物の保存ヘッダから共通の底面高・通常の1輪郭という値を省略した。種類・色・省略フラグを1バイトへまとめ、小さな輪郭の頂点数も1バイトで保存する。省略値は復元時に種類から正確に戻す。座標は従来の2cm格子のint16、高さも従来の1cm格子を維持し、輪郭や精度を削らない。gzipの圧縮率による容量減ではない。

形式は`kind2-color4-flags2-y01-i16-rings-u8`。色は既定色を含め16個まで、輪郭は256本まで、各輪郭の頂点は65,535個まで。頂点数255以上は拡張長を保存する。旧形式も復元器で読める。範囲外の入力や途中で切れた整数列は拒否する。復元器は通常本体へも接続し、既存の配列形式の都市データと共存する。

輪郭簡略化の許容値は、軽量化前の採用値と同じ実寸2mへ固定し、保存方式が変わっても街区を作り替えない。c8d2b52の地形と全2,210体積の座標・高さ・色が完全一致し、地面・川・枠・ラベル・縮尺・角度も完全一致した。Python保存器とJS復元器の27レコードで、既定値、任意の高さ、16色、256輪郭、頂点数の境界を照合した。不正入力の拒否も確認済み。

比較を再現するには、`git show c8d2b52:mapdesign/hoshimichi_west/layout.json > /tmp/hoshimichi-west-before.json`として、プレビュー検査の最後の引数にそのファイルを渡す。検査記録はpreview-check.json。

## 本体を使う地形試走

```sh
node tools/build_hoshimichi_west_walk.cjs /tmp/hoshimichi-west-walk.html
node tools/test/hoshimichi_west_walk_check.cjs /tmp/hoshimichi-west-walk-check
```

確認用HTMLはThree.js・本体・地形・音を内包し、追加通信なしで開ける。WASD、Shift、Space、Mは通常ゲームと同じ。新御茶ノ水側の空いた地面から実機体1機で開始し、基地・プラント・BOTと時間切れは置かない。通常のマップ選択とmaps.jsは変更しない。出典とThree.jsのライセンスも含める。

進入範囲はXZ各方向±350m・±175m、描画は±450m・±275m。範囲の外側に機体半径が出ないよう制限する。近傍の警告は黄色・16m幅・8m高で、機体の高さへ追従する。カメラと射線は遮らない。遠景床は描画範囲の外側だけへ足し、河川の内側を塞がない。

元の地形JSONは94,314Bのまま。境界・開始地点・配色指定を足した試走用地形は94,423B、試走用マップ定義全体は95,231B。単独HTML全体は本体・音・Three.jsも含むため約3MBであり、地形100KBの予算とは区別する。

検査は四辺と四隅、地上から高度1,000mまでの制限、外向きだけの速度除去、8m表示距離、角の2辺表示、プレイヤー/BOT共通の歩行・ダッシュ・近接踏み込み・吹き飛ばし・射出・滞空を対象にする。3参照地点近くの開始候補から、実機体で移動とジャンプも確認する。既存都市・従来マップとの往復で警告やカメラ形状の破棄、人数と対戦表示の復帰を確認する。通常HTMLでは実際のW・Shift・Space・M入力とWebGL描画を検査する。全路地の安全性や新マップのBOT対戦を検証済みとは扱わない。

確認結果はwalk-check.json。境界・表示・実機体の705項目、既存マップとの切替、通常HTMLの実入力に成功し、ブラウザエラー0・外部通信0。既存4マップ各150秒のBOT戦と、origin/main比較の簡易テストも成功した。
