# マップ制作の段階確認

ユーザー指定（2026-10-22）：地形を作る → 確認 → ベース位置を決める → 確認 → プラント位置を決める → Bot対戦テスト。

1. 地形だけの俯瞰図を見せ、起伏・道路の上下・建物・機体との尺度をユーザーに確認してもらう。
2. 確定した地形に両基地を置き、位置と範囲・出撃口・周辺施設の空間をユーザーに確認してもらう。
3. 確定した地形と基地を使い、ユーザーとプラントの数と位置を決める。補給所と両軍の再出撃帯も確かめる。
4. 配置が決まったら経路を生成し、実移動・占拠・Bot対戦を検査する。移動時間は、機体・徒歩/ブースト・カタパルト・起終点・試行数を添えて比較する。

途中の確認は図と軽い形状・配置検査で進める。長いBot戦・全体の回帰試験・ZIP作成は配置確定後、またはユーザーから個別に依頼された時に行う。確定した地形・基地・他のプラントは一か所の修正で勝手に動かさず、変更が必要なら該当段階に戻って修正案を見せる。

既存の記録が同じ条件の比較に使える場合は再集計し、無関係な試験を繰り返さない。共通の物理・射撃・Botを変更した場合の必須検査は従来どおり行う。機能検査と統計的な公平さの評価は区別する。

現在のOSM用CLIは施設と経路をまとめて生成する完成候補用で、段階別CLIは未実装。途中の確認は表示要素と検査を段階に合わせて分け、自動配置を採用済みとは扱わない。
