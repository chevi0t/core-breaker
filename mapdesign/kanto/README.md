# 環都駅前・五街区争奪戦

梅田のPLATEAU建物と国土地理院の道路から再構築した1km四方を、通常の機体・武器・HUDで遊べる推奨10対10のマップへ接続した。IDは `kanto`。通常の `prototype/index.html` のマップ選択に表示する。[確認用HTML](play.html)は同じ本体と素材を使い、このマップを選択済みにしている。

## 配置

ユーザー図の南西に青基地、北東に橙基地を置き、赤いPの5地点を中立プラントにする。各基地のカタパルト4基・砲台4基・レーダー1基・補給ポッド2基、各プラントにポッド1基。試合は10分。街路に中立ジャンプパッド6基と、B→C・D→Cのカタパルト各1基を追加する。出撃前の人数選択で、両軍共通2〜50機にも変更できる。

基地の囲みとプラントの半径18mだけ建物を切り、道路と大きな路地を残した。A/Eのポッドは深さ2mの窪地・3面の5m壁と歩いて出られる坂で隠す。両陣営から各プラントへの再出撃候補を6地点ずつ、自軍基地側46〜52mに置く。カタパルトの降り先は空中経路も建物に当たらない街路から選ぶ。

## 外観

B周辺のうめきた公園に相当する範囲を芝生色にし、舗装路を残した。地面の高さ・当たり判定は変えず、地図にも同じ芝生を表示する。

公開外観写真と位置を確認し、9か所を目印として配色した。中央駅は銀色の屋根・砂色の北棟・白灰色の南棟、北側高層群は青緑のガラス、大型店舗は白銀、東側百貨店は茶色の低層部と白い上層部。観覧車のある商業施設は既存の上部構造を赤い目印にし、東のガラス棟は深い青緑、西の石調ビルは暖灰色にした。一般の建物は8色の落ち着いた石・金属色で分け、同じ建物の上下はそろえる。ミニマップも同じ色を使う。

資料・実物との対応は [外観の採用記録](../../research/maps/umeda-landmarks.json)。ゲーム画面には実在の名称・看板を出さない。写真を素材として取り込まず、既存形状の色と窓の描画だけを変えている。公開モデルの収録時期による差は残す。例えば南側百貨店の入力モデルには新しい高層部がなく、着色に合わせて建物を足すことはしていない。

白い大屋根は駅舎と線路の向きに合わせた約200m×92mの傾斜板1枚。北側76mから南側50mへ下げ、上面・下面・縁を含む12三角形で表現した。対戦用の接地・弾判定も同じ板を使い、マップデータの増加は327 B。元の建物は削っていない。

## 動作確認

本体の移動・占拠・射撃・勝敗処理で検査した。[対戦記録](battle-check.json)は操作禁止の解除を修正したcommit `94b07d5` 時点で、移動設備・芝生・加速中のブースト回復の追加後、20機すべてをBotとして600秒を上限に動かした1試合。約501秒で橙コアが破壊され、173撃破・16占拠・139回射出で正常終了した。陣営別の長期勝率や実機FPSは未測定。

[カタパルトの操作解除](../catapult-control-check.json)は台地・星路・環都の全30台で、飛行時間によらず1秒後にShiftとSpace長押しが使えること、無入力なら着地点へ届くこと、早期着地でも禁止が残らないことを確認する。

[移動設備の実走](mobility-check.json)は、パッド72条件（軽量・標準・重量×両軍×30/120Hz×6基）の屋上着地と地上への離脱、B/D→Cの射出48条件（軽量・重量×両軍×30/120Hz×立ち位置3種）、本体Botの判断による屋上到達24条件を確認した。既存の垂直パッドの物理は変更していない。

施設検査はカタパルト60条件で最初の接地の最大誤差2.59m。長距離台の接地後の滑走は停止地点も検査し、全例が中央の占拠円手前の安全な地上に収まる。さらに再出撃240サンプル、両基地から全プラントへの徒歩10経路、補給の制約と坂からの退出、砲台・レーダーを確認した。ブラウザエラー0。
