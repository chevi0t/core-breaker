# 星路駅前試験区・街区を再構築した案

2026-10-23、ユーザー指定の「PLATEAUで配置を拾い、ゲーム用に割り切って100KB程度で街を再構築する」試作。[単体HTMLを開く](index.html)。ネット接続なしで本体の機体を操作できる。

[参照版と再構築案の俯瞰比較](comparison.png) / [街全体の立体図](overview.png) / [機体から見た通り](street-view.png)。比較図は左が確認済みの参照版、右が今回の案。同じ600m四方・同じ縮尺。

## 作り方と容量

仮説は、配置と大きな外形を残して棟をまとめれば、通れる街路と目印を保ちながら街データを100KB以内へ減らせる、というもの。入力には、すでに取得済みのPLATEAUから作成した[実機体試走版](../trial/README.md)を使う。原データの再ダウンロードは不要。参照版のHTMLと生成物は変更せず、今回の成果物を別フォルダへ置く。

| 比較するもの | 参照版 | 再構築案 |
| --- | ---: | ---: |
| 街データJSON（gzip前） | 625,743 B | **92,997 B** |
| 同じJSONのgzip | 230,151 B | **45,800 B** |
| HTMLに埋め込むbase64 | 306,868 B | 61,068 B |
| 描画の三角形 | 28,590 | **12,240** |
| 建物の接触用角柱 | 698 | 176 |
| 駅・高架・店舗・基地を含む角柱 | 765 | 243 |
| 共通ゲーム本体・音楽・効果音・Three.js込みのHTML | 3,175,468 B | 2,933,973 B |

1KB=1,000Bで計測。目標100KBは**gzip前の街データ全体**へ適用し、生成器が超過時に停止する。容量の実測と入力・生成器のハッシュは[再構築記録](reconstruction.json)、形状・配置の詳細は[生成記録](generation.json)。配置JSONは[layout.json](layout.json)、同内容の圧縮版は[layout.json.gz](layout.json.gz)。HTMLはそれらを別途読み込まず、同じデータを内部に持つ。

普通の棟と隙間を埋めていた低層部分を、接続する街区ごとに統合する。583個から146個へまとめ、細い凹凸・閉じた中庭・屋上の小物・小さい棟を省略する。輪郭は主に10cm格子、代表的な屋根の高さは面積を考慮して3m刻みにする。色分けした18か所は大きな外形と主要高さを残し、屋上の細かい段差を省く。北西のパッド着地点は95mのまま。

建物・駅屋根・高架・店舗は「輪郭と下端・上端の高さ」を保存し、Three.jsに同梱されたEarcutで描画面を生成する。その同じ輪郭と高さを機体の壁・床・天井判定にも使う。線路の細部は薄い帯に整理し、店舗前面の細かいパネルを省略する。地面、橋、川岸、復帰用の斜面は参照版の面を1cm格子の座標と頂点参照で保存する。川底と水面は川の輪郭から組み立てる。

道路と空地は統一した灰色。川、駅屋根、高架の上下関係、線路間の接続床、川の出口8か所、拡幅した高架横の路地、補修した孤立穴、北東の10棟、両基地の更地と位置、北西の高層棟へ上がるパッドを引き継ぐ。細かい屋上の足場や棟ごとの高さは変わるため、今回の図と試走で街の見え方を確認する段階。

## 試走と確認

「試走を始める」で出撃。WASDで移動、Shiftでブースト、Spaceでジャンプ、Mで地図、Escでメニュー。大通り・駅屋根・上下高架・川底・両基地など9地点から開始できる。敵機・プラントは置かず、時間制限なし。境界は機体中心±298.7m。

- [再構築の検査](rebuild-check.json)：街データの容量・HTMLと単体JSONの一致、18か所の配色とガラス、駅屋根と高架、基地の更地777地点、道路・川沿いの高台・広場・線路間の徒歩192通り、接続床上下の射線、再組み立て時のカメラ形状を検査。
- [路地と落下後の脱出](blocks-check.json)：拡幅した高架横と北東街区の88通り、穴を補修した場所へ落下して高架へ歩き出す12通り。
- [復帰と視点](recovery-check.json)：川の8出口を徒歩で戻る32通りと、路地の24地点・1,273条件の視点・照準。
- [基地・店舗・高架](district-check.json)：復元した路地48通り、基地から乗り場4通り、パッド射出から屋上着地4通り、南北線の縦走8通りと店舗外壁。
- [本体の入力・移動](movement-check.json)：実キー入力、全開始地点の接地、ジャンプ・ブースト・壁・屋根・橋の上下・射線・四辺と四隅など31項目。

歩行検査は軽量機・重量機、1/30秒・1/120秒刻みを使用し、復帰・通路検査ではブースト容量を0にする。すべてオフラインChromiumで実施し、ブラウザエラー・外部通信なし。代表地点の機能検査であり、全街路の到達性・FPS・Bot利用率・対戦バランスの測定は今後の段階。

試作として保持し、比較図・試走をユーザーに確認してもらう。採用後に地形と基地の位置を確定し、プラント配置、経路、Bot対戦へ進む。通常配信への登録・ZIP作成・既存マップの置換は行っていない。

## 再生成

Python依存は `tools/plateau/requirements-compact.txt`、面数の確認にはNode.js 18以降と同梱のThree.jsを使う。表示検査にはリポジトリのPlaywright/Chromiumが必要。

```sh
python3 tools/plateau/rebuild_trial.py mapdesign/akihabara_city/trial /tmp/city-rebuilt
node tools/test/city_rebuild_check.js /tmp/city-rebuilt
node tools/test/city_blocks_check.js /tmp/city-rebuilt
node tools/test/city_district_check.js /tmp/city-rebuilt
node tools/test/city_recovery_check.js /tmp/city-rebuilt
node tools/test/city_trial_check.js /tmp/city-rebuilt
```

本体の移動・射撃・機体・カメラの共通設定は参照版と同じ。再構築の処理は `tools/plateau/rebuild_trial.py`、配置の展開は `rebuild_runtime.js`、本体への接続は既存の `build_trial.py` を共用する。[再生成の照合記録](reproducibility.json)では、標準生成HTMLが参照版とバイト単位で一致し、再構築の再実行でも配置・HTML・生成記録が一致することを確認した。
