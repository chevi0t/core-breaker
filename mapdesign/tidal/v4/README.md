# 基地前の工場街と住宅地

2026-10-20。基地前の空き地が多く、射線を切って接近する選択肢が不足していた。青の常設基地前を工場街、橙の野戦拠点前を住宅地にする。370×1136m・10対10・600秒、既存3配置、基地とプラント・補給・再出撃・カタパルトは維持する。変更前のマップと生成器をbaseline-*へ保存する。

## 攻防の仮説

- 工場街：大きな作業棟・倉庫・コンテナ・設備塔で見通しを分割する。工場間の地上路、連絡橋の下、10〜12mの屋根上を分ける。屋根は坂またはパッドで利用し、荷役屋根から基地内へ接続する。屋上にも設備を置き、最後まで無遮蔽の一直線にしない。
- 住宅地：切妻の低層住宅、庭壁、互い違いの路地と共同住宅を組み合わせる。路地から搬入口へ回れるほか、共同住宅の屋上から基地の荷役屋根へ渡れる。
- 両軍とも正面ゲートへの地上の接近路を残す。街区の遮蔽へ寄るか、門を直接押すかを選ぶ。屋根は高所から見通せる一方、登る時間と露出がある。

舗装範囲を指定し、街路にランダムな起伏を置かない。建物は占拠円・再出撃域・隠した補給点・カタパルトの着地を空ける。工場と共同住宅の屋上は実際の上面と歩行用の床を合わせる。坂は建物の基礎を持ち上げないよう外側に置き、上端を床へ重ねる。

## 検査と知識

M01/M02/M13（上下の実物理）、M03/M06（接近・迎撃と射線）、M14（両所有条件の再出撃）、M16（坂の接続）、M18（見た目と公平さの区別）を継承する。工場の隙間・屋根・路地・正面を軽量/重量機で実走し、両軍の単独Botによるコア攻略と屋根利用を確認する。地上と屋根の射線、補給点の屋上からの露出、通常射出での着地も調べる。

対戦は新地形で各4戦を行い、旧版の結果を引き継がない。公平さや生還率の改善は、移動・遮蔽の機能成立とは分けて判断する。

## 実装結果と採否

既定の生成版を `tidal4` とし、3配置へ登録した。工場街には5棟の作業棟・倉庫、屋上設備、コンテナ、連絡橋を設置。住宅地には12棟の低層住宅、庭壁、2棟の共同住宅を置いた。坂と新パッド3基を追加し、10〜12mの屋根から既存の荷役屋根へ接続する。低層住宅の切妻は装飾で、連続した屋根経路は工場・共同住宅に用意した。左右の正面ゲートへの地上路は維持する。
