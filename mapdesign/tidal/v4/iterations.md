# 街区追加時の失敗と修正

2026-10-20。各候補の生成設定・ソースSHA256・失敗理由をruns配下へ保存した。失敗した候補を登録せず、合格済みの旧マップを保持して再検査した。

1. 最初は工場の屋根に同じ階の接続節点が無かった。坂の上端へ平坦面を重ねた際、平坦面が坂の終点より手前へ張り出し、実物理で登れない段差になった。坂の終点から平坦面を始め、その先で床へ入るように変更した。[記録](runs/2026-10-20T04-48-02-897Z-tidal4-fKEzxV/generation-failures.json)
2. 工場屋根から既存の荷役通路へ足した橋が、坂を上っている機体の頭上を塞いだ。上層の接続を坂の上端より奥へ移し、従来の徒歩乗降も通した。[記録](runs/2026-10-20T04-50-13-692Z-tidal4-UCSkyT/generation-failures.json)
3. 新パッドの水平距離が長く、重量機で着地先に届かなかった。両軍の装備抽選条件で検査し、射出点を壁から離したまま出口を屋根の縁へ寄せ、必要な水平移動を短くした。[記録1](runs/2026-10-20T04-52-18-448Z-tidal4-YZoDWP/generation-failures.json)／[記録2](runs/2026-10-20T04-54-19-872Z-tidal4-HdO5Gx/generation-failures.json)／[記録3](runs/2026-10-20T04-56-00-605Z-tidal4-wZEEPG/generation-failures.json)
4. 両脇だけに街区を置いた初回案は、中央の通りに長い見通しが残った。占拠円・補給点・両所有条件の再出撃域を空けた位置へ管理棟と住宅を追加し、左右のゲートへ向かう道を残した。[初回案](first-pass/README.md)。途中の対戦記録は最終評価から除外。

次回も、上層を足すときは下を通る既存の経路を同時に走らせる。街区を置いた後は固定の攻撃経由点が建物に埋まっていないかも確認し、正面・路地・屋根の通行、視認、通常Botの攻略を別々に扱う。
