# 橙基地側面の山岳侵入路

2026-10-20。v4の12戦は青2勝・橙10勝。ユーザーの指定で橙基地の陸側に防壁より高い山を追加し、青の侵入候補にする。勝敗の偏りが基地侵入だけで生じたとは扱わない。

## 仮説と固定条件

高さ14mの尾根を橙基地の陸側（−x）へ置く。坂を登って尾根沿いに進み、10mの短い足場で8mの側壁を越え、基地内の小さな斜面から地上へ下る。正面と住宅地・屋根の既存経路は残す。青の潜行役がこの経路を使う。

370×1136m・10対10・600秒、3配置のプラント・施設・補給・再出撃条件、青側の地形は固定。基地内の地形を平らにする処理には、指定した正の地形だけ高さを残す任意項目を足す。既存マップは従来の処理をそのまま使う。旧データ・生成器・本体をbaseline-*に保存した。

M01/M02/M13/M16/M19を継承し、外側の坂→尾根→防壁越え→内側の斜面を軽量・重量機で実走する。既存の屋根・パッド・搬入口、補給点と両所有条件の再出撃も再検査する。単独Botの山の利用とコア攻撃を確認した後、v4と同じseed・編成入替で各4戦を比較する。M04/M08/M11/M12/M18/M20に従い、直接攻撃と大破を分解し、地形の機能と公平さの改善を分ける。

## 最終実装と機能検査

登録版は `tidal5`。山の平坦化を外す `keepBaseHeight` と、狭い経路の陣営別の到達半径 `pointRadius` は任意項目で、省略したマップは従来の処理を使う。橙の側壁を持ち上げず8mのまま、山は14m、横断の足場は10m。内側は射出台とプレハブを避ける幅8mの坂にした。山の上でも、通常どおり基地境界を越えればレーダー警報が鳴る。

**要望の山岳経路は実装として採用するが、バランス改善案としては未合格。** 合計は青2勝・橙10勝から、青1勝・橙10勝・引分1。青の直接攻撃は828から0になり、増えていない。青の大破損失は72,056.25から76,500、橙も67,893.75から72,112.5へ増えた。単独で登れてコアへ届くことを、通常戦の前線突破・生還や勝率改善と同一視しない。

実戦では青の尾根進入を延べ37回、指定した横断帯への進入を39回記録した。後者は山を通らない屋根役や再進入も含み、37回から39回成功したという意味ではない。山と青の潜行経由点・到達半径を一緒に変えた比較なので、地形単独とBot誘導の効果は分離していない。各4戦で統計的な公平さは未確定だが、この観測では橙優勢を解消できていない。

[新しい主配置リプレイ](replay/replay.html)はseed20261410通常戦。B4を選ぶと約583秒に尾根へ入り、596秒に側壁を越える様子を追える。この1戦では終盤の侵入となり、コア攻撃は両軍0。初期状態・残コア・時間・勝者・撃破を対戦バッチへ照合した。[同seedの旧地形リプレイ](../v4/replay/replay.html)も残す。

次は、山の入口へ届くまでの大破と所要時間、侵入警報から防衛の帰還・迎撃までを試合単位で追う。前線の損耗・補給・攻め役の配分と、基地の越えやすさを分けて修正する。今回の失敗・修正は [履歴](iterations.md)、再利用する知識は [M21/M22](../../LESSONS.md)。
