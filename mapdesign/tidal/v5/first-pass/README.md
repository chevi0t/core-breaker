# 最終評価に含めない途中案

candidate-map.jsは既存の起伏まで再抽選した初回の山岳案。単独攻略は固定編成への切替前の記録で、青の支援によるレーダー攻略が未達だった。

return-ledge/は、基地内から足場へ戻る際の引っかかりを発見して停止した途中の対戦・検査。全件を終えた最終バッチとは別に残す。

raid-wide-radius.jsonは既定の14m半径で山の角を飛ばし、山から落ちて既存パッドへ回った実記録。raid-ground-height.jsonは、到達半径を4mへ狭めた際に既存の小山上の高さ0の経由点で停止した記録。

最終版の検査と対戦は ../final/ のみ。途中の結果を最終勝率へ足さない。
