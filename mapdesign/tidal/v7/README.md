以下は統合前本体でのv6/v7比較履歴。マージ時に取り込んだ最新mainでの確認は[統合検査](integration-main/README.md)へ別保存する。過去の勝敗・到達時間と新しい本体の成績を混ぜない（M11）。

370×1136m・10対10・600秒、プラント3配置・地形・斜め橋・既存建物と施設・侵入経由点・戦闘ルールは固定。既存のlayoutとnavだけへ追加し、本体は変えない。旧版はbaseline-map.js、baseline-generator.js、baseline-manifest.jsonに保存する。起伏はM21に従い以前の基準から生成し、同じ配列を照合する。

合計は青6勝・橙6勝。青の大破損失は74,362.5→71,718.75、橙は73,068.75→70,312.5と減ったが、上層の青は増加し、橙4勝となった。追加後のコア直接攻撃は両軍0で、12戦すべてが大破損失だけで決着。遮蔽が増えたことを侵入成功や全配置の公平さの改善と扱わない。

コンテナは要望の地形として採用する。**バランスは未合格・勝率未確定**。A–BとC–Eへの追加に倉庫2m移動も伴うため、区間ごとの単独効果は分離していない。次は上層配置で、展望台の占有・上下の再合流・補給へ戻る経路と滞在を調べる。結果を確認せず共通地形全体へさらに遮蔽を増やさない。

[主配置リプレイ](replay/replay.html)はseed20261410通常戦。初期状態・終局HP・勝者・撃破が対戦バッチと一致し、閲覧・イベント遡り・機体選択・390px幅・外部要求なしの検査も合格した。[変更前の同seed](../v6/replay/replay.html)を残す。

## 上層Cへのアクセスについての追加診断

ユーザーの指摘を受け、[B/DからCへの再合流8走](access-diagnostic/README.md)を追加した。上層配置に合わせた前線カタパルトの補填はしていなかった。基地→C占拠は両軍約52秒だったが、中心付近から出発する重量BotのCの床への到着は青42.15秒・橙25.55秒。青は途中パッドへ回り、リフトも1便遅れた。軽量と後方再出撃では同じ便に乗れて差が隠れた条件もある。開始位相固定の無交戦検査で、通常戦の平均や勝敗の唯一の原因は未確定。検査の抜けをM27へ記録し、B側の前線カタパルトを次の比較候補とする。この診断によるマップ・設備の変更はない。
