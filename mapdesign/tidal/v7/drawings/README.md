# 両区間のコンテナを追加した図面

現行tidal7を本体の地形・固定衝突形状から採取した。370×1136m、主配置「屈折前線」。[全体平面](plan.png)・[上層配置](plan-v2.png)・[複路配置](plan-v3.png)の緑の破線枠が追加した14群の段積みコンテナ。上段は下段より狭い。

[断面9本](sections.png)／[PDF・3ページ](tidal-plan-sections.pdf)。A〜Iの切断線、縮尺・採取方法は[v6](../../v6/drawings/README.md)を継承する。地面は2m、断面は0.5m間隔で本体から採取し、geometry.jsonへマップ・本体のSHA256を記録した。

[地上の視認範囲の比較](exposure-comparison.png)は、変更前後とも立てる共通の地上点に対し、各区間で3つの固定視点から見える数の差を示す。10m格子。見える視点が減った点は緑、変化なしは灰、増えた点は橙。箱の内部を「隠れられる地上点」として数えない。試合の滞在量や被弾率とは別の形状検査。

実景はapproach-blue.png・approach-orange.pngを参照する。撮影だけ霧を省き、ゲーム中の霧・物理・射線は変更していない。
