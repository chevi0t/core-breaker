# 潮路搬送区：10対10の工業港

2026-10-20。Issue #1 の段階1〜5を使う新テーマ。人数はユーザー指定の10対10、時間は600秒。参照研究は [AC版マップの特徴抽出](../../../research/arcade/maps/third-mining-island-rinkai.md)。名称・座標・外形・モデルは本作独自。

## 生成前の設計

- ID：`tidal`。370×710m、コアは既存仕様に合わせて `z=±320`、ベース境界は `±275`。両端を向かい合わせ、中央で進路を曲げる。原作のL字を写す必要はない。
- 主題：運搬高架と倉庫に挟まれた港湾。舗装路は平坦。非舗装の余白だけ既存の起伏生成器を使う。
- 戦線：自陣前→前線補給→中央争奪→敵前線補給→敵陣前。初期所有は両端のみ、内部は中立。
- 経路：高架を横切る地上経路、橋下、橋上、倉庫の内部と屋根、海沿いの迂回路。複数箇所で上下・左右を切り替えられるようにする。
- 中央：地上の争奪点と、離れた展望台の候補を持つ。主配置は地上の争奪を中心とし、同じ地形で高所干渉・分散占拠の配置も生成する。
- 補給：中央そのものにはポッドを置かず、南北の前線支点に設ける。端のポッドは三方の土手と窪地へ隠す。Botの90m選択範囲と、実際の退避を別に確認する。
- 昇降：展望台はリフトと徒歩坂、倉庫屋根はジャンプパッド、高架は両端の坂と途中のリフト。高い場所すべてへ同じ装置一式を置かない。
- 防衛：各ベースに砲台4基・ポッド2基・左奥レーダー・左右各2基のカタパルト。カタパルトは自陣前までの移動を補い、中央へ直行しない。
- Bot：既存の目標選択・索敵・戦闘・経路探索・昇降判断を使う。新テーマごとに高さを含むnavを作り直す。近道だけを検査せず、橋上・橋下・沿岸・倉庫・各プラントへの移動を軽量/重量機で通す。
- 知識の引継ぎ：M01/M02（実物理と乗降）、M03/M06（退避・再合流・迎撃と射線）、M04（コア被害の分解）、M05/M08/M11（比較条件）、M07（少数戦から勝率を断定しない）、M10/M12（ポッド機能と戦場改善を分ける）。IDは [知識台帳](../../LESSONS.md)。

## Bot戦の観測と限界

各配置で2つの編成seedを両軍へ入れ替え、4戦ずつ。開始seedは20261200、主配置は20261200/201、上層は20261202/203、複路は20261204/205。全12戦のコア被害内訳を実HP差へ照合した。配置間は異なる編成seedなので、配置だけの因果比較には使わない。

| 配置 | 青勝利 | 橙勝利 | 青によるコア直接攻撃量の合計 | 橙によるコア直接攻撃量の合計 |
|---|---:|---:|---:|---:|
| 屈折前線 | 3 | 1 | 86 | 0 |
| 上層干渉 | 2 | 2 | 0 | 1,524 |
| 複路争奪 | 2 | 2 | 29 | 0 |

**勝率未確定。** 特に主配置の青3勝1敗は偏りを調べる根拠として残す。ほかの2勝2敗も公平さの証明とはしない。全体の占拠所有者変更330件、修理開始444件、昇降イベント548件を観測した。修理や昇降の利用成立を、そのまま戦場改善の採用根拠にはしない（M12）。

直接攻撃があったのは12戦中3戦で、主な決着要因は大破損失。中央への陽動が別経路の突破をどの程度助けたか、凸の試行数に対する成功率は未計測。中央の制圧時間だけでも勝敗は説明できず、主配置seed20261200の入替戦は橙がCを約505秒保持したが青が勝った。プラント保持・大破・直接攻撃を分解して見る（M04）。

## 参照仮説の採否と次の検査

- 参照H02の接続条件は実走で確認でき、地形の開発候補として採用。H01の陽動と突破、H03の補給が戦況へ及ぼす効果、H04の高所の利益と代償、H05の公平さは未確定。原作の攻略説明から自動的に成立扱いしない。
- M13：橋上の傾斜は橋の面で測る。実走目標を近くの下階へ置き換えない。
- M14：再出撃帯は両軍の所有条件で検査する。占拠円や施設の検査だけでは、補給用の壁・高所の坂との干渉を見落とす。
- 次の調整は主配置の青側優位をまず診断する。リプレイで大破位置、補給からの再合流、侵入から発見・迎撃までを見て、プラントか経路かを分けて一要素ずつ比較する。現時点の少数戦だけで壁やポッドを追加しない。
- 高所配置の中央では、前線ポッドがBotの90m選択範囲の外にある。移動手段が使えることと、負傷後に補給へ戻れることは分け、高所保持の損失と降りて再合流する経路を次の検査に含める（M10/M12）。
