# 縦延長と二種類の基地

2026-10-20。ユーザーが採用した長方形の工業港を維持し、縦を710mから1136mへ延長する。10対10・10分。中央争奪、高架上下、倉庫、展望台は引き継ぎ、前線から基地への接近と迎撃に時間を持たせる。

## 攻防の仮説

正面の左右の門に加え、両側の搬入口と、片側の荷役屋根から侵入できる。屋根はパッドで素早く上がれるが、遠い坂から歩いて入ることもできる。門からコアを直線で見通せないよう、内部に防壁・建物・資材を置く。基地内での射線切りは侵入者にも使えるため、壁の多さを防衛力と同一視しない。

- 青は常設の駐屯基地。高いコンクリート防壁、事務所、兵舎、資材コンテナ、トレーラーを置く。
- 橙は侵攻側の野戦拠点。HESCO、低いプレハブ、コンテナを置く。厚い防壁とずらした内壁で射線を重ねる。素材ごとの架空の防御倍率は設けず、実際の高さ・厚さ・配置で差を作る。

守備2機を門内とコア脇へ分け、被攻撃プラントへの自動転出を止める。通常の索敵情報で自陣への接近を確認した場合、近い占拠役を最大2機戻す。遠ければ通常のエリア移動待機を経る。レーダーを壊されてもセンサーで検知できる一方、どちらにも映らず見えていない敵の位置は使わない。

攻め役には正面、側面潜行、レーダー破壊、屋根からの速度重視の経路候補を分ける。普通の装備・ブースト・空中操作・射線判定を使う。レーダー射撃は門外から試し、届かなければ接近する。戦術の成功は対戦で別途計測する。

## 延長時に保持する実寸

再出撃46〜52m、補給点の窪地2mと土手5m、機体サイズ、ジャンプ高、リフト速度を拡大しない。中央の再出撃帯に掛かる遮蔽も元の位置を保つ。坂は格子へ焼くと端に隙間ができるため、屋根の床と重ねて接続する。基地の地面は従来どおり平らにし、歩き用の屋根の坂は基地境界の外側に置く。

v1は旧地形の測定記録。v2は途中の基地強化設計と比較用の旧本体・旧生成器の保存。新地形の検査・対戦はこのv3へ保存し、旧勝率を引き継がない。

## 実測結果と判断

[最終検査](final/manifest.json)は徒歩220経路、設備乗降84件、再出撃1,280回、単独占拠40経路、基地守備8ケース、単独侵入8経路。3配置の完全版施設検査は★なし、両端ポッドの視認0、カタパルト着地誤差は最大0.9m。レーダー攻略は両軍で破壊、屋根侵入は両軍で実際にパッドを利用した。

通常Botは各配置4戦、編成を入れ替えて12戦。主配置は青1勝・橙3勝、上層は2勝2敗、複路は青1勝・橙3勝。直接攻撃は両方向で成立したが、主配置・複路は橙だけが通した。地形の到達性と基地の機能を確認した開発候補として採用し、公平さの最終合格とはしない。勝率未確定。基地形状・中央経路・Botの方針のどれが差を生むかは、条件を固定した次の比較で調べる。
