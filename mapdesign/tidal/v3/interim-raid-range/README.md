# 実装途中の記録（最終評価から除外）

基地と攻撃役を変更中に回した記録。通常銃の射程省略を0と扱った版と、その修正版、仮設棟の配置変更が含まれる。途中でデバッグ版を作り直したため、この対戦バッチを固定版の勝率や改善比較へ使わない。最終版の記録は `../final/`。

最初の単独侵入検査では、支援が「停止のためalive=falseにした砲台」を修理しに行った。これは検査環境が作った別目標で、マップの移動不能と判定しない。最終検査では停止した砲台をBotの施設対象リストから外し、物理の残骸は残した。射程0の不具合と、この検査条件の混同を分けて扱う。

最初のレーダー攻略の判定も、爆風が先にコアへ当たると検査を終了していた。最終検査は通常の武器でレーダー破壊とコア攻撃の両方を確認する。
