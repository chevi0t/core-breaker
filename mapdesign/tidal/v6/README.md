# 斜め高架とB–C間の遮蔽

2026-10-20。ユーザー指定の「斜めの橋1本」と、B–C間の射線分割を一緒に実装する。旧版はv5に保存、今回の基準データをbaseline-*に保存した。

370×1136m、10対10、600秒、3配置のプラント、補給、基地街区、山岳侵入路、戦闘ルールは維持する。中央高架は(-132,+192)→(+96,-192)へ斜めに架け、両端に地上からの坂、途中にリフト2基を接続する。倉庫上に機体が入れる空間を残すため床20mとする。矩形床を2m間隔で重ね、描画と衝突を一致させる。B–C間には地上防壁、橋上の塔、中央側の積み荷を置き、左右に逃げ道を残す。

M03/M04/M06に従い、視認と実弾を変更前後で比較する。M01/M02/M13/M16/M19に従い上下の実走・乗降・両所有の再出撃を確認する。M21に従い起伏の乱数はv4を参照して固定する。M08/M11/M12に従いv5と同seed・同編成の各4戦で大破損失とコア直接攻撃を分けて比較し、12戦で公平さを断定しない。

## 実装と機能検査

登録版は `tidal6`。高架の端点は青側(-132,+192)、橙側(+96,−192)、床20m、幅約20m。旧高架・旧橋脚・両端の坂を置き換え、中央倉庫を橙側へ移し、橋下の地上横断を残した。橋上塔の両脇、地上防壁の両脇、積み荷の両脇を通れる。ゲーム本体はv5から変更していない。

- [生成記録](runs/2026-10-20T07-28-42-676Z-tidal6-Kx6iKf/generation.json)：3配置、徒歩334経路、全パッド・リフト120件。7候補・20配置案から従来と同じ3配置を選抜。

- [再出撃1,280回・本体Botの占拠40経路](final/bot-access.json)。22mの試作で101.9秒を要した橙重量機の展望台占拠は、最終20m案で52.05秒。設備単体の成立と最終目標への選択を分ける知識[M23](../../LESSONS.md)を追記した。
- [街区の地上8経路と射線6組](final/district-check.json)、[固定編成の単独Bot攻略8経路](final/raid-check.json)を確認。青の山岳侵入は山・壁越え・コア攻撃が成立するが、所要時間はv5の72.9秒から88.9秒へ伸びた。到達性の成立を前進効率の改善と扱わない。
- [固定条件の照合](final/fixed-conditions.json)：プラント3配置、基地施設、補給、パッド、山岳経由点、既存起伏、本体を保持。[最終ソース](final/manifest.json)。
