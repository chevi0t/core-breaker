# 主武器の発砲炎

本体のHTML blob：`24819914037abd5f9d0df29372260c2a5edff66e`。土台：main `ce2e1bee5c009dcbaf5a6a7a11276082a7cefb51`。

[連射→射撃停止の動画（3秒）](firing.webm)／[実弾](ar.png)／[ガトリング](gatling.png)／[二丁拳銃](pistols.png)／[光学兵器](rail.png)。すべて本体のモデル・射撃処理・発砲炎の実描画。確認用の固定カメラのステージで撮影した。Canvasで描いた炎と光のテクスチャを使い、外部素材は追加していない。

- 主武器の発射時に、白い芯と銃口の前へ噴く炎を追加。実弾は橙、光学兵器は青緑。寿命は0.08秒（散弾0.1秒）で、縮んで薄れる。
- 散弾は粒ごとに増やさず、銃口ごとに1つ。二丁武器は左右。充填する主武器は解放時に出し、満充填で光弾になる物にも対応。
- 銃口ごとに1メッシュ/1材質を使い回し、形状と2種類のテクスチャは共有。メッシュは6三角形。光源・当たり判定は追加しない。
- 移動・構え・反動と補正済みの銃口に追従し、持ち替え・撃破で消える。再試合・マップ切替では機体とともに材質が破棄される。

## 確認

- Playwrightで主武器100型（うち二丁26型）の `shot` を呼び、左右の表示数・再利用・深度設定・寿命・当たり判定数を確認。空撃ち、リロード、持ち替え、ポッド、ガトリングの空転、充填中には出ないこと、充填解放・二丁光弾・Botの射撃で出ること、上下/屈み/移動への追従、持ち替え/撃破/副武器では表示しないこと、マップ切替での材質破棄も確認。[結果と対象一覧](validation.json)。この確認は演出に絞り、100型すべての戦闘性能を試したものではない。
- `node tools/test/quick_check.js origin/main`：city/dock各60秒のBot戦成功。武器285種・72パーツ・マップのデータ変更は0。[全出力](quick-check.txt)。
- `node tools/test/muzzle_wall_check.js dbg/muzzle-flash`：4兵装で壁越しの射撃なし、開けた所の銃口位置は同じ。[全出力](wall-check.txt)。
- 実弾・ガトリング・二丁・光学の画像と、アサルトライフルの連射→停止を90フレーム/30fpsで確認。動画は `weaponsTick`・`weaponLook`・`mainMuzzleUpdate` を1/30秒ずつ進めて描画した。ブラウザエラーなし。

再確認は `python3 tools/test/make_dbg.py dbg/muzzle-flash` で作ったデバッグ版から行える。発射は `__g.weaponsTick`、演出の時間送りは `__g.mainMuzzleUpdate`、表示は `__g.player.gun.userData.muzzleFlame`（左手は `gun2`）で確認する。
