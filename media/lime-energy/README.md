# ライムグリーンの光学弾

2026-10-21追記：ユーザー指定でプラズマ砲をピンクの太い砲弾へ、光弾狙撃ライフルを即時の緑レーザー＋0.4秒の残光へ変更した。[現在の描画と確認](../plasma-visual/README.md)。以下は最初の実装時の記録。

[通常の光学弾](lime-shot.png)／[敵軍](enemy-shot.png)／[満充填の二丁光弾](charged-dual.png)／[プラズマ弾](plasma.png)／[実弾との比較](ballistic.png)／[連射→停止の動画（3秒）](firing.webm)。本体の射撃・弾道・飛翔弾を確認用の固定カメラで実描画。外部素材は追加していない。

- 光学弾を敵味方ともライムグリーン `#b8ff32` に統一。通常の光学銃は細いレーザー状の筋が進み、見た目の到達後に短い残光が消える。
- 筋は最大18m、半径0.014〜0.055m、残光0.06秒。これらは見た目の調整値。描画上の速度450m/sと着弾演出の遅延は従来のまま。
- 飛翔する充填光弾・蓄圧砲・プラズマ弾は球の代わりに細い尾を引く。先端は従来の弾の位置にあり、後ろの尾だけを描く。尾は最大10m、速度×0.06秒以内、発射点を越えない。
- 飛翔弾の形と材質は共有。実弾の色・太さ・筋の長さ、狙撃銃の煙、銃口の発光、光波剣の三日月は継承する。弾速・威力・爆風・発射間隔・弾数・衝突判定は変更しない。

本体HTML blob：`cf5054cb0921e47fae3a4b22659b952468ddb56a`。main `38aa29f`（兵装マークまで）を取り込み済み。
