# 副武器33型の検証画面

`tools/test/secondary_weapons_check.js` で出力し、型の一覧・オリジナルの形・性能比較の▲▼を目視確認した。画面は追加候補にマウスを置いて、現在の装備との違いを表示している。

- `assault.png`：VC-8系の連鎖ボム4型と強装型の比較。
- `heavy.png`：LQ-9系の蓄圧砲3型。半/満充填の威力、充填時間、重量の比較。
- `raid.png`：SZ-4系の二段ズーム狙撃銃4型と倍率・反動の比較。
- `support.png`：VN-6系の遠隔ボムランチャー4型と連射型の比較。

性能照合は33型、既存217種・36パーツの一致と初期装備順も確認。挙動36項目は熱の接触/継続/再接触/壁貫通、地表連鎖と反射・障害物、炸裂弾の部位/頭部判定と重複除外、二段階充填と連続発射・過熱、地雷の感知・上昇・遅延、遠隔ボムの吸着と敵機追従、ポッド制約、Botの罠設置、マップ切替の片付け、バリケードのある市街地での近接攻撃を含む。実際の右クリックで倍率の循環と持ち替え解除を確認し、4兵装の選択保存と再読み込みを確認した。

全250種の射撃でコンソールエラーなし。新33型は持続効果を型ごとに片付け、5秒充填の重装型にも十分な時間を与えて実射し、33型すべてで発射・弾消費・正の実ダメージを確認した。射撃検査は描画を行列更新だけに置き換えている。射撃ログのダメージは命中状況と機体補正を含むため、性能の比較にはカタログ表を使う。wikiの不明値と本作の再現値は `research/arcade/weapons/secondary.md` に記載する。

Bot対戦は市街地153秒・広域152秒・台地158秒、港湾は27秒で戦力0の正常終了。4マップともエラーなし。新副武器は10系統25型の実射を計94射記録した。
