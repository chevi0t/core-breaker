# 自機の操縦感を強めた移動音

[調整後の8秒の試聴音声](movement-demo.ogg)。ゲーム本体のWeb Audio処理で、歩行→クイックブースト→巡航→ジャンプ・着地→滞空→加速装置の順に合成しています。[変更前の同じ動作](../movement-audio-sync/movement-demo.ogg)と比較できます。

足音の音量係数を半分、クイックブーストを1.44倍、巡航などの継続噴射を1.625倍にしました。これらの移動音は自機専用です。味方・敵の射撃音と警告音は引き続き鳴ります。

既存CC0素材の再利用です。[素材の出典と作者への謝辞](../../sounds/CREDITS.md)を参照してください。
