# 自機の操縦感を強めた噴射音

[ブースト専用の試聴（WAV）](boost-sampled.wav)は単発→3連発→巡航の6秒です。[小さいOGG版](boost-sampled.ogg)もあります。[全体の8秒の試聴](movement-demo.ogg)は、歩行→クイックブースト→巡航→ジャンプ・着地→滞空→加速装置の順です。いずれもゲーム本体のWeb Audio処理を録音しています。

クイックブーストはオーナー指定で提供動画の実音をサンプリングしています。最初の噴射の0.728秒から約0.24秒を取り、音程を変えずに低い不要成分と始端・終端だけを整えました。PCM WAVで収録し、`tools/build_sounds.py --only boostStart` で生成データへ入れています。既存13音のデータは完全に同じです。巡航はユーザーが採用した[噴流版](boost-airflow.ogg)から波形を変えていません。24kHz・48kHzで全サンプルの完全一致を確認しています。移動音は自機専用です。

短い噴射はユーザー提供動画の実音、巡航はコードによるオリジナルの合成音です。歩行・着地などは既存CC0素材の再利用です。[提供素材の記録と作者への謝辞](../../sounds/CREDITS.md)を参照してください。
