# 自機の操縦感を強めた噴射音

[ブースト専用の試聴（WAV）](boost-pressure.wav)は単発→3連発→巡航の6秒です。[小さいOGG版](boost-pressure.ogg)もあります。[全体の8秒の試聴](movement-demo.ogg)は、歩行→クイックブースト→巡航→ジャンプ・着地→滞空→加速装置の順です。いずれもゲーム本体のWeb Audio処理を録音しています。

クイックブーストは低い打撃成分を抑え、空気が強く抜ける「ブシュゥー」を中心にしました。巡航はユーザーが採用した[噴流版](boost-airflow.ogg)から波形を変えていません。24kHz・48kHzで全サンプルの完全一致を確認しています。足音の音量係数は元の半分、クイックブーストは1.44倍、巡航などの継続噴射は1.625倍です。これらの移動音は自機専用です。味方・敵の射撃音と警告音は引き続き鳴ります。

専用の噴射音はコードによるオリジナルの合成音です。歩行・着地などは既存CC0素材の再利用です。[素材の出典と作者への謝辞](../../sounds/CREDITS.md)を参照してください。
