# 自機の操縦感を強めた噴射音

[ブースト専用の試聴](boost-airflow.ogg)はクイックブースト3回→巡航です。[変更前の同じ6秒](boost-preview.ogg)と比較できます。[全体の8秒の試聴](movement-demo.ogg)は、歩行→クイックブースト→巡航→ジャンプ・着地→滞空→加速装置の順です。いずれもゲーム本体のWeb Audio処理を録音しています。

音程のある低音・倍音・周期的な唸りを外し、クイックブーストは空気圧の立ち上がりと抜ける噴流、巡航は広い帯域の持続噴射にしました。足音の音量係数は元の半分、クイックブーストは1.44倍、巡航などの継続噴射は1.625倍です。これらの移動音は自機専用です。味方・敵の射撃音と警告音は引き続き鳴ります。

専用の噴射音はコードによるオリジナルの合成音です。歩行・着地などは既存CC0素材の再利用です。[素材の出典と作者への謝辞](../../sounds/CREDITS.md)を参照してください。
