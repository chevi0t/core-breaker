# 榴弾砲の画面確認

- [射撃モード](mode.png)：拡大マップ、水平射程、着弾誤差、連続砲撃中の表示。右クリックで直前の武器へ戻る。
- [装備画面](loadout.png)：オリジナルの発射筒と4型の一覧、性能・重量の比較。

`node tools/test/artillery_check.js dbg [画像出力先] [変更前stats.json]` で再現する。AC4型の数値、86項目の動作、相対マウス入力のイベント、ポインタロック中と解除後の実クリック、保存・再読み込みを検証する。ヘッドレスChromiumのCDP移動は相対量が不定になるため、相対移動の検証にはmovementX/movementY付きDOMイベントを使う。
