# ブースター演出の強化

背面ノズルに沿う二条の噴流。青い外炎・白熱した芯・流れる節と、短い点火リングを1メッシュにまとめる。巡航、短いブースト、加速装置、滞空、近接踏み込みで噴流の長さを変える。音、移動性能、消費、照準・カメラの数値は変更しない。

## 再確認

```sh
python3 tools/test/make_dbg.py dbg/boost
node tools/test/booster_visual_check.js dbg/boost
python3 tools/booster_preview.py dbg/boost/results/model.json dbg/boost/results/preview.html
node tools/test/quick_check.js origin/main
```

`preview.html` は実際の機体・噴流のシェーダーと本体の更新関数を使ったオフライン確認画面。ボタンで噴射を変え、ドラッグで回転、ホイールで拡大できる。音声なし、機体は比較用の固定姿勢。

`checks.json` に33項目の結果を記録。実移動との同期、連続ステップ、巡航移行、停止・死亡・再出撃、迷彩、機体本体への実射、壁での実描画の遮蔽、ゲーム状態と乱数の分離、共有資源と解放を確認した。

噴流は1機1ドロー・864三角形。100機分を作っても形状は1個を共有し、噴射中に追加オブジェクトを生成しない。他機の180m以遠では点火輪を省略、350m以遠は非表示。これは描画構造の確認で、100機戦の実機GPUのFPS計測ではない。

噴流を視覚効果として当たり判定から除外した。旧来の円錐は機体の全メッシュを被弾対象へ登録する処理に混ざっていたため、長い炎が被弾面にならないよう明示的に分離。装甲と武器の形は変更していない。
