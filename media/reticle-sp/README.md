# 照準円の下のSPゲージ

[通常](normal.png)／[作動中](active.png)／[再充填中](recharging.png)／[スコープ中](scope.png)／[640×480](small.png)。本体のHUDと3D画面をChromiumで実描画し、確認用にSP残量と状態を固定して撮影したもの。

- 武器を持ち替えても、照準円の下で特別装備のSP残量を確認できる。横バーと残量%を表示する。
- 左下と同じ残量・緑の作動表示・迷彩被弾時の赤・使い切った後の再充填を表示。SPの消費や回復は既存の処理を読む。
- 照準円のサイズから配置を計算し、中央の操作メッセージはバーの下へ避ける。スコープ中も表示し、撃破・行動不能中は隠す。

確認：[表示・状態・配置の結果](validation.json)、[簡易テスト](quick-check.txt)。`make_dbg.py` で本体から確認用ページを作り、Playwrightで4兵装×4武器枠×残量4段階の表示、迷彩の実消費・回復・被弾、使い切り後の回復と再出撃、スコープ、640×480・800×600・1280×720・1920×1080の配置を確認した。簡易テストは `node tools/test/quick_check.js origin/main`（city/dock、各60秒指定。dockは28秒で決着）。いずれも成功し、ブラウザのエラーなし。
