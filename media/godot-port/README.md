# Godot版の初期移植の確認

2026-10-21、Godot 4.6.3。ブラウザ版も独立して開発を続ける。今回の到達点・残差は [godot/PORTING.md](../../godot/PORTING.md)。

## 画面

- [出撃画面](menu.png)：名前、出撃側、猫、4兵装の武器、72パーツを選択。
- [対戦画面・ロック警告](battle.png)：元のオリジナル形状を使ったGodotの3D描画。

1280×720、ソフトウェア描画のOpenGL/llvmpipeで撮影。位置とロック先を固定した目視用の場面で、通常戦の成績や移植完了の証拠とは区別する。画像加工は行っていない。[撮影条件](capture.json)、再現用の `godot/tests/capture.gd` を同梱している。ダミー画面でV-Syncを変更できない警告は出るが、スクリプト/描画の実行エラーは0。

## 動作確認

[validation.json](validation.json) に環境・結果・取込元のハッシュを保存した。

- 機能検査 **813/813成功**：24条件の機体性能比較、元の地形高、1/60秒のジャンプ実測、全配置の生成、通常射撃・頭部倍率・味方判定、占拠、大破/蘇生、ポッドの行動制限と離脱、リフト往復、パッド、ジップ、平面索敵、熱、跳躍地雷、SP、砲撃、転送、デモ人数、武器一覧の発射/状態など。
- Godotの通常全10配置で各150秒のBOT戦（港は104.9秒で正常決着）。全配置で発砲・命中・撃破が発生し、コア戦は占拠所有権も変化。実行エラー0。
- Linux向けのリソースパックを書き出し、リポジトリ外の `/tmp` から30秒の市街地BOT戦を実行。20機・発砲・撃破・占拠を確認。ブラウザ版やその保存データは起動に不要。
- ブラウザ版の `quick_check.js origin/main` 成功。市街地と港で各60秒、コンソールエラー0。ブラウザ本体・マップ・既存の配布/共通試験ツール・package.jsonの変更なし。

各配置1戦の機能確認であり、両版の戦績一致・公平さ・Windows/macOSでの実機性能や聴感は未検証。全武器のデータ・基本動作を読み込めることも、全ての特殊効果・操作・UIの再現が完了したこととは区別する。
