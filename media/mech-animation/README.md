Node 24・Playwright 1.56.1・Chromium 141・Three.js r128・SwiftShaderで確認。関節だけの20機分のCPU処理は最後の実行で約4.0ms/フレーム（30回平均。他の検証も並列実行中。初回約1.1ms、GPU描画は含まない）。全シーンのFPSを示す値ではない。

全武器の初回試験では連鎖ボムを胴へ投げていたため、動いた装甲/武器で反射し、敵から離れた所に接地する場合があった。単発の狙撃は初弾から新しい姿勢・行列で確かめるため、発射前に表示を同期した。ゲームの投擲・反射・ダメージを変えず、上記6型の追加試験で仕様どおりの地面狙いと発射前の表示同期を確認した。この試験条件の変更は `tools/test/weapons_check.js` にも残した。

件数と対象コミット、ログのSHA256は [validation.json](validation.json)。実行手順は [参考資料](../../research/animation/README.md#再現と検証) に記載してある。Claudeのレビューでは、この対象コミットと結果を確認して、必要な追加検証を選べるようにする。
