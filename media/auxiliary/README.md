# 補助装備の選択・型比較

`node tools/test/auxiliary_equipment_check.js dbg/auxiliary media/auxiliary [追加前stats.json]` で、実ゲームのカスタマイズ画面から取得。

- claw.png：双爪ガントレットの通常/特殊の各段合計と重量。
- pike.png：蓄圧杭の段階威力・充填時間と重量。
- air.png：浮遊自動銃の内部銃・弾倉と重量。
- radar.png：展開式レーダーの範囲・角度と重量。
- plane.png：索敵カーテンの半径・表示時間と重量。
- ammo.png：補給コンテナの感知範囲・投擲と重量。

すべて型ごとの行と比較の▲▼を表示。選択後の保存・再読み込みも検査する。公式画像・モデル・ロゴは使わない。
