# 猫の仮パイロット

制作した猫8匹は [画像と制作記録](../../prototype/avatars/CREDITS.md) を参照。

- [選択画面](selection.png)：キジトラ（垂れ目）、サバトラ（切れ長）、黒猫（ボス）、白猫（桜耳）、茶トラ（笑い顔）、三毛（いたずら顔）、ハチワレ（照れ屋）、シャム（眠たげ）。
- [アーケードHUD](arcade.png)：自分の顔と兵装の頭文字を表示。
- [640×480の標準HUD](compact.png)：顔を照準下のSPと重ねない。
- [10対10のスコア表](score.png)：自分とBotの顔。Botは陣営・機体番号で固定割り当て。
- [撃破相手](killcam.png)：キルカメラに相手の顔を表示。

白猫を選んだ状態で、試合の進行と乱数を固定して本体のHUD・3D画面を描画した。8匹の画像は透過PNGをHTMLに埋め込み、同じ1枚から表示する。ゲームや配布用の画像ファイルを追加で読まない。

確認：`pilot_avatars_check.js`（68項目・16通りの配置、画像のデコード・8匹の違いと透過・保存・兵装・再出撃・Bot・スコア・キルカメラ）、`console_hud_check.js`（359項目・32通りの配置）、`quick_check.js origin/main`（city・dockのBot戦を含む）。ブラウザのエラーなし。
