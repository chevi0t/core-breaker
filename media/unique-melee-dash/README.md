# 日本刀とレーザー爪のダッシュ技

[動画](preview.mp4)は本作のオリジナルモデルを撮影したもの。左から日本刀、双爪ガントレット基本型、重装型。実際の速さで再生し、水平移動だけ据え置いている。日本刀の小跳躍は本体の物理を実行し、実際に上下する。公式の映像や音は含まない。

`melee_dash_capture.js`で3型を30fps/105フレーム撮影し、横に並べた。日本刀は袈裟→逆袈裟→横薙ぎ→片手の面打ち、ガントレットは伸びるレーザー刃の右袈裟→左袈裟。重装型では刃と薙ぐ範囲、振りと戻しが大きくなる。参考資料と仕様は[記録](../../research/animation/unique-melee-dash.md)。
