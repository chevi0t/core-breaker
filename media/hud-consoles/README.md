# 切り替えられる4種類のコンソール

メニューの「コンソール」で選ぶか、戦闘中に **F2** で順番に切り替える。選択は自動で保存する。

| 選択名 | 参考にした表示 | 実画面 |
|---|---|---|
| 標準 | 現行の配置 | [1440×900](standard.png) |

| フライト | 星と翼のパラドクス。積み重ねる両軍ゲージ、丸い計器枠、中央下の装備 | [1440×900](flight.png)／[800×600](flight-small.png) |

4種類を並べた比較：[compare.png](compare.png)。4種類の実画面（1440×900・800×600）は、SPを黄色い棒だけにしてアーケードを参考画像に寄せた後（2026-10-20、ユーザー指定）に撮り直した。

[選択画面](selection.png)／[640×480・複数の警告・長い装備説明](warnings-compact.png)。本体から作った確認用ページで、数値・位置・装備を固定し、本体のHUDと3DをChromiumで実描画したもの。撮影用ページではWebGLのフレーム保持を有効にしている。参照作品の画像やロゴはゲームにもこのフォルダにも含めていない。[参考資料と本作への当てはめ](../../research/hud-consoles.md)。

照準の下のSP残量は全種類で共通。フライトの速度は上下を含む実速度、対地高度は足元から下の地面・床までの距離。切り替えは画面だけに作用する。

確認：

- `python3 tools/test/make_dbg.py dbg/hud-consoles`
- `node tools/test/console_hud_check.js dbg/hud-consoles`：359項目成功。メニューのキーボード操作、保存と再読み込み、不正な保存値、保存APIが使えない場合、F2での巡回、試合・既存の保存値を変えないこと、SP消費・回復、スコープ、行動不能と実際の再出撃を確認。
- 4種類×640×480・800×600・1280×720・1920×1080×city/dockの32通りで配置を確認。長い蓄圧杭の説明と被ロックオン・基地侵入・被索敵を含め、中央のSPや警告の重なりを検査。[結果](validation.json)。
- `node tools/test/quick_check.js origin/main`：成功。武器・機体パーツ・マップの差分なし。cityは62秒、dockは15秒で決着（各60秒指定）。[記録](quick-check.txt)。ブラウザのエラーなし。
